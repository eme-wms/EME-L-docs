# Класс FreeBrowser

Класс `FreeBrowser` в языке EME-L — браузер, не привязанный к записи базы данных (отвязанный браузер). Предоставляет механизм отображения данных из запросов EME DB в табличном виде без привязки к конкретной записи или диалогу. Источником данных для `FreeBrowser` всегда выступает объект запроса (`Query`) — в отличие от обычного `Browser`, который привязывается к шаблону браузера по имени.

Класс поддерживает создание на основе объекта запроса с необязательным указанием имени браузера, имени EME-L-класса и сетевой настройки. Позволяет настраивать источник данных (метод `Tune`), управлять заголовком окна и софтовым именем, сохранять и загружать сетевые и базовые настройки, а также программно управлять сохранением фильтров и сортировок и устанавливать форматы отображения колонок.

Внимание! Для того чтобы настройки браузера можно было сохранить, ему нужно дать имя и записать в запись настроек. Обычный браузер делает это при его создании в редакторе диалогов. Здесь нужно зайти в меню браузера «Настройки» -> «Сохранить настройки браузера в шаблон». Если после этого браузер переименовать, его настройки потеряются.

## Создание объекта

Класс `FreeBrowser` имеет пять перегрузок конструктора — на каждое число аргументов от 0 до 4.

```EME-L
'Без аргументов — привязка к текущему контексту выполнения'
objFB = Object("FreeBrowser");
```

```EME-L
'Только объект запроса (query зарезервирован, но не используется для настройки)'
objFB = Object("FreeBrowser", objQuery);
```

```EME-L
'Объект запроса + имя браузера (включает режим сохранения настроек)'
objFB = Object("FreeBrowser", objQuery, "Приходы без ASN");
```

```EME-L
'Объект запроса + имя + имя класса EME-L (устанавливает прокси-обработчик)'
objFB = Object("FreeBrowser", objQuery, "Приходы без ASN", "GoodsItem");
```

```EME-L
'Объект запроса + имя + класс + сетевая настройка (режим сохранения НЕ включается)'
objFB = Object("FreeBrowser", objQuery, "Приходы без ASN", "GoodsItem", "ASN_Layout");
```

| Конструктор | Аргументы | Возвращает | Описание |
|-------------|-----------|------------|----------|
| `FreeBrowser()` | — | FreeBrowser | Отвязанный браузер, подключённый к текущему контексту выполнения. Используется, когда браузер создаётся внутри диалога, уже содержащего отвязанный браузер. |
| `FreeBrowser(query)` | query: Query (зарезервирован) | FreeBrowser | Пустой объект `FreeBrowser` без привязки к источнику данных. В текущей версии параметр `query` зарезервирован, но не используется при создании браузера. |
| `FreeBrowser(query, name)` | query: Query, name: String | FreeBrowser | Отвязанный браузер на основе объекта запроса с указанием имени. Имя используется для сохранения настроек и отображения заголовка окна. При создании автоматически включается режим сохранения настроек. |
| `FreeBrowser(query, name, className)` | + className: String | FreeBrowser | То же с указанием имени класса EME-L. Устанавливает прокси-обработчик для маршрутизации сообщений браузера. При создании автоматически включается режим сохранения настроек. |
| `FreeBrowser(query, name, className, netSettings)` | + netSettings: String | FreeBrowser | То же с загрузкой сетевой настройки из базы данных. Устанавливает прокси-обработчик. **В отличие от трёхаргументной формы**, режим сохранения настроек автоматически **не** включается. |

Безаргументная форма (`FreeBrowser()`) требует, чтобы контекст выполнения уже содержал отвязанный браузер — в противном случае объект останется пустым.

## Методы

Методы сгруппированы по функциональности. Все методы возвращают `Boolean` в формате EME-L (TRUE = -1, FALSE = 0), если не указано иное. Возвращаемое `false` для булевых методов означает «браузер не найден».

### Управление настройками

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetSaveSettingsFlag(flag)` | flag: Boolean | Boolean | Управляет флагом сохранения настроек отвязанного браузера. `true` — сохранять настройки, `false` — не сохранять. |
| `SaveBaseSettings()` | — | Boolean | Сохраняет базовую настройку отвязанного браузера в базе данных. |
| `SaveNetSettings(name, forAllUsers)` | name: String, forAllUsers: Boolean | Boolean | Сохраняет сетевую настройку с именем `name`. `forAllUsers=true` — доступна всем пользователям, `false` — только текущему. |
| `LoadNetSettings(name)` | name: String | Boolean | Загружает сетевую настройку `name`. После успешной загрузки флаг сохранения настроек автоматически сбрасывается в `false`. |

### Источник данных и идентификация

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Tune(source)` | source: String или Query | Boolean | Настраивает источник данных. При строковом аргументе — имя шаблона браузера; при передаче объекта `Query` — подключает его в качестве источника данных. |
| `SetSoftName(name)` | name: String | Boolean | Устанавливает софтовое имя браузера, используемое для сохранения настроек. |
| `SetTitle(title)` | title: String | Empty | Устанавливает заголовок окна браузера. |

### Сохранение фильтров и сортировок

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetFilterSaving(saveFlag)` | saveFlag: Boolean | Empty | Управляет режимом сохранения фильтров. `true` — сохранять фильтры всегда, `false` — не сохранять. |
| `SetSortSaving(saveFlag)` | saveFlag: Boolean | Empty | Управляет режимом сохранения сортировок. `true` — сохранять сортировки всегда, `false` — не сохранять. |

### Формат колонок

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetColumnFormat(columnName, format)` | columnName: String, format: String | Empty | Устанавливает формат отображения ячеек колонки `columnName`. Примеры форматов: `"%s"` — строковое представление, `"%.2f"` — вещественное число с двумя знаками после запятой. При отсутствии браузера или ненайденной колонке генерируется ошибка (в режиме `except`). |

## Методы базового класса Browser

Помимо перечисленных выше собственных методов, объект `FreeBrowser` наследует полноценный интерфейс запуска и навигации от базового класса [`Browser`](./browser.md) — в частности `Run`, `Close`, `RemoveColumn`, `GetName`, `GetColumn` и др. Это позволяет использовать `FreeBrowser` как обычный браузер: открыть модально, выбрать строку, программно скрыть колонки и т. п.

## Примеры

Создание браузера по объекту запроса с запуском и выбором строки:

```EME-L
'Настроить запрос и создать отвязанный браузер с именем'
objQuery = Object("Query", "SELECT * FROM GoodsItems");
objQuery.SetFirstLine();
FreeBrowser = Object("FreeBrowser", objQuery, "Товары");
QueryLine = FreeBrowser.Run(0);
'QueryLine — номер выбранной строки или -1 при отмене'
```

Краткая форма создания и немедленный запуск (результат `Run` отбрасывается):

```EME-L
Object("FreeBrowser", Query, "Свертка").Run();
```

Установка формата колонки и управление сохранением фильтров:

```EME-L
FreeBrowser = Object("FreeBrowser", objQuery, "Отчёт по остаткам");
FreeBrowser.SetColumnFormat("Цена", "%.2f");
FreeBrowser.SetFilterSaving(True);
FreeBrowser.SetSortSaving(False);
```

Сохранение сетевой настройки с диалогом ввода имени:

```EME-L
FreeBrowser = Object("FreeBrowser");
Name = is_enter_value_dialog(tr("Введите имя представления"), "");
If (~is_empty(Name))
    is_transaction(1, tr("Сохранение представления"));
    FreeBrowser.SaveNetSettings(Name, False);
    is_transaction(-1);
End If
```
