# Класс IrrImage

Класс `IrrImage` в языке EME-L — класс двумерного изображения движка Irrlicht. Представляет растровое изображение, хранящееся в формате ARGB32, и предоставляет средства для его создания, рисования примитивов и текста, загрузки из файла, сохранения, копирования, поворота, а также наложения одного изображения на другое.

Основные возможности: заливка фона и прямоугольников цветом RGBA; рисование прямоугольников, эллипсов, текста и других изображений; настройка пера, кисти, шрифта, сглаживания примитивов и текста; получение размеров изображения и габаритов строки текста; загрузка и сохранение файлов с указанием формата; копирование части изображения в другой объект `IrrImage` и поворот изображения на произвольный угол.

Используется в прикладных скриптах EME-L для подготовки и обработки двумерной графики, текстур и элементов интерфейса перед отображением в сцене Irrlicht.

## Создание объекта

Класс `IrrImage` имеет два конструктора — один на каждое число аргументов.

```EME-L
'Конструктор без аргументов — изображение 32x32 пикселя'
objImage = Object("IrrImage");
```

```EME-L
'Конструктор с указанием ширины и высоты в пикселях'
objImage = Object("IrrImage", 1000, 1000);
```

Конструктор без аргументов создаёт изображение размером 32×32 пикселя. Конструктор с двумя аргументами создаёт изображение заданного размера. В обоих случаях формат пикселей — ARGB32 (8 бит на канал, включая альфа-канал).

## Цвета и заливка

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Fill(arg0)` | arg0: Integer (RGBA) | Empty | Заполняет всё изображение заданным цветом. |
| `FillRect(arg0, arg1, arg2, arg3, arg4)` | arg0: Integer (left), arg1: Integer (top), arg2: Integer (width), arg3: Integer (height), arg4: Integer (RGBA) | Empty | Заполняет прямоугольник цветом. |

Цвет передаётся как целое число в формате RGBA. Для формирования значения используйте функцию `is_RGBA(r, g, b, a)`.

## Перо, кисть, шрифт

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetPen(arg0)` | arg0: Integer (RGBA) | Empty | Задаёт цвет пера для рисования линий и контуров. |
| `SetBrush(arg0)` | arg0: Integer (RGBA) | Empty | Задаёт цвет кисти для заливки фигур. |
| `SetFont(arg0, arg1)` | arg0: String (имя), arg1: Integer (размер, пт) | Empty | Устанавливает шрифт для рисования текста. |
| `SetFont(arg0, arg1, arg2)` | arg0: String (имя), arg1: Integer (размер, пт), arg2: Integer (вес) | Empty | То же с указанием веса (0–99; 50 — нормальный, 75 — жирный). |
| `SetAntialiasing(arg0)` | arg0: Boolean | Empty | Включает (`TRUE`) или отключает (`FALSE`) сглаживание примитивов. |
| `SetTextAntialiasing(arg0)` | arg0: Boolean | Empty | Включает (`TRUE`) или отключает (`FALSE`) сглаживание текста. |

Вес шрифта соответствует шкале `QFont`: 50 — `Normal`, 75 — `Bold`.

## Рисование примитивов и текста

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `DrawRect(arg0, arg1, arg2, arg3)` | arg0: Integer (left), arg1: Integer (top), arg2: Integer (width), arg3: Integer (height) | Empty | Рисует контур прямоугольника текущим пером. |
| `DrawEllipse(arg0, arg1, arg2, arg3)` | arg0: Integer (left), arg1: Integer (top), arg2: Integer (width), arg3: Integer (height) | Empty | Рисует эллипс, вписанный в ограничивающий прямоугольник, текущим пером. |
| `DrawText(arg0, arg1, arg2, arg3, arg4, arg5)` | arg0: Integer (left), arg1: Integer (top), arg2: Integer (width), arg3: Integer (height), arg4: String (флаги), arg5: String (текст) | Empty | Рисует текст в заданном прямоугольнике с выравниванием. |
| `GetTextHeight(arg0)` | arg0: String | Integer | Высота строки текста в пикселях при текущем шрифте. |
| `GetTextWidth(arg0)` | arg0: String | Integer | Ширина строки текста в пикселях при текущем шрифте. |

Флаги выравнивания в `DrawText` передаются строкой через точку с запятой. Допустимые значения: `"Left"`, `"Right"`, `"HCenter"` — по горизонтали; `"Top"`, `"Bottom"`, `"VCenter"` — по вертикали. По умолчанию применяется `"HCenter;VCenter"`; если строка флагов пуста, также используется выравнивание по центру.

## Загрузка и сохранение

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `LoadFile(arg0)` | arg0: String (имя файла) | Boolean | Загружает изображение из файла. `TRUE` — успех, `FALSE` — ошибка. |
| `LoadFile(arg0, arg1)` | arg0: String (имя файла), arg1: String (формат) | Boolean | Загружает из файла в указанном формате. |
| `SaveFile(arg0)` | arg0: String (имя файла) | Boolean | Сохраняет изображение в файл. `TRUE` — успех, `FALSE` — ошибка. |
| `SaveFile(arg0, arg1)` | arg0: String (имя файла), arg1: String (формат) | Boolean | Сохраняет в файл в указанном формате. |

`LoadFile` сначала пытается прочитать файл через файловую систему EME (запись «Файловая система» или «Файловые ресурсы»); если файл не найден, используется прямой путь на диске.

## Размеры изображения

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetWidth()` | — | Integer | Ширина изображения в пикселях. |
| `GetHeight()` | — | Integer | Высота изображения в пикселях. |

## Операции с изображениями

Эти методы принимают ссылки на другие объекты — `IrrImage` и `Rect`.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `CopyImage(arg0, arg1)` | arg0: IrrImage (по ссылке), arg1: Rect (по ссылке) | Empty | Копирует часть текущего изображения в `arg0`. Прямоугольник `arg1` задаёт копируемую область. |
| `RotateImage(arg0, arg1)` | arg0: IrrImage (по ссылке), arg1: Real (угол, градусы) | Empty | Поворачивает текущее изображение на `arg1` градусов и помещает результат в `arg0`. |
| `DrawImage(arg0, arg1)` | arg0: IrrImage (по ссылке), arg1: Rect (по ссылке) | Empty | Рисует изображение `arg0` на текущем в области `arg1`. |

Для создания прямоугольника `Rect` используйте `Object("Rect", left, top, right, bottom)`.

## Примеры

Загрузка изображения, рисование и сохранение результата:

```EME-L
'Загрузить исходное изображение из файла'
objImage = Object("IrrImage");
objImage.LoadFile("D:\\1.png");

'Нарисовать контур прямоугольника текущим пером'
objImage.SetPen(is_RGBA(0, 0, 0, 255));
objImage.DrawRect(10, 10, 100, 20);

'Сохранить результат в новый файл'
objImage.SaveFile("D:\\result.png");
```

Создание изображения заданного размера с заливкой, текстом и поворотом:

```EME-L
'Создать изображение 200x200 с жёлтой заливкой'
objImg = Object("IrrImage", 200, 200);
objImg.Fill(is_RGBA(0xFD, 0xD8, 0x2F, 0xFF));

'Настроить шрифт и нарисовать текст по центру'
objImg.SetFont("Arial", 16);
objImg.SetPen(is_RGBA(0, 0, 0, 255));
objImg.DrawText(0, 0, 200, 200, "HCenter;VCenter", "Hello!");

'Повернуть на 90 градусов в новый объект'
objRotated = Object("IrrImage");
objImg.RotateImage(objRotated, 90);

objRotated.SaveFile("D:\\rotated.png");
```

Копирование части изображения и наложение на другое:

```EME-L
'Загрузить источник и создать пустой холст'
objSource = Object("IrrImage");
objSource.LoadFile("3D\\rack.png");
objCanvas = Object("IrrImage", 1000, 1000);

'Скопировать фрагмент (60,25)-(110,202) из источника'
objFragment = Object("IrrImage");
objSource.CopyImage(objFragment, Object("Rect", 60, 25, 110, 202));

'Нарисовать фрагмент на холсте'
objCanvas.DrawImage(objFragment, Object("Rect", 0, 0, 50, 177));

objCanvas.SaveFile("3D\\composed.png");
```

Измерение габаритов текста при текущем шрифте:

```EME-L
objImage = Object("IrrImage");
objImage.SetFont("Arial", 24);
Height = objImage.GetTextHeight("Text");
Width  = objImage.GetTextWidth("Text");
```
