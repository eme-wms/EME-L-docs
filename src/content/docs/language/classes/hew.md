# Класс Hew

Класс `Hew` в языке EME-L — класс для работы с переменной выделения (битовым буфером) строк записей базы данных. Предоставляет механизм управления множественным выделением строк через битовый массив, привязанный к переменной диалога, записи базы данных или фильтру строк.

Поддерживает операции установки и снятия пометок на отдельных строках, проверку состояния выделения, навигацию по выделенным строкам, а также массовые операции — инверсию, очистку и подсчёт выделенных строк. Дополнительно реализует сериализацию состояния выделения в строку Base64 и обратно, заполнение выделения из массива ссылок или объекта Array, применение EME-L фильтров для инициализации выделения по алгоритму класса, сравнение и слияние с другими объектами Hew.

Используется в прикладных скриптах EME-L для программного управления множественным выбором строк в браузерах, диалогах и запросах, а также для передачи наборов выделенных строк между методами и объектами.

## Создание объекта

Объект `Hew` создаётся через `Object()`. Поддерживаются две перегрузки конструктора — без аргументов и с указанием диалога и имени переменной выделения.

```EME-L
'Конструктор без аргументов — создание несвязанного объекта'
objHew = Object("Hew");
```

Несвязанный объект инициализируется later — методами `AttachToRecord`, `Attach`, `AttachToLineFilter`, `InitHew` или `InitFromArrayOfRefs`.

```EME-L
'Конструктор с привязкой к переменной выделения диалога'
objHew = Object("Hew", Dialog, "Заказы");
```

Вторая форма эквивалентна последовательности `Object("Hew")` и `Attach(Dialog, "Заказы")`: объект сразу привязывается к существующей переменной выделения указанного диалога.

## Идентификатор и состояние

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetIdentificator(arg0)` | arg0: любой тип | Empty | Устанавливает произвольный идентификатор для объекта; хранится внутри и может использоваться для различения нескольких объектов Hew. |
| `GetIdentificator()` | — | тип, переданный в `SetIdentificator` | Ранее установленный идентификатор; пустое значение, если не был установлен. |
| `IsAttached()` | — | Boolean | TRUE — объект привязан к переменной выделения (внутренний битовый буфер создан или подключён); FALSE — не инициализирован. |
| `GetRecord()` | — | ссылка на CEMERec | Указатель на запись базы данных, к которой привязана переменная выделения; NULL, если привязки нет. |
| `SetAutoDelete(arg0)` | arg0: Boolean | Empty | Управляет автоматическим уничтожением внутреннего битового буфера при уничтожении объекта: TRUE — буфер удаляется вместе с объектом; FALSE — буфер сохраняется. |

## Привязка к источнику данных

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Attach(arg0, arg1)` | arg0: ссылка на Dialog, arg1: String (имя переменной) | Boolean | Привязывает объект к переменной выделения указанного диалога. TRUE — успех, FALSE — диалог не найден или переменная отсутствует. |
| `AttachToRecord(arg0)` | arg0: String (имя записи) / Integer (номер) / ссылка CEMERec | Boolean | Привязывает объект к записи базы данных, создавая переменную выделения для её строк. TRUE — успех, FALSE — запись не найдена. |
| `AttachToLineFilter(arg0)` | arg0: ссылка на LineFilter | Boolean | Привязывает объект к фильтру строк, помечая в переменной выделения все строки из фильтра. |
| `AttachToLineFilter(arg0, arg1)` | arg0: ссылка на LineFilter, arg1: Integer (номер записи) или String (имя) | Boolean | То же с явной записью; если не указано — используется запись, связанная с фильтром. |
| `Detach()` | — | Integer | Отвязывает объект и уничтожает внутренний битовый буфер. Всегда возвращает 1. |
| `InitHew(arg0, arg1, arg2[, arg3...])` | arg0: запись, arg1: String (класс фильтра), arg2: String (метод фильтра), arg3+: параметры | Integer | Привязывает объект к записи и инициализирует выделение вызовом метода EME-L-класса фильтра. Переменная выделения передаётся в метод автоматически первым аргументом. Возвращает количество прошедших фильтрацию строк; -1 — переменная не установлена или результат пуст; -2 — класс не найден/ошибка; -3 — метод не найден. |
| `InitFromArrayOfRefs(arg0[, arg1])` | arg0: ссылка на Array, arg1 (опц.): запись (String/Integer/CExERec) | Boolean | Инициализирует выделение набором ссылок из массива. При указании `arg1` предварительно привязывает объект к записи. TRUE — успех, FALSE — массив пуст или объект не привязан. |

## Операции с пометками строк

Методы работают с битами, адресованными по номеру строки. Каждая строка может быть помечена (бит установлен) или снята (бит сброшен).

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `MarkLine(arg0)` | arg0: Integer (номер строки) | Empty | Устанавливает пометку на строке с проверкой корректности номера. |
| `UnmarkLine(arg0)` | arg0: Integer | Empty | Снимает пометку со строки с проверкой корректности номера. |
| `IsMarkedLine(arg0)` | arg0: Integer | Boolean | TRUE — строка помечена; FALSE — не помечена или номер некорректен. |
| `IsCorrectLine(arg0)` | arg0: Integer | Boolean | TRUE — номер строки находится в допустимом диапазоне (0 … максимальный номер строки). |
| `UnmarkAll()` | — | Empty | Снимает пометки со всех строк; буфер и привязка к записи сохраняются. |
| `RemoveAll()` | — | Empty | Синоним `UnmarkAll`. |
| `Add(arg0)` | arg0: Integer | Empty | Устанавливает пометку на строке **без проверки корректности номера** — быстрее, но требует аккуратного использования. |
| `Remove(arg0)` | arg0: Integer | Empty | Снимает пометку со строки **без проверки корректности номера**. |
| `InvertAll()` | — | Boolean | Инвертирует все биты буфера: выделенные строки становятся невыделенными и наоборот. FALSE — объект не инициализирован. |
| `GetSize()` | — | Integer | Количество помеченных строк. 0 — объект не инициализирован. |
| `IsAnyMarked()` | — | Boolean | TRUE — выделена хотя бы одна строка. |
| `IsNothingMarked()` | — | Boolean | TRUE — ни одна строка не помечена (инверсия `IsAnyMarked`). |

## Навигация по выделенным строкам

У объекта есть две **параллельные системы навигации** — по прямым номерам строк битового буфера (методы без суффикса `Rec`) и по номерам строк записи базы данных (методы с суффиксом `Rec`). Каждая система хранит свой итератор.

### Прямые номера строк битового буфера

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetFirstLine()` | — | Empty | Устанавливает итератор на первую выделенную строку. |
| `SetNextLine()` | — | Empty | Перемещает итератор на следующую выделенную строку. |
| `IsValidLine()` | — | Boolean | TRUE — итератор указывает на корректную выделенную строку; FALSE — достигнут конец набора. |
| `GetLine()` | — | Integer | Номер текущей строки итератора; 0, если итератор не установлен или некорректен. |
| `SetLine(arg0)` | arg0: Integer | Empty | Устанавливает итератор на указанную строку; если строка не выделена — перемещается на следующую выделенную после неё. |

### Номера строк записи базы данных

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetFirstLineRec()` | — | Empty | Устанавливает итератор на первую выделенную строку в контексте номеров строк записи. |
| `SetNextLineRec()` | — | Empty | Перемещает итератор на следующую выделенную строку в контексте номеров записи. |
| `IsValidLineRec()` | — | Boolean | TRUE — итератор указывает на корректную выделенную строку; FALSE — достигнут конец. |
| `GetLineRec()` | — | Integer | Номер текущей строки записи; 0, если итератор не установлен или некорректен. |
| `SetLineRec(arg0)` | arg0: Integer | Empty | Устанавливает итератор на указанную строку записи. |

## Заполнение и извлечение ссылок

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `PutRefArray(arg0)` | arg0: массив ссылок | Boolean | Заполняет переменную выделения значениями из массива ссылок. Если объект не инициализирован — создаёт новый буфер размером по максимальной ссылке. TRUE — успех, FALSE — массив пуст или ошибка. |
| `GetRefArray()` | — | массив ссылок | Массив ссылок, соответствующий всем выделенным строкам; пустой массив, если объект не инициализирован или выделение пусто. |

## Сериализация состояния

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `ToString()` | — | String | Сериализует состояние выделения в строку Base64 (битовый буфер и метаданные). Пустая строка — объект не инициализирован. |
| `FromString(arg0)` | arg0: String (Base64 из `ToString`) | Boolean | Восстанавливает состояние из строки Base64. TRUE — успех, FALSE — пустая строка, неверный формат или ошибка. |

## Сравнение и слияние

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Compare(arg0)` | arg0: ссылка на Hew | Boolean | TRUE — переменные выделения совпадают; FALSE — различаются или один из объектов не инициализирован. |
| `Merge(arg0)` | arg0: ссылка на Hew | Boolean | Объединяет текущее выделение с другим: в результат попадают все строки, помеченные хотя бы в одном из объектов. TRUE — успех. |
| `CopyFrom(arg0)` | arg0: ссылка на Hew | Boolean | Копирует состояние битового буфера из другого объекта Hew в текущий. TRUE — успех, FALSE — один из объектов не инициализирован. |

## Корректировка браузера

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `CorrectDialogVariableBit_BROWSE_BIT_SELECT_MARK(arg0)` | arg0: ссылка на Dialog | Boolean | Устанавливает флаг `BROWSE_BIT_SELECT_MARK` для переменных диалога, ссылающихся на текущую переменную выделения. Это заставляет браузер использовать выделение из переменной выделения при отображении данных. TRUE — флаг установлен хотя бы для одной переменной. |

## Примеры

Создание объекта с привязкой к диалогу и снятие всех пометок:

```EME-L
OrdersHew = Object("Hew", Dialog, "Заказы");
OrdersHew.UnmarkAll();
```

Инициализация выделения перебором ссылок и пометка строк:

```EME-L
WarehousesFilter = Object("Hew");
WarehousesFilter.AttachToRecord(r_Warehouses.GetRecord());

Prefix = "WarehouseRef";
Index = 0;
Ref = DialogParameters.GetLongParam(is_format("Filter.%s.%d", Prefix, Index), NULL_REF);
While (Ref >= 0)
    WarehousesFilter.MarkLine(Ref);
    Index = Index + 1;
    Ref = DialogParameters.GetLongParam(is_format("Filter.%s.%d", Prefix, Index), NULL_REF);
End While
```

Перебор выделенных строк с использованием итератора:

```EME-L
objHew.SetFirstLine();
While (objHew.IsValidLine())
    LineNo = objHew.GetLine();
    'LineNo — номер выделенной строки битового буфера'
    objHew.SetNextLine();
End While
```
