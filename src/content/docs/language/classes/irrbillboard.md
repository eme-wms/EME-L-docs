# Класс IrrBillboard

Класс `IrrBillboard` в языке EME-L — класс билборда движка Irrlicht. Представляет плоский прямоугольный спрайт, который автоматически поворачивается лицом к камере, сохраняя неизменной видимую площадь независимо от угла обзора.

Наследует все методы базового класса [`IrrNode`](./irrnode.md) — управление положением, поворотом, масштабом, видимостью, именем, материалом и текстурой узла — и расширяет их возможностью задавать собственные ширину и высоту через метод `SetSize`. Размеры билборда масштабируются глобальным масштабом устройства `IrrDevice`, а не масштабом родительской ноды, что обеспечивает единообразный визуальный размер относительно камеры.

Используется в прикладных скриптах EME-L для отображения двумерных изображений в трёхмерной сцене: маркеров, индикаторов состояния, меток оборудования, частиц и декоративных элементов.

## Создание объекта

В блоке `BEGIN_IMPLEMENT(CIIrrBillboard)` нет зарегистрированных конструкторов с аргументами — объект `IrrBillboard` не создаётся через `Object("IrrBillboard", ...)` напрямую. Канонический способ получить билборд — вызвать `AddBillboard()` у родительского узла `IrrNode`: этот метод создаёт дочерний узел-билборд и возвращает ссылку на новый объект `IrrBillboard`.

```EME-L
'Создать устройство Irrlicht и корневой узел сцены'
objDevice = Object("IrrDevice");
objRoot   = objDevice.GetRootNode();

'Добавить дочерний билборд к корневому узлу'
objBoard = objRoot.AddBillboard();
```

При создании билборда в методе `CreateBillboard` устанавливаются значения по умолчанию:

| Параметр | Значение по умолчанию |
|----------|-----------------------|
| Идентификатор узла Irrlicht | `0` |
| Тип узла | `Billboard` |
| Масштаб | `(1, 1, 1)` |
| Имя | `""` (пустая строка) |

Ширина и высота при создании равны `0` — их необходимо задать методом `SetSize`.

При загрузке билборда из дерева свойств (`LoadNode`) ключи размеров:

| Параметр | Ключ в PropertyTree | Значение по умолчанию |
|----------|---------------------|-----------------------|
| Ширина билборда | `BillboardWidth` | `0.0` |
| Высота билборда | `BillboardHeight` | `0.0` |

## Размеры билборда

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetSize(arg0, arg1)` | arg0: Real (ширина), arg1: Real (высота) | Empty | Устанавливает ширину и высоту билборда в единицах сцены с учётом глобального масштаба устройства. Если текущий узел не является билбордом, выводится сообщение об ошибке. |

Метод `SetSize` умножает переданные размеры на глобальный масштаб устройства (`IrrDevice.m_dGlobalScale`) и вызывает `setSize` Irrlicht с порядком аргументов высота, ширина, ширина (`height, width, width`) — это особенность Irrlicht `IBillboardSceneNode::setSize`, где второй и третий параметры задают верхнюю и нижнюю ширину соответственно.

## Примеры

Создание билборда с текстурой над зоной ворот:

```EME-L
'Получить корневой узел сцены IrrDevice'
objRoot = objDevice.GetRootNode();

'Создать дочерний билборд'
objBoard = objRoot.AddBillboard();

'Задать размеры: ширина 1.0, высота 0.2 единицы сцены'
objBoard.SetSize(1.0, 0.2);

'Сместить над зоной ворот по оси Y'
objBoard.SetPosition(0.0, GateHeight + 0.3, 0.0);

'Включить прозрачность по альфа-каналу и наложить текстуру'
objBoard.SetMaterialType("trans_alphach");
objBoard.SetMaterialTexture(BillboardImage);
objBoard.SetLighting(FALSE);
```
