# Класс ArrayOfObjects

Класс `ArrayOfObjects` в языке EME-L — динамический массив указателей на объекты с автоматическим управлением памятью через механизм `SmartPointer`. Каждый элемент массива представляет собой умный указатель на объект, что обеспечивает корректное время жизни хранящихся объектов: они освобождаются автоматически при удалении из массива или при уничтожении самого массива.

Класс предназначен для хранения и манипулирования наборами объектов внутри системы EME. Поддерживает операции добавления, вставки, удаления и доступа к элементам по индексу. Индексация элементов начинается с 0.

<blockquote>
Размер массива может быть <strong>только уменьшен</strong>. Попытка увеличить размер через `SetSize` или вставить элемент за пределами текущего размера приводит к ошибке.
</blockquote>

Объект класса `ArrayOfObjects` создаётся через `Object()` и не привязан к контексту диалога или браузера — это самостоятельный класс для организации коллекций объектов в прикладных скриптах EME-L.

## Создание объекта

```EME-L
arr = Object("ArrayOfObjects");
```

Конструктор без аргументов создаёт пустой массив. Элементы добавляются методами `Add` или `InsertAt`.

<blockquote>
В языке EME-L префикс <code>arr</code> по соглашению используется для объектов класса <code>ArrayOfObjects</code> и других Array-подобных классов (<code>Array</code>, <code>MultiArray</code>). Следуйте этому правилу для читаемости кода.
</blockquote>

## Размер массива

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetSize()` | — | Integer | Текущее количество элементов в массиве. |
| `SetSize(arg0)` | arg0: Integer | Empty | Уменьшает размер массива. `arg0` должен быть меньше или равен текущему размеру; попытка увеличить размер генерирует ошибку. |

## Доступ к элементам

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetAt(arg0)` | arg0: Integer | Reference | Возвращает элемент по индексу. Индексация с 0. Выход за пределы генерирует ошибку. |
| `Lookup(arg0)` | arg0: Integer | Reference | Возвращает элемент по индексу. Если индекс выходит за пределы массива, возвращает `NULL`. |
| `Lookup(arg0, arg1)` | arg0: Integer, arg1: Reference | Reference | То же, но при выходе индекса за пределы возвращает `arg1` как значение по умолчанию. `arg1` должен быть объектом. |
| `GetContent()` | — | String | Строковое представление содержимого для отладки: имена классов объектов (или `<nullptr>` для пустых указателей), разделённые `"; "`. |

`GetAt` и `Lookup` различаются обработкой неверного индекса: `GetAt` генерирует ошибку, `Lookup` безопасно возвращает `NULL` или значение по умолчанию. Используйте `Lookup` в проверочном коде и `GetAt` когда корректность индекса гарантирована.

## Добавление и вставка

Методы `Add` и `InsertAt` имеют по две перегрузки: одна принимает готовый объект `SmartPointer`, другая принимает параметры и конструирует новый объект внутри массива.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Add(arg0)` | arg0: Reference (SmartPointer) | Integer | Добавляет существующий объект `SmartPointer` в конец массива. Возвращает индекс добавленного элемента. |
| `Add(...)` | параметры конструктора SmartPointer (≥1) | Integer | Создаёт новый `SmartPointer` из переданных параметров и добавляет в конец. Вызов без аргументов генерирует ошибку. |
| `InsertAt(arg0, arg1)` | arg0: Integer, arg1: Reference (SmartPointer) | Empty | Вставляет существующий объект по индексу. `arg0` должен быть меньше текущего размера; иначе генерируется ошибка. |
| `InsertAt(arg0, ...)` | arg0: Integer, далее параметры конструктора SmartPointer (≥1) | Empty | Создаёт новый `SmartPointer` из параметров и вставляет по индексу. Вызов с одним аргументом или без аргументов генерирует ошибку. |

## Удаление элементов

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Remove()` | — | Empty | Удаляет последний элемент. Если массив пуст, операция игнорируется. |
| `RemoveAt(arg0)` | arg0: Integer | Empty | Удаляет элемент по индексу. Индекс больше или равный размеру генерирует ошибку. |
| `RemoveAll()` | — | Empty | Очищает массив, удаляя все элементы. |

## Присвоение существующему индексу

`SetAt` заменяет элемент по индексу. Как и `Add`/`InsertAt`, имеет две перегрузки.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetAt(arg0, arg1)` | arg0: Integer, arg1: Reference (SmartPointer) | Empty | Присваивает элементу по индексу существующий объект `SmartPointer`. |
| `SetAt(arg0, ...)` | arg0: Integer, далее параметры конструктора SmartPointer (≥1) | Empty | Присваивает элементу по индексу новый объект, созданный из переданных параметров. Вызов с одним аргументом или без аргументов генерирует ошибку. |

## Примеры

Создание массива, добавление готовых объектов и обход:

```EME-L
arr = Object("ArrayOfObjects");
arr.Add(objItem1);
arr.Add(objItem2);
'arr.GetSize() возвращает количество элементов'

Loop (arr)
    'Тело цикла работает с каждым элементом массива'
    item = arr.GetAt(arr.GetSize() - 1);
End Loop
```

Безопасный доступ через `Lookup` со значением по умолчанию:

```EME-L
objDefault = Object("File");
objFound = arr.Lookup(idx, objDefault);
'objFound = элемент массива, либо objDefault если idx за пределами'
```

Отладка содержимого массива:

```EME-L
arr.Add(objItem);
Content = arr.GetContent();
'Content содержит имена классов объектов через "; "'
```

Уменьшение размера массива:

```EME-L
arr.SetSize(arr.GetSize() - 1);
'Последний элемент удалён, размер уменьшен'
```
