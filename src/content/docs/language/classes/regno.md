# Класс RegNo

Класс `RegNo` в языке EME-L — генератор регистрационных номеров строк записи (учетных номеров). Предназначен для автоматического формирования и валидации регистрационных номеров строк записей базы данных. Поддерживает два режима генерации номеров: поиск последнего использованного номера с инкрементом и поиск первого свободного номера в заданном диапазоне.

Обеспечивает работу с группами номеров, проверку допустимости вручную введенных номеров, а также получение текущих групп и индексов из записи или диалога. При переполнении разрядности может либо генерировать исключение, либо выполнять циклический переход в начало диапазона в зависимости от настроек конструктора.

Используется в прикладных скриптах EME-L для организации нумерации документов, строк таблиц и других объектов, требующих уникальных регистрационных номеров в рамках группы.

Объект класса `RegNo` создаётся через `Object()` и привязывается к объекту записи базы данных, для строк которого генерируются номера. Конструктор требует минимум один аргумент — ссылку на объект записи. Не создаётся без аргументов.

## Создание объекта

Класс `RegNo` имеет четыре перегрузки конструктора — от одного до четырёх аргументов.

```EME-L
'Минимальный конструктор — только объект записи'
objRegNo = Object("RegNo", r_Record);
```

```EME-L
'С объектом диалога — номера вычисляются в контексте диалога'
objRegNo = Object("RegNo", r_Record, r_Dialog);
```

```EME-L
'С настройкой поведения при переполнении разрядности'
objRegNo = Object("RegNo", r_Record, r_Dialog, TRUE);
```

```EME-L
'С полным контролем поведения поиска'
objRegNo = Object("RegNo", r_Record, r_Dialog, TRUE, TRUE);
```

| Конструктор | Аргументы | Описание |
|-------------|-----------|----------|
| `RegNo(record)` | record: Record (ссылка) | Создаёт генератор на основе объекта записи. |
| `RegNo(record, dialog)` | record: Record (ссылка), dialog: Record (ссылка) | Дополнительно задаёт объект диалога для определения текущей группы номеров. |
| `RegNo(record, dialog, throw_exceptions)` | + throw_exceptions: Boolean | TRUE — генерировать исключение «Превышена разрядность» при переполнении. FALSE — циклический переход в начало диапазона. |
| `RegNo(record, dialog, throw_exceptions, search_full_record)` | + search_full_record: Boolean | TRUE — просматривать все строки записи для определения максимального индекса (включается при реанимации строк в записи, когда просмотра нескольких строк с конца недостаточно; использует блочное чтение `regno_GetLastIndex`). FALSE — просматривать ограниченное число последних строк (по умолчанию). |

## Инициализация

Метод `Init` задаёт режим поиска номеров и глубину просмотра строк записи. Вызов без аргументов недопустим.

| Перегрузка | Аргументы | Возвращает | Описание |
|------------|-----------|------------|----------|
| `Init(search_last)` | search_last: Boolean | Empty | Устанавливает только режим поиска. indent и group_indent получают значения по умолчанию (1000). |
| `Init(search_last, indent)` | search_last: Boolean, indent: Integer | Empty | Устанавливает режим поиска и число просматриваемых последних строк. Тот же `indent` используется для group_indent. |
| `Init(search_last, indent, group_indent)` | search_last: Boolean, indent: Integer, group_indent: Integer | Empty | Полная инициализация с раздельными значениями indent и group_indent. Если `indent` передан как Empty, используется значение по умолчанию (1000). |

Параметры:

- **search_last** — режим поиска номера: TRUE — искать последний использованный номер и возвращать следующий (по умолчанию). FALSE — искать первый свободный номер в диапазоне.
- **indent** — число просматриваемых последних строк записи при поиске последнего номера. По умолчанию 1000.
- **group_indent** — число просматриваемых последних строк текущей группы при поиске последнего номера. По умолчанию 1000.

## Генерация и проверка номеров

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Get()` | — | String | Возвращает новый регистрационный номер. В режиме поиска последнего номера определяет максимальный индекс и возвращает следующий. В режиме свободного номера находит первый незанятый индекс. При переполнении либо генерирует исключение, либо выполняет циклический переход. |
| `GetNext(reg_no)` | reg_no: String | String | Возвращает номер, следующий за указанным. Увеличивает индекс на единицу и формирует новый номер. |
| `IsValid(reg_no)` | reg_no: String | Boolean | Проверяет допустимость номера: группа совпадает с текущей, индекс больше нуля и не превышает максимально допустимый. TRUE — номер допустим, FALSE — недопустим. |

## Группы и индексы

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetDialogGroup()` | — | String | Группа регистрационного номера текущей строки диалога. Требует объект диалога в конструкторе; при его отсутствии генерирует ошибку «Не задан диалог». |
| `GetRecordGroup()` | — | String | Группа регистрационного номера текущей строки записи. |
| `GetDialogIndex()` | — | Integer | Индекс регистрационного номера текущей строки диалога. Требует объект диалога. |
| `GetRecordIndex()` | — | Integer | Индекс регистрационного номера текущей строки записи. |

## Константы

| Константа | Значение | Описание |
|-----------|----------|----------|
| `DEFAULT_INDENT` | 1000 | Число просматриваемых последних строк по умолчанию для indent и group_indent. |

Текст исключения при переполнении разрядности: `«Превышена разрядность»`. Текст ошибки при незаданной разрядности: `«Не задана разрядность»`.

## Примеры

Генерация номера для нового документа с инкрементом от последней строки (реальный паттерн из прикладных скриптов):

```EME-L
'Создать генератор, привязанный к записи документа'
objRegNo = Object("RegNo", r_Document);
'Режим поиска последнего номера; глубина просмотра — все строки документа'
objRegNo.Init(TRUE, r_Document.GetNoOfLines(TRUE));
'Получить следующий регистрационный номер и записать его в строку'
r_Document.PutRegNo(objRegNo.Get());
```

Проверка вручную введенного номера:

```EME-L
'Проверить допустимость номера в текущей группе'
If (objRegNo.IsValid(sEnteredNo))
    'Номер допустим — использовать'
Else
    'Номер недопустим — предложить исправить'
End If
```

Получение номера от отдельной записи-перечисления (без диалога):

```EME-L
'Запись rDocEnum используется только для вычисления номера'
enum = Object("RegNo", rDocEnum);
csReg = enum.Get();
r_Document.PutRegNo(csReg);
```
