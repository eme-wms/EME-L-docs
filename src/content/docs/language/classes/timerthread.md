# Класс TimerThread

Класс `TimerThread` в языке EME-L — класс для запуска периодического таймера в отдельном потоке выполнения. Предназначен для автоматического вызова указанного метода EME-L-класса с заданным интервалом времени в фоновом режиме.

Конструктор позволяет задать имя потока, которое используется при создании таймера для формирования уникального имени объекта EME-L-класса. Метод `StartTimer` запускает таймер с указанием интервала в миллисекундах, имени класса, имени метода и текстового описания. Метод `StopTimer` останавливает таймер и освобождает ресурсы потока. Метод `Trace` включает или отключает трассировку выполнения метода в журнале катастрофических событий.

> **Важно:** в отличие от многих классов, деструктор `TimerThread` **не останавливает** запущенный таймер и не удаляет объект потока. Для корректного завершения работы необходимо явно вызвать `StopTimer()`.

## Создание объекта

Класс `TimerThread` имеет два конструктора — без аргументов и с одним необязательным аргументом.

```EME-L
'Таймер без имени потока — имя объекта будет сформировано как "ClassName."
objTimer = Object("TimerThread");

'Таймер с именем потока — имя объекта будет "ClassName.MyThread"
objTimer = Object("TimerThread", "MyThread");
```

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `threadName` | String | Нет | Имя потока таймера. Используется при формировании уникального имени объекта EME-L-класса при вызове `StartTimer`. По умолчанию — пустая строка. |

## Управление таймером

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `StartTimer(interval, className, methodName[, description])` | `interval`: Integer, `className`: String, `methodName`: String, `description`: String | Empty или Integer | Запускает таймер в отдельном потоке выполнения. При успешном запуске возвращает пустое значение. Если таймер уже был запущен, возвращает `-1`. |
| `StopTimer()` | — | Integer | Останавливает таймер и удаляет объект потока. При успешной остановке возвращает `0`. Если таймер не был запущен, возвращает `-1`. |
| `Trace(enable)` | `enable`: Boolean | Integer | Включает (`True`) или отключает (`False`) трассировку выполнения метода таймера в журнале катастрофических событий. Возвращает `0`. Если таймер не запущен, вызов игнорируется. |

### Параметры StartTimer

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `interval` | Integer | Да | Интервал срабатывания таймера в миллисекундах. Должен быть больше `0`. |
| `className` | String | Да | Имя EME-L-класса, объект которого будет создан и чей метод будет вызываться. |
| `methodName` | String | Да | Имя метода указанного класса для периодического вызова. |
| `description` | String | Нет | Текстовое описание таймера для журналирования. По умолчанию — `"<UNKNOWN>"`. |

### Имя создаваемого объекта

При запуске таймера внутри создаётся объект EME-L-класса `IClass` с именем, составленным из имени класса и имени потока:

```EME-L
'Если threadName = "MyThread", а className = "MyTimerClass",
'внутри будет создан объект с именем "MyTimerClass.MyThread"
objTimer = Object("TimerThread", "MyThread");
objTimer.StartTimer(60000, "MyTimerClass", "OnTimer", "Фоновая задача");
```

Если имя потока не задано, имя объекта заканчивается точкой (`"ClassName."`). Это имя используется только внутри движка; из скрипта EME-L объект таймера управляется через переменную, в которой сохранена ссылка.

## Примеры

Минимальный таймер, вызывающий метод `OnTimer` класса `MyBackgroundClass` раз в минуту:

```EME-L
'Создаём таймер с именем потока для уникальности объекта
objTimer = Object("TimerThread", "BackgroundSync");

'Запускаем вызов OnTimer каждые 60 секунд
objTimer.StartTimer(60000, "MyBackgroundClass", "OnTimer", "Синхронизация остатков");

'Включаем трассировку — в журнал будут писаться начало/конец каждого вызова
objTimer.Trace(True);

'Позже, при завершении работы, останавливаем таймер явно
objTimer.StopTimer();
```

Проверка состояния перед запуском и корректная остановка:

```EME-L
objTimer = Object("TimerThread");

'Если таймер уже запущен, StartTimer вернёт -1
result = objTimer.StartTimer(30000, "HeartbeatClass", "Ping", "Heartbeat");
If (result = -1)
    is_message(tr("Внимание"), tr("Таймер уже запущен"), 1, 1);
    Return;
End If

'...по завершении работы
If (objTimer.StopTimer() = 0)
    'Таймер остановлен
End If
```

## Особенности поведения

- Первый вызов метода происходит **сразу** после запуска таймера (`OnPostCreate`), до первого срабатывания таймера. После этого метод вызывается с заданным интервалом.
- Метод таймера выполняется в отдельном потоке, поэтому внутри него должны соблюдаться правила потокобезопасности: использование семафоров (`Semaphore`), атомарных операций (`Atom`) и транзакций при записи в базу данных.
- `StopTimer` возвращает `0` только если таймер был запущен. После остановки повторный запуск на том же объекте `TimerThread` **может не сработать** из-за того, что внутренний флаг состояния не сбрасывается в деструкторе. Рекомендуется создавать новый объект `TimerThread` для каждого цикла запуска/остановки.
