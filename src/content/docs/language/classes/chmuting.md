# Класс Chmuting

Класс `Chmuting` в языке EME-L выполняет высокоуровневую процедуру проверки и коррекции целостности данных (чмутинг). Предоставляет механизм выборочной или полной проверки записей базы данных в соответствии с настройками, хранящимися в записях `Chmuting` и `ChmutingVolume`. Поддерживает выбор тома проверки, фильтрацию обрабатываемых записей по отдельности или массово, а также управление отображением некорректных строк в дамп.

Объект класса `Chmuting` создаётся через `Object()` и привязан к контексту выполнения и объекту-контейнеру — без валидного контекста конструктор генерирует ошибку.

## Создание объекта

```EME-L
'Без явного контейнера — контекст определяется автоматически'
objChm = Object("Chmuting");

'С явным объектом-контейнером'
objChm = Object("Chmuting", rContainer);
```

Конструктор без аргументов определяет объект-контейнер из текущего контекста выполнения и генерирует ошибку, если контекст не задан. Конструктор с одним аргументом принимает ссылку на объект-контейнер, в контексте которого будет выполняться чмутинг. При создании инициализируется внутренний битовый массив для отслеживания используемых строк настроек чмутинга, а выражение отображения некорректных строк устанавливается в значение по умолчанию `"1"`.

## Выбор тома и настройка записей

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetVolume(arg0)` | arg0: String (имя тома) | Empty | Устанавливает том чмутинга по имени, загружая настройки из записи `ChmutingVolume`. Сбрасывает внутренний битовый массив выбранных строк. Если том не найден — генерирует ошибку. |
| `CheckRecord(arg0, arg1)` | arg0: String (идентификатор записи), arg1: Boolean | Empty | Включает или исключает отдельную запись из операции чмутинга для текущего тома. `arg1=TRUE` — включить, `FALSE` — исключить. Если том не задан — генерирует ошибку. |
| `CheckAllRecords(arg0)` | arg0: Boolean | Empty | Включает или исключает все записи текущего тома сразу. `arg0=TRUE` — включить все, `FALSE` — исключить все. Если том не задан — генерирует ошибку. |

## Управление отображением и запуск

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `ShowBad(arg0)` | arg0: Boolean | Empty | Управляет отображением некорректных строк в дамп при выполнении чмутинга. `TRUE` — показывать плохие строки (выражение `"1"`), `FALSE` — скрывать (выражение `"0"`). |
| `Run(arg0)` | arg0: Boolean (режим коррекции) | Integer | Выполняет процедуру чмутинга для выбранного тома с учётом установленных битов. `TRUE` — чмутинг с коррекцией данных, `FALSE` — только проверка. Если том не задан — генерирует ошибку. |

## Порядок вызова

Типичный сценарий: создать объект, установить том через `SetVolume`, настроить набор проверяемых записей через `CheckRecord` (выборочно) или `CheckAllRecords` (массово), при необходимости включить отображение плохих строк через `ShowBad`, затем запустить процедуру методом `Run`.

## Примеры

Проверка целостности всех записей тома (только режим проверки, без коррекции):

```EME-L
'Создать объект чмутинга в текущем контексте'
objChm = Object("Chmuting");
objChm.SetVolume("Main");
objChm.CheckAllRecords(TRUE);
Result = objChm.Run(FALSE);
'Result — код результата выполнения чмутинга'
```

Выборочная проверка с коррекцией и отображением плохих строк:

```EME-L
objChm = Object("Chmuting", rContainer);
objChm.SetVolume("Archive");
objChm.CheckRecord("DOC_HEADER", TRUE);
objChm.CheckRecord("DOC_LINES", TRUE);
objChm.ShowBad(TRUE);
Result = objChm.Run(TRUE);
'Result — код результата, плохие строки выведены в дамп'
```
