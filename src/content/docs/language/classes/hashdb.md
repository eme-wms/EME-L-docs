# Класс HashDB

Класс `HashDB` в языке EME-L — класс для работы с распределённой хеш-базой данных (хеш-БД). Предоставляет интерфейс для добавления, поиска, изменения и удаления ключей в хеш-БД с поддержкой модульной адресации (до 64 модулей) и контроля срока жизни ключей.

Класс позволяет формировать ключи из массивов параметров или из строк, устанавливать срок жизни ключей в днях, ограничивать максимальные значения числовых показателей, а также выполнять пакетные операции добавления (`RequestAdd`), установки (`RequestSet`) и поиска (`RequestFind`) для набора предварительно добавленных ключей. Поддерживает сериализацию данных в бинарные файлы `.hdb` с последующей загрузкой.

Используется для организации высокопроизводительного доступа к данным по ключу в многомодульных системах, где требуется быстрый поиск и контроль целостности значений с автоматическим удалением устаревших ключей. Типичный потребитель в системе EME.WMS — учёт грузовых мест (SSCC, короба, PDF, QR, дата-матрицы) по модулям: приход, остатки, агрегация.

Объект класса `HashDB` создаётся через `Object()`. Адрес и порт сервера хеш-БД либо берутся из системных настроек модулей «Система.Хеш-БД.IP адрес» и «Система.Хеш-БД.Порт» (конструктор без аргументов), либо задаются явно вторым конструктором. Все операции выполняются относительно установленных параметров подключения и номера модуля.

## Создание объекта

Класс `HashDB` имеет два конструктора.

```EME-L
'Конструктор без аргументов — адрес и порт из системных настроек'
objHash = Object("HashDB");
```

```EME-L
'Конструктор с явным адресом сервера и портом'
objHash = Object("HashDB", "192.168.1.10", 50001);
```

Конструктор без аргументов создаёт объект с параметрами подключения по умолчанию, которые читаются из системных настроек модулей «Система.Хеш-БД.IP адрес» и «Система.Хеш-БД.Порт».

## Параметры подключения и модуля

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetModuleNo(arg0)` | arg0: Integer | Empty | Устанавливает номер модуля. Допустимый диапазон: 1..64. При выходе за диапазон генерируется ошибка выполнения. |
| `SetKeyLifeTime(arg0)` | arg0: Integer | Empty | Устанавливает срок жизни ключа в днях. Срок годности вычисляется как текущая дата плюс срок жизни; по истечении ключ удаляется автоматически. Значение должно быть не менее 1. |
| `SetKeyMaxLength(arg0)` | arg0: Integer | Empty | Устанавливает максимальную длину ключа. Значение должно быть не менее 1. |
| `SetCreateKey(arg0)` | arg0: Boolean | Empty | Управляет режимом добавления новых ключей. `TRUE` (по умолчанию) — новые ключи создаются при отсутствии в хеш-БД, `FALSE` — игнорируются. |
| `SetDebugMode(arg0)` | arg0: Boolean | Empty | Включает (`TRUE`) или выключает (`FALSE`) режим диагностики. При включении лог записывается в файл `CATASTRF.LOG`. |
| `GetModuleNo()` | — | Integer | Номер модуля, установленный для объекта. |
| `GetKeyLifeTime()` | — | Integer | Срок жизни ключа в днях. |
| `GetKeyMaxLength()` | — | Integer | Максимальная длина ключа. |
| `IsCreateKey()` | — | Boolean | Текущий режим создания ключей. `TRUE` — новые ключи добавляются, `FALSE` — игнорируются. |
| `GetDBError()` | — | String | Описание ошибки хеш-БД, возникшей при последнем запросе. Пустая строка, если ошибок не было. |
| `SetDBError(arg0)` | arg0: String | Empty | Устанавливает текстовое описание ошибки хеш-БД для объекта. |

## Добавление ключей

Ключи формируются из строки или из массива параметров (`CIArray`) и накапливаются во внутреннем списке объекта до выполнения пакетного запроса. При передаче пустого массива генерируется ошибка выполнения.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddKey(arg0)` | arg0: String или Array (по ссылке) | Empty | Добавляет ключ без значения и ограничения. arg0 — строковый ключ либо массив параметров `CIArray` для составного ключа. |
| `AddKey(arg0, arg1, arg2)` | arg0: String/Array, arg1: Real, arg2: Real | Empty | Добавляет ключ со значением и максимальным ограничением. arg2 не может быть меньше arg1. |
| `AddKey(arg0, arg1, arg2[, arg3])` | + arg3: Integer | Empty | То же со ссылкой на связанный объект. arg3 по умолчанию — пустая ссылка (`NULL_REF`). |
| `AddKey(arg0, arg1, arg2[, arg3[, arg4]])` | + arg4: Integer | Empty | Полный набор параметров. arg4 — код ошибки ключа (по умолчанию 0). |

Параметр arg4 (код ошибки ключа) принимает значения: `0` — ошибок нет, `1` — ключ не найден, `2` — превышено максимальное значение, `3` — запрещено добавлять новый ключ.

## Пакетные запросы

Методы выполняют операцию над всеми ключами, добавленными методом `AddKey` после последнего вызова `Clear`. Возвращают `Boolean` — результат выполнения запроса.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `RequestAdd()` | — | Boolean | Добавление или вычитание значений. Если ключ отсутствует в хеш-БД — создаётся и инициализируется параметрами `AddKey`. Если существует — изменяется только значение; ссылка, срок годности и другие параметры не затрагиваются. |
| `RequestSet()` | — | Boolean | Установка параметров ключей. Если ключ уже существует — все его параметры перезаписываются. |
| `RequestFind()` | — | Boolean | Поиск ключей. Результат доступен через перебор списка методами `SetFirstLine` / `SetNextLine` / `IsValidLine` и проверки `IsKeyFound`. |

## Перебор ключей и получение данных

После выполнения запроса результат доступен через навигацию по внутреннему списку ключей.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetFirstLine()` | — | Empty | Устанавливает внутренний индекс на первый ключ. |
| `SetNextLine()` | — | Empty | Перемещает индекс на следующий ключ. |
| `IsValidLine()` | — | Boolean | `TRUE` — индекс указывает на корректный ключ, `FALSE` — выход за границы списка. |
| `GetNoOfLines()` | — | Integer | Количество ключей в текущем списке. |
| `GetKey()` | — | String или Empty | Идентификатор текущего ключа в виде строки. При невалидном индексе — `Empty`. |
| `GetKey(arg0, arg1, arg2, arg3)` | arg0: Array (по ссылке), arg1–arg3: переменные по ссылке | Empty | Записывает данные текущего ключа в переданные переменные: arg0 — составные части ключа в `CIArray`, arg1 — значение, arg2 — максимальное значение, arg3 — ссылка. При невалидном индексе переменные не изменяются. |
| `GetKeyError()` | — | Integer | Код ошибки текущего ключа: `0` — нет ошибок, `1` — ключ не найден, `2` — превышено максимальное значение, `3` — запрещено добавлять новый ключ. |

## Проверки состояния ключа

Методы возвращают `Empty` при невалидном внутреннем индексе; при валидном — `Boolean`.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `IsNoError()` | — | Boolean/Empty | `TRUE` — при последней операции с текущим ключом ошибок не возникло. |
| `IsKeyFound()` | — | Boolean/Empty | `TRUE` — текущий ключ найден в хеш-БД. |
| `IsValueExcess()` | — | Boolean/Empty | `TRUE` — при последнем `RequestAdd` значение превысило максимальное. |
| `IsCreateKey()` | — | Boolean | `TRUE` — режим добавления новых ключей включён. Не зависит от индекса. |

## Сериализация в файлы

Сохранение и загрузка используются для разделения клиентской и серверной частей обмена с хеш-БД: клиент накапливает ключи, сериализует их в файлы, сервер загружает и применяет.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SaveFiles(arg0)` | arg0: String (каталог) | Empty | Сохраняет ключи в бинарные файлы `.hdb`. В один файл записывается до 100 000 ключей; при превышении ключи разбиваются на несколько файлов. Имена файлов генерируются автоматически. В файл записываются номер модуля, срок жизни, длина ключа, ключ, значение и ссылка. |
| `LoadFiles(arg0)` | arg0: String (каталог) | Empty | Загружает все файлы `.hdb` из каталога. После успешной загрузки каждый файл удаляется. Для каждого загруженного набора вызывается емельный метод `SetValue` класса, указанного в запросе (по умолчанию `HashDBEmulator`), для записи ключей в БД. |
| `Clear()` | — | Empty | Очищает список добавленных ключей и сбрасывает внутренние параметры объекта. |

## Константы

Диапазон номера модуля — от 1 до 64 включительно. Максимальное число ключей в одном `.hdb`-файле при сериализации — 100 000. Расширение файлов сериализации — `.hdb`. Файл диагностического лога при включённом режиме отладки — `CATASTRF.LOG`.

## Примеры

Установка значений набора ключей с ограничением и сроком жизни:

```EME-L
objHash = Object("HashDB");
objHash.SetModuleNo(1);
objHash.SetKeyLifeTime(365);
objHash.SetKeyMaxLength(64);

objHash.AddKey("SSCC-001", 1.0, 1.0);
objHash.AddKey("SSCC-002", 1.0, 1.0);

Result = objHash.RequestSet();
If (~Result)
    LastError = objHash.GetDBError();
End If
```

Поиск ключей и перебор результата:

```EME-L
objHash.AddKey("SSCC-001");
objHash.AddKey("SSCC-002");

Result = objHash.RequestFind();
If (Result)
    objHash.SetFirstLine();
    While (objHash.IsValidLine())
        If (objHash.IsKeyFound())
            KeyId = objHash.GetKey();
        End If
        objHash.SetNextLine();
    End While
End If
```
