# Класс VendorEnhancement

Класс `VendorEnhancement` в языке EME-L — это класс-интерфейс для работы с таблицей дополнительных соответствий организаций (вендоров). Предоставляет доступ к специфичным для конкретной организации настройкам соответствия между кодами SAP и внутренними статусами/локейшенами системы EME.

Основные возможности класса `VendorEnhancement` в языке EME-L:

- Преобразование пар SAP-локейшен + SAP-статус в складской статус EME и обратно.
- Получение кодов движений (Movement Type) и транзакций (Transaction Code) SAP по начальным и конечным статусам/локейшенам.
- Получение произвольных кодов из таблицы дополнительных соответствий по ключу.
- Автоматическая настройка на организацию с контролем актуальности кэшированных данных.

Данные загружаются из таблицы `VendorEnhancement` (код записи «Дополнительные соответствия») и кэшируются в памяти с отслеживанием изменений по штампу записи организации. Используется в интеграционных сценариях обмена с SAP и другими внешними системами в системе EME.WMS.

> Объект `VendorEnhancement` не предназначен для прямого редактирования таблицы соответствий — это объект только для чтения. Изменение настроек вендора выполняется через справочник «Дополнительные соответствия» (запись таблицы `VendorEnhancement`).

## Создание объекта

Класс `VendorEnhancement` создаётся через `Object()` без аргументов. Перед использованием методов необходимо вызвать `TuneVendorIfNeed`, чтобы настроить объект на организацию и загрузить актуальные соответствия.

```EME-L
'Создание объекта настройки вендора'
Vendor_Obj = Object("VendorEnhancement");

'Настройка на организацию по ссылке на запись Clients'
Vendor_Obj.TuneVendorIfNeed(rVendor.GetLine());
```

Конструктор без аргументов создаёт объект, связанный с общим кэшем таблицы дополнительных соответствий. Все вызовы методов выполняются относительно последней настроенной организации.

## Методы

### Настройка

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `TuneVendorIfNeed(nVendorRef)` | arg0: Integer | Empty | Выполняет настройку объекта на указанную организацию (вендора), если текущая настройка устарела или отсутствует. Проверяет актуальность кэшированных данных по штампу записи организации и при необходимости перезагружает внутренние карты соответствий из таблицы `VendorEnhancement`. |

### Соответствия статусов и локейшенов (ключ `SLOC`)

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetStatusFromLocation(szLocation, szSAPStatus)` | arg0: String (SAP-локейшен), arg1: String (SAP-статус) | String | Возвращает односимвольный складской статус системы EME (например, `'U'`, `'B'`, `'Q'`) по паре SAP-локейшен и SAP-статус. Возвращает пустую строку, если соответствие не найдено. |
| `GetLocationFromStatus(szStatus, szWarehouseOrReason)` | arg0: String (складской статус EME), arg1: String or Integer (тип склада или ризон-код) | String | Возвращает SAP-локейшен по складскому статусу EME и типу склада (или ризон-коду). Если `arg1` — целое число, `0` трактуется как склад брака (`BADSTOCK`), любое ненулевое значение — как основной склад (`PRIMESTOCK`). Возвращает пустую строку, если соответствие не найдено. |
| `GetSAPStatusFromStatus(szStatus, szWarehouseOrReason)` | arg0: String (складской статус EME), arg1: String or Integer (тип склада или ризон-код) | String | Возвращает односимвольный SAP-статус по складскому статусу EME и типу склада. Если `arg1` — целое число, `0` трактуется как склад брака (`BADSTOCK`), любое ненулевое значение — как основной склад (`PRIMESTOCK`). Если соответствие не найдено, возвращает значение по умолчанию `'B'` (блокирован). |

### Коды движений и транзакций (ключ `MVT`)

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetMvtCode(szFrom, szTo)` | arg0: String (начальный статус или локейшен), arg1: String (конечный статус или локейшен) | String | Возвращает код движения SAP (Movement Type) по начальному и конечному параметрам. Если передано числовое значение, отличное от `0`, автоматически подставляется ключ `SLOC`. Возвращает пустую строку, если соответствие не найдено. |
| `GetTrsCode(szFrom, szTo)` | arg0: String (начальный статус или локейшен), arg1: String (конечный статус или локейшен) | String | Возвращает код транзакции SAP (Transaction Code) по начальному и конечному параметрам. Если передано числовое значение, отличное от `0`, автоматически подставляется ключ `SLOC`. Возвращает пустую строку, если соответствие не найдено. |

### Произвольные коды (ключ `SIMP`)

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetSimpleCode(szKey)` | arg0: String (ключ поиска) | String | Возвращает значение произвольного кода (третье поле таблицы) по ключу (второму полю таблицы). Возвращает пустую строку, если соответствие не найдено. |

## Константы и внутренние ключи таблицы

Таблица дополнительных соответствий (`VendorEnhancement`, код записи «Дополнительные соответствия») различает записи по значению первого поля. Внутренние ключи, используемые классом `VendorEnhancement` в системе EME.WMS:

| Ключ | Назначение |
|------|------------|
| `SLOC` | Соответствия между SAP-локейшеном + SAP-статусом и складским статусом/локейшеном EME. |
| `MVT` | Соответствия между начальным и конечным статусом/локейшеном и кодом движения/транзакции SAP. |
| `SIMP` | Произвольные коды: поиск по ключу (второе поле) возвращает значение (третье поле). |
| `FUNC` | Зарезервированный ключ для апплетов/обработчиков (не используется через публичные методы класса). |
| `PRIMESTOCK` | Основной склад; используется как значение по умолчанию, когда целочисленный аргумент `szWarehouseOrReason` не равен `0`. |
| `BADSTOCK` | Склад брака; используется как значение по умолчанию, когда целочисленный аргумент `szWarehouseOrReason` равен `0`. |
| `U` / `B` / `Q` | Типичные односимвольные складские статусы EME, возвращаемые `GetStatusFromLocation`. |
| `B` | Значение SAP-статуса по умолчанию для `GetSAPStatusFromStatus`, если соответствие не найдено. |

## Примеры

Проверка произвольной настройки вендора (паттерн из `Document.txt`):

```EME-L
'Получить объект настройки вендора'
Vendor_Obj = Object("VendorEnhancement");

'Настроиться на организацию из текущей строки документа'
Vendor_Obj.TuneVendorIfNeed(rVendor.GetLine());

'Проверить, включена ли схема периодов'
If (Vendor_Obj.GetSimpleCode("USE_PERIOD_SCHEME") == "")
    Return 0;
End If
```

Корректировка даты с учётом настройки вендора (паттерн из `EANCOM.txt`):

```EME-L
'Создать и настроить объект вендора'
Vendor_Obj = Object("VendorEnhancement");
Vendor_Obj.TuneVendorIfNeed(VendorRef);

UsePeriodScheme = False;

'Проверить флаг использования периодической схемы'
If (Vendor_Obj.GetSimpleCode("USE_PERIOD_SCHEME") == "ON")
    UsePeriodScheme = True;
End If
```

Получение SAP-статуса по складскому статусу и типу склада:

```EME-L
Vendor_Obj = Object("VendorEnhancement");
Vendor_Obj.TuneVendorIfNeed(rVendor.GetLine());

'Основной склад: szWarehouseOrReason не равен 0'
SAPStatus = Vendor_Obj.GetSAPStatusFromStatus("U", 1);
'SAPStatus — односимвольный SAP-статус или "B" по умолчанию'

'Склад брака: szWarehouseOrReason равен 0'
SAPStatusBad = Vendor_Obj.GetSAPStatusFromStatus("U", 0);
```

Получение кода движения между статусами/локейшенами:

```EME-L
Vendor_Obj = Object("VendorEnhancement");
Vendor_Obj.TuneVendorIfNeed(rVendor.GetLine());

'Код движения из статуса в статус'
MvtCode = Vendor_Obj.GetMvtCode("U", "B");

'Код движения с числовой подстановкой SLOC (число не 0)'
MvtCodeSLoc = Vendor_Obj.GetMvtCode("1", "B");
```
