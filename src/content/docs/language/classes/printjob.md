# Класс PrintJob

Класс `PrintJob` в языке EME-L — класс для формирования и выполнения групповой печати документов на принтер. Позволяет создать пакет печати, задать имя принтера, добавить файлы (PDF и другие), настроить параметры печати (количество копий, ориентация, двусторонняя печать, скрепление) и отправить задание на печать напрямую, через драйвер Windows или с использованием библиотеки Mupdf (в текущей реализации режим Mupdf не реализован). Также предоставляет текст последней ошибки, позволяет задавать имя задания и объединять несколько PDF-файлов в один.

Объект класса `PrintJob` создаётся через `Object()` без аргументов и не привязан к контексту диалога или браузера. Это самостоятельный класс для управления печатью: после создания объект накапливает пакет файлов и общие параметры, а запуск печати выполняется одним вызовом `Execute`.

Используется в прикладных скриптах EME-L для пакетной печати комплектов документов — например, сертификатов, деклараций и сопроводительных листов, экспортированных в PDF.

## Создание объекта

Класс `PrintJob` имеет один конструктор — без аргументов.

```EME-L
'Создать объект группового задания печати'
r_PrintJob = Object("PrintJob");
```

После создания у объекта нет ни принтера, ни файлов в пакете — всё задаётся методами ниже.

## Настройка задания

Методы для задания общих параметров пакета печати.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetPrinterName(arg0)` | arg0: String (имя принтера) | Boolean | TRUE — имя принтера задано, FALSE — ошибка. Если метод не вызывать, используется принтер по умолчанию системы. |
| `SetJobName(arg0)` | arg0: String (имя задания) | Boolean | Контракт: задаёт имя пакета печати. Всегда возвращает TRUE. **Внимание:** в текущей реализации фактическая установка имени отключена (подозрение, что ломает печать) — вызов игнорируется. |
| `SetStaple(arg0)` | arg0: Integer (режим скрепления) | Boolean | TRUE — режим установлен, FALSE — ошибка. Допустимые значения `arg0`: 0 — без скрепления, 1 — одна скрепка, 2 — скрепка в углу, 3 — две скрепки, 4 — три скрепки, 5 — шесть скрепок. |
| `SetAddBlankPageForDuplexPrint(arg0)` | arg0: Boolean (добавлять пустую страницу) | Empty | **Не реализован.** При вызове генерируется ошибка «функция не реализована». Возврат — пустое значение. |

## Наполнение пакета

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddFileToJob(arg0)` | arg0: String (полный путь к файлу) | Boolean | Добавляет файл в пакет с параметрами по умолчанию: 1 копия, книжная ориентация, односторонняя печать, конвертация в PDF включена. TRUE — файл добавлен, FALSE — ошибка. |
| `AddFileToJob(arg0, arg1)` | + arg1: Integer (копии) | Boolean | То же с явным числом копий. По умолчанию 1. |
| `AddFileToJob(arg0, arg1, arg2)` | + arg2: Integer (ориентация) | Boolean | То же с ориентацией: 0 — книжная (по умолчанию), 1 — альбомная. |
| `AddFileToJob(arg0, arg1, arg2, arg3)` | + arg3: Integer (режим печати) | Boolean | То же с режимом печати: 0 — на одной стороне листа (по умолчанию), 1 — на двух сторонах. |
| `AddFileToJob(arg0, arg1, arg2, arg3, arg4)` | + arg4: Boolean (конвертация в PDF) | Boolean | То же с явным флагом необходимости конвертации файла в PDF перед печатью. По умолчанию TRUE. |

## Запуск печати и диагностика

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Execute()` | — | Boolean | Запускает печать сформированного пакета в режиме по умолчанию (0 — прямая печать PDF). TRUE — печать выполнена, FALSE — ошибка. |
| `Execute(arg0)` | arg0: Integer (режим) | Boolean | Запускает печать в заданном режиме: 0 — прямая печать PDF (обход драйвера Windows), 1 — печать через драйвер Windows, 2 — режим Mupdf (**не реализован**, генерируется ошибка). Значения меньше 0 воспринимаются как режим 1 для совместимости со старыми скриптами, где параметр передавался как TRUE/FALSE (TRUE в EME-L равно -1). |
| `GetLastError()` | — | String | Текстовое описание последней ошибки. Пустая строка, если ошибок не было. |

## Объединение PDF

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `ConvertAndUnitePDFFiles(arg0)` | arg0: Array (по ссылке, массив путей к PDF) | String | Преобразует переданные PDF-файлы и объединяет их в один результирующий PDF. Возвращает полный путь к объединённому файлу. |

## Примеры

Пакетная печать нескольких экспортированных PDF на принтер по умолчанию:

```EME-L
r_PrintJob = Object("PrintJob");
r_PrintJob.SetJobName("Пакетная печать EME.WMS.");
'Третий аргумент — ориентация (0 — книжная);'
'четвёртый — режим печати (1 — двусторонняя)'
r_PrintJob.AddFileToJob(strCertFile, 1, 0, 1);
r_PrintJob.AddFileToJob(strDeclFile, 1, 0, 1);
'Односторонняя печать комплекта'
r_PrintJob.AddFileToJob(strOrgFile, 1, 0, 0);
r_PrintJob.Execute(0);
err = r_PrintJob.GetLastError();
If (err != "")
    ArrayErrors.Add(err);
End If
```

Объединение нескольких PDF в один файл:

```EME-L
arrPdfs = Object("Array");
arrPdfs.Add("D:\\Data\\doc1.pdf");
arrPdfs.Add("D:\\Data\\doc2.pdf");
r_PrintJob = Object("PrintJob");
strUnited = r_PrintJob.ConvertAndUnitePDFFiles(arrPdfs);
'strUnited — полный путь к объединённому PDF'
```
