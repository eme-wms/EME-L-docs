# Класс ServerJob

Класс `ServerJob` в языке EME-L — клиент для отправки и управления заданиями на HTTP-сервере транзакций и обычном HTTP-сервере. Предоставляет механизм удалённого выполнения методов EME-L-классов на сервере через очередь заданий.

Поддерживает два типа заданий: **REPORT** (отчёты, выполняемые без открытия транзакции) и **TRANSACTION** (транзакционные операции с базой данных). Задания ставятся в очередь на сервере, выполняются последовательно или параллельно в зависимости от настроек, а результаты возвращаются на рабочую станцию по запросу.

Класс позволяет отправлять задания с произвольным набором аргументов (включая сериализуемые объекты), получать статус выполнения, номер в очереди, результат и значения возвращаемых переменных. Поддерживает расширенные режимы выполнения: `TRANSACTION:SHARE` (общая транзакция для нескольких заданий) и `TRANSACTION:BATCH` (пакетное выполнение с массивом параметров).

Включает средства для получения журнала сервера заданий и журнала отдельного задания в виде объектов `Query`, установки лимитов на количество одновременно выполняемых заданий, отмены заданий и управления режимом параллельного выполнения транзакционных заданий.

Используется для выноса длительных вычислений и отчётов на сервер, разгрузки рабочей станции и организации фоновой обработки данных в системе EME.

Объект класса `ServerJob` создаётся через `Object()`. Адрес сервера и порты определяются автоматически при вызове без аргументов, либо задаются явно. Класс является клиентским — он отправляет HTTP-запросы на сервер заданий, где проживает исполнительный поток, опрашивающий очередь раз в секунду.

## Создание объекта

Класс `ServerJob` имеет четыре конструктора — по числу аргументов от 0 до 3.

```EME-L
'Без аргументов: автоопределение адреса и портов сервера в сети'
objJob = Object("ServerJob");
```

```EME-L
'Только IP-адрес: порт запросов по умолчанию 80, порт транзакций равен ему'
objJob = Object("ServerJob", "192.168.1.100");
```

```EME-L
'IP-адрес и порт запросов: порт транзакций принимается равным порту запросов'
objJob = Object("ServerJob", "192.168.1.100", 8080);
```

```EME-L
'IP-адрес, порт запросов и порт транзакций — для раздельных серверов'
objJob = Object("ServerJob", "192.168.1.100", 8080, 8081);
```

При вызове без аргументов адрес и порты определяются автоматически поиском HTTP-сервера транзакций в сети. Если в сети не обнаружен HTTP-сервер транзакций, генерируется ошибка. Конструкторы с аргументами отправляют задание на обычный порт — на указанном сервере обязательно должен быть запущен HTTP-сервер транзакций. Таймаут запросов по умолчанию равен **5000 мс** (можно изменить методом `SetTimeout`).

## Отправка задания

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetTimeout(arg0)` | arg0: Integer | Empty | Таймаут запросов к серверу в миллисекундах. По умолчанию 5000 мс. |
| `SendJob(arg0, arg1, arg2, arg3, arg4[, argN…])` | arg0: String (тип), arg1: String (имя), arg2: Parameters (необязательный), arg3: String (класс), arg4: String (метод), argN: произвольный | Integer | Отправляет задание в очередь. Возвращает идентификатор: чётный для REPORT, нечётный для TRANSACTION. -1 при ошибке отправки. Минимальное число аргументов — 5 (тип, имя, класс, метод и хотя бы ноль аргументов вызова); при `argn < 4` ядро генерирует «слишком мало аргументов». |

### Тип задания (первый аргумент SendJob)

| Значение | Описание |
|----------|----------|
| `"REPORT"` | Задание отчёта. Не должно открывать транзакцию. Выполняется на обычном HTTP-сервере. |
| `"TRANSACTION"` | Транзакционное задание. Выполняется на сервере транзакций последовательно. |
| `"TRANSACTION:SHARE"` | Несколько заданий в одной общей транзакции. Само задание не должно открывать и закрывать транзакцию. |
| `"TRANSACTION:BATCH"` | Пакетное выполнение. Параметры передаются массивом; задание может иметь только один параметр. |

### Параметры задания (третий аргумент SendJob, объект Parameters)

| Имя | Тип | По умолчанию | Описание |
|-----|-----|-------------|----------|
| `LIFELENGTH` | Integer | 60 | Время хранения задания после выполнения, в минутах. |
| `SILENT` | Boolean | FALSE | Подавить уведомления о выполнении задания. |

Для совместимости третий аргумент может быть целым числом — тогда он трактуется как `LIFELENGTH`.

## Статус и очередь

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetJobStatus(arg0)` | arg0: Integer или String | Integer или Empty | Статус задания: 0 — Создано, 1 — В очереди, 2 — Выполняется, 3 — Выполнено, 4 — Закрыто, 5 — Ошибка. Empty — задание не найдено. |
| `GetStatusAsString(arg0)` | arg0: Integer | String | Текстовое описание статуса на русском: «Создано», «В очереди», «Выполняется», «Выполнено», «Закрыто», «Ошибка», «Неизвестно». |
| `GetJobQueue(arg0)` | arg0: Integer или String | Integer или Empty | Позиция в очереди (нумерация с 0). Отрицательное число — задание выполнено. Empty — не найдено. |
| `GetJobLength(arg0)` | arg0: Integer или String | Integer или Empty | «Чистая» продолжительность выполнения в мс без учёта записи результатов. 0 — ещё не выполнено. Empty — не найдено. |
| `IsJobsComplete(arg0)` | arg0: Integer, String или Array | Boolean | TRUE — задание (или все задания из массива) выполнено. При неверном номере генерирует исключение. |
| `CancelJob(arg0)` | arg0: Integer или String | Boolean или Empty | TRUE — успешно отменено. Empty — задание не найдено или уже выполнено. Поведение зависит от состояния: при статусе моложе «Выполняется» задание переводится в «Ошибка» с результатом «Выполнение задания отменено»; если поток уже начал выполнение, ядро пытается остановить его через `SetStopExecution(TRUE)` (версия ядра ≥ 46.0) и возвращает TRUE, если поток найден. |

## Идентификация и поиск

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetJobId(arg0)` | arg0: String (номер `dd-hh:mm-NNNNNN`) | Integer | Числовой идентификатор по номеру. Статический метод, не обращается к серверу. |
| `GetJobNo(arg0)` | arg0: Integer (идентификатор) | String или Empty | Номер в формате `dd-hh:mm-NNNNNN` по идентификатору. Empty — не найдено. |
| `GetJobName(arg0)` | arg0: Integer или String | String или Empty | Имя задания по идентификатору или номеру. Empty — не найдено. |
| `FindJob(arg0, arg1)` | arg0: String (тип), arg1: String (имя) | Integer | Идентификатор по типу и имени. -1 — не найдено. Тип: `"TRANSACTION"` или `"REPORT"`. |

## Результат выполнения

Основной результат — это значение, возвращённое исполнительным методом. Для получения нескольких значений используйте `GetJobReturnValue` и `EnumJobReturnValues`. Переменные результата должны быть определены в конструкторе вызываемого класса как `AsExternal`.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetJobResult(arg0)` | arg0: Integer или String | Number/String или Empty | Основной результат (число или строка). Объекты не возвращаются. Empty — не найдено или не выполнено. |
| `GetJobReturnValue(arg0, arg1)` | arg0: Integer/String, arg1: String | Number/String или Empty | Значение переменной по имени. Только простые типы. Empty — недоступно. Если объект задания временно недоступен (другой поток читает результат), сервер вместо возврата данных записывает в `m_csResult` строку «Задание временно недоступно. Попробуйте позже» — её возвращает `GetLastError`, а `GetJobReturnValue` вернёт Empty. |
| `GetJobReturnValue(arg0, arg1, arg2)` | + arg2: Boolean | произвольный тип или Empty | То же с возвратом объектов (массив, мапа, запрос, сериализуемый класс). arg2 по умолчанию FALSE. Вызывать до `Close`. |
| `GetJobReturnType(arg0, arg1)` | arg0: Integer/String, arg1: String | String или Empty | Тип значения переменной результата. Empty — недоступно. |
| `EnumJobReturnValues(arg0)` | arg0: Integer или String | Array или Empty | Массив имён переменных с результатами. Вызывать до `Close`. |
| `GetLastError(arg0)` | arg0: Integer или String | String или Empty | «OK» при успехе, текст ошибки при ошибке, Empty — задание не найдено. |
| `Close(arg0)` | arg0: Integer или String | Boolean | Переводит в статус «Закрыто» и удаляет задание с сервера. TRUE — успешно, FALSE — ошибка. |

## Аргументы и свойства задания

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetJobArgValue(arg0, arg1)` | arg0: Integer/String, arg1: Integer (номер арг.) | Number/String или Empty | Значение аргумента вызова по индексу (с 0). Только простые типы. |
| `GetJobArgValue(arg0, arg1, arg2)` | + arg2: Boolean | произвольный тип или Empty | То же с возвратом объектов. arg2 по умолчанию FALSE. |
| `GetJobArgType(arg0, arg1)` | arg0: Integer/String, arg1: Integer (номер арг.) | String или Empty | Тип аргумента вызова по индексу. Реестр объявляет 2 параметра, но реализация клиента и сервера читают третий аргумент `returnObjects` (Boolean, по умолчанию FALSE) — фактически метод поддерживает необязательный третий параметр, влияющий только на формат ответа сервера. |
| `GetJobPropertyValue(arg0, arg1)` | arg0: Integer/String, arg1: String (имя свойства) | произвольный тип или Empty | Значение свойства задания. Empty — свойство неверно. |
| `GetJobParameters(arg0)` | arg0: Integer или String | String или Empty | Параметры задания в виде строки текста. Empty — не найдено. |

### Свойства GetJobPropertyValue

| Имя свойства | Тип | Описание |
|--------------|-----|----------|
| `"ARGN"` | Integer | Количество аргументов вызова. |
| `"CLASS_NAME"` | String | Имя класса. |
| `"METHOD_NAME"` | String | Имя метода. |
| `"TYPE"` | String | Тип задания. |
| `"COMPUTER"` | String | Компьютер, создавший задание. |
| `"USER"` | String | Оператор, создавший задание. |
| `"EXE_DATE_TIME"` | DateTime | Дата и время выполнения. Вычисляется приблизительно по `GetTickCount()` на сервере (не хранится как абсолютное время) — может расходиться с реальным временем старта на время работы сервера после перезагрузки системы. Если задание не выполнено, возвращает пустую дату. |
| `"LIFE_LENGTH"` | Integer | Период хранения после выполнения, в минутах. |

## Журнал и лимиты

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetServerLog()` | — | Query | Журнал сервера заданий (объединённый с обычного сервера и сервера транзакций). |
| `GetServerLog(arg0)` | arg0: Integer (секунд назад) | Query | Журнал за последние N секунд. |
| `GetJobLog(arg0)` | arg0: Integer или String | Query или Empty | Журнал одного задания. |
| `SetJobLimit(arg0, arg1)` | arg0: String (имя), arg1: Integer (лимит) | Integer | Лимит одновременно выполняемых заданий с данным именем. Имеет смысл только для REPORT. 0 — без ограничения. Возвращает предыдущее значение. |
| `SetConcurrentTransactions(arg0)` | arg0: Boolean | Boolean | Разрешить/запретить параллельное выполнение транзакционных заданий. По умолчанию FALSE. Возвращает предыдущее значение. |

### Поля объекта Query из GetServerLog / GetJobLog

| Поле | Тип | Описание |
|------|-----|----------|
| `JobNo` | TEXT | Номер задания в формате `dd-hh:mm-NNNNNN`. |
| `Name` | TEXT | Имя задания. |
| `Date` | DATE | Дата события. |
| `Time` | TIME | Время события. |
| `Computer` | TEXT | Компьютер, создавший задание. |
| `User` | TEXT | Оператор, создавший задание. |
| `Status` | INT | Статус задания в момент события. |
| `LastError` | TEXT | Текстовое описание результата выполнения. |

## Примеры

Отправка транзакционного задания с параметрами и ожидание результата:

```EME-L
'Отправить задание на сервер и получить идентификатор'
objJob     = Object("ServerJob");
jobParams  = Object("Parameters");
jobParams.PutParam("LIFELENGTH", 30);
jobParams.PutParam("SILENT", True);

JobId = objJob.SendJob("TRANSACTION:SHARE", "Расчёт заказов", jobParams, "OrdersBatch", "ProcessOrders", OrderId);

'Опросить статус и прочитать результат'
If (objJob.IsJobsComplete(JobId))
    strResult = objJob.GetJobResult(JobId);
    objJob.Close(JobId);
End If
```

Поиск задания по имени и чтение журнала:

```EME-L
objJob = Object("ServerJob");
JobId = objJob.FindJob("REPORT", "Движение товаров");

If (JobId != -1)
    QueuePos = objJob.GetJobQueue(JobId);
    JobLog   = objJob.GetServerLog(3600);
End If
```
