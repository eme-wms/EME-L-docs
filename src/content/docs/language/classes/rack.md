# Класс Rack

Класс `Rack` в языке EME-L — класс для работы с топологией складского стеллажа. Представляет собой объектную модель физической структуры стеллажа, построенную на основе данных сектора, колонн, ячеек и секций из базы данных.

Основные возможности:

- Привязка к сектору склада и загрузка полной топологии стеллажа с расчётом физических размеров пролетов, уровней и колонн.
- Получение структурных характеристик: количество колонн, рядов, уровней и пролетов.
- Доступ к ячейкам по координатам внутри стеллажа (колонна, ряд, уровень) с получением ссылок на записи классификатора ячеек.
- Получение физических размеров и координат элементов стеллажа (ширина пролетов, высота уровней, координаты стоек и колонн).
- Поиск индексов колонн и уровней по их номерам (шифрам).
- Построение трёхмерной визуализации стеллажа в движке Irrlicht.
- Сериализация топологии в дерево свойств для передачи на клиент или сохранения.

Объект класса `Rack` создаётся через `Object()` с пустой топологией. Для загрузки структуры необходимо вызвать метод `Attach`, передав ссылку на сектор склада — после этого объект готов к запросам размеров, координат и ссылок на ячейки.

## Создание объекта

Класс `Rack` имеет единственный конструктор без аргументов — объект создаётся с пустой топологией, привязка к сектору выполняется отдельным методом `Attach`.

```EME-L
'Создать объект стеллажа с пустой топологией'
objRack = Object("Rack");
```

После создания объект не содержит данных о колоннах, уровнях и ячейках — все методы доступа вернут нулевые значения, пока не вызван `Attach`.

## Привязка к сектору

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Attach(arg0)` | arg0: Integer (ссылка на сектор) | Empty | Привязывает объект к сектору склада, загружает колонны, ячейки, секции и уровни. Рассчитывает физические размеры пролетов, ширины секций, высоты уровней и координаты колонн на основе данных ячеек. Ссылка должна указывать на существующую запись в классификаторе секторов. |

`Attach` выполняет полную загрузку топологии за один вызов. Если у сектора нет привязки к секциям (`GetSectionRef() == NULL_REF`), пролеты формируются автоматически по три колонны в каждом.

## Структурные характеристики

Методы возвращают размеры загруженной топологии по каждому измерению.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetNoOfColumns()` | — | Integer | Общее количество колонн, загруженных в топологию. |
| `GetNoOfRows(arg0)` | arg0: Integer (индекс колонны, с 0) | Integer | Количество рядов (строк ячеек) в указанной колонне. |
| `GetNoOfLevels(arg0, arg1)` | arg0: Integer (индекс колонны, с 0), arg1: Integer (индекс ряда, с 0) | Integer | Количество уровней (ярусов) в указанном ряду заданной колонны. |
| `GetBayIndexOfColumn(arg0)` | arg0: Integer (индекс колонны, с 0) | Integer | Индекс пролета (секции), к которому относится указанная колонна. |
| `GetNoOfBays()` | — | Integer | Количество пролетов в стеллаже. Пролеты формируются из секционной привязки или автоматически группируются по три колонны при отсутствии секций. |

## Уровни в пролётах

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetNoOfLevelsInBay(arg0, arg1)` | arg0: Integer (индекс пролёта, с 0), arg1: Integer (индекс ряда, с 0) | Integer | Максимальное количество уровней среди всех колонн, входящих в указанный пролёт, для заданного ряда. При недопустимом индексе пролёта генерируется ошибка выполнения. |
| `GetLevelHeightInBay(arg0, arg1)` | arg0: Integer (индекс пролёта, с 0), arg1: Integer (индекс уровня, с 0) | Real | Абсолютная высота указанного уровня относительно пола в метрах. Пустые или отсутствующие высоты заменяются типовыми значениями. При недопустимом индексе уровня генерируется ошибка выполнения. |

## Доступ к ячейкам

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetCellRef(arg0, arg1, arg2)` | arg0: Integer (индекс колонны, с 0), arg1: Integer (индекс ряда, с 0), arg2: Integer (индекс уровня, с 0) | Integer | Ссылка на ячейку склада в указанной позиции. Возвращает `NULL_REF`, если комбинация индексов выходит за пределы загруженной топологии. |

## Физические размеры

Все размеры возвращаются в метрах. Координаты Y пролетов центрируются относительно начала координат.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetBayWidth(arg0)` | arg0: Integer (индекс пролёта, с 0) | Real | Ширина пролёта в метрах. Рассчитывается из суммарной ширины входящих в него ячеек с учётом типовых размеров. |
| `GetUprightWidth()` | — | Real | Ширина стойки стеллажа. Совпадает с высотой балки (`GetBeamHeight`). |
| `GetBeamHeight()` | — | Real | Высота балки стеллажа в метрах. Если высота не задана в секторе, по умолчанию `0.1` (10 см). |
| `GetUprightMinY(arg0)` | arg0: Integer (индекс пролёта, с 0) | Real | Y-координата левой (минимальной) границы указанного пролёта. |

**Внимание:** В текущей реализации C++ (файл `i_Rack.cpp`) диспетчер EME-L для `GetUprightMinY` ошибочно переопределён функцией с именем `GetUprightWidth(int argn, COleVariant args[])`, которая вызывает `GetUprightWidth` с лишним аргументом. Вызов `GetUprightMinY` из EME-L может не вернуть ожидаемое значение. См. раздел «Расхождения» ниже.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetUprightMaxY(arg0)` | arg0: Integer (индекс пролёта, с 0) | Real | Y-координата правой (максимальной) границы указанного пролёта. |
| `GetColumnY(arg0)` | arg0: Integer (индекс колонны, с 0) | Real | Y-координата центра указанной колонны. Рассчитывается как сумма минимальной Y-координаты пролёта и центрального смещения колонны внутри пролёта. |

## Поиск индексов по шифрам

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetColumnIndex(arg0)` | arg0: Integer (номер/шифр колонны) | Integer | Индекс колонны в топологии. Возвращает `-1`, если колонна с указанным номером отсутствует. |
| `GetLevelIndex(arg0)` | arg0: Integer (номер/шифр уровня) | Integer | Индекс уровня в топологии. Возвращает `-1`, если уровень с указанным номером отсутствует. |

## 3D-визуализация и сериализация

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddRack(arg0)` | arg0: IrrNode (родительский узел сцены) | IrrMesh или Empty | Создаёт трёхмерную полигональную сетку стеллажа и добавляет её к родительскому узлу Irrlicht. Формирует геометрию балок для всех уровней всех пролетов, применяет текстуры и нормальные карты. При отсутствии поддержки Irrlicht возвращает пустое значение. |
| `SaveRack(arg0)` | arg0: PropertyTree (дерево свойств) | Empty | Сохраняет полную топологию стеллажа в дерево свойств: уровни, колонны, ряды, ячейки, пролёты и их размеры. Для каждой ячейки дополнительно записывает номер, объём, свободный объём, используемый объём, высоту, признак физической пустоты и зазор. |

## Константы

Значения по умолчанию и граничные величины, используемые при расчёте топологии в теле методов (взяты из реализации C++):

| Константа | Значение | Назначение |
|-----------|----------|------------|
| Высота балки по умолчанию | `0.1` м (10 см) | Применяется, если высота балки не задана в секторе (`GetBeamHeight == 0`). |
| Коэффициент перевода см → м | `0.01` | Размеры ячеек и сектора в БД хранятся в сантиметрах; класс переводит их в метры. |
| Ширина ячейки по умолчанию | `1.0` м | Применяется, если ширина ячейки равна нулю или отсутствует. |
| Высота ячейки по умолчанию | `2.0` м | Применяется, если высота ячейки равна нулю или отсутствует. |
| Максимальная высота ячейки | `4.0` м | Ограничение сверху: ячейки выше этого значения обрезаются, чтобы «не упирались в небо» при 3D-визуализации. |
| NULL_REF | `0` (ссылка) | Возвращается `GetCellRef`, если комбинация индексов выходит за пределы топологии. |
| Индекс не найден | `-1` | Возвращается `GetColumnIndex` и `GetLevelIndex`, если элемент с указанным шифром отсутствует. |
| Версия формата SaveRack | `"1.0"` | Записывается в атрибут `version` корневого узла дерева свойств. |

## Примеры

Загрузка топологии стеллажа и перебор ячеек:

```EME-L
'Создать стеллаж и привязать к сектору'
objRack = Object("Rack");
objRack.Attach(r_Sector);

'Перебрать все колонны, ряды и уровни'
nColumns = objRack.GetNoOfColumns();
For (c = 0; c < nColumns; c = c + 1)
    nRows = objRack.GetNoOfRows(c);
    For (r = 0; r < nRows; r = r + 1)
        nLevels = objRack.GetNoOfLevels(c, r);
        For (l = 0; l < nLevels; l = l + 1)
            cellRef = objRack.GetCellRef(c, r, l);
            If (cellRef != 0)
                'cellRef — ссылка на ячейку в БД'
            End If
        End For
    End For
End For
```

Поиск колонны по шифру и получение её физических координат:

```EME-L
'Найти индекс колонны по номеру из классификатора'
colIdx = objRack.GetColumnIndex(105);
If (colIdx != -1)
    yPos = objRack.GetColumnY(colIdx);
    'yPos — координата центра колонны в метрах'
End If
```

## Расхождения с реализацией C++

В файле `i_Rack.cpp` обнаружено расхождение между регистрацией методов и их реализацией:

- **`GetUprightMinY` — сломанный диспетчер.** В `BEGIN_IMPLEMENT(CIRack)` зарегистрирован метод `GetUprightMinY(arg0)` (один аргумент, индекс пролёта). Однако в телах функций на C++ диспетчер `COleVariant CIRack::GetUprightMinY(int argn, COleVariant args[])` **отсутствует**. Вместо него в строке 699 определён второй `COleVariant CIRack::GetUprightWidth(int argn, COleVariant args[])` (дублирующее определение), тело которого вызывает `GetUprightWidth(variant2integer(args[0]))` — но `long CIRack::GetUprightWidth()` не принимает аргументов. Это либо не компилируется, либо вызов `GetUprightMinY(idx)` из EME-L направляется в неверную функцию. Документация следует контракту REGISTRY; но при использовании следует проверять фактическое поведение времени выполнения.
