# Класс Timer

Класс `Timer` в языке EME-L — класс для измерения временных интервалов выполнения действий в миллисекундах с записью результатов в базу данных.

Предназначен для профилирования производительности операций в системе EME, особенно при работе с роботом автоматизированного тестирования. Позволяет запускать несколько таймеров одновременно для различных действий, измеряя время каждого из них. Объект создаётся без параметров. По умолчанию включён режим подробного логирования (`isUseLog = true`), который удобен для отладки, но снижает точность измерения примерно на 1% из-за времени открытия транзакций. Для точного профилирования производительности рекомендуется отключить логирование методом `SetUseLog(false)`.

Класс `Timer` доступен в версиях ядра EME.WMS 28.6 и выше (условие компиляции `LAST_VERSION >= MAKE_VERSION(28, 6)`).

Объект класса `Timer` создаётся через `Object()` и не привязан к контексту диалога или браузера — это самостоятельный класс для измерения времени выполнения операций.

## Создание объекта

Класс `Timer` имеет один конструктор — без аргументов.

```EME-L
'Создать таймер для измерения времени выполнения операций'
timer = Object("Timer");
```

Конструктор не принимает параметров. При попытке передать аргументы генерируется ошибка `too many`.

## Методы

### Запуск и остановка таймеров

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Start()` | — | Empty | Запускает таймер для действия без названия (эквивалентно `Start("БЕЗ НАЗВАНИЯ")`). Создаёт или находит запись действия в справочнике `RobotQualifierActions` по имени `"БЕЗ НАЗВАНИЯ"`. |
| `Start(name)` | name: String | Empty | Запускает таймер для действия с указанным именем. Если имя не передано, используется `"БЕЗ НАЗВАНИЯ"`. |
| `Stop()` | — | Integer | Останавливает таймер для действия без названия и возвращает время выполнения в миллисекундах. Если действие не найдено, возвращает 0. |
| `Stop(name)` | name: String | Integer | Останавливает таймер для действия с указанным именем и возвращает время выполнения в миллисекундах. Если имя не передано, используется `"БЕЗ НАЗВАНИЯ"`. Если действие не найдено, возвращает 0. |

### Настройка логирования

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetUseLog(useLog)` | useLog: Boolean | Empty | Устанавливает режим подробного логирования. `true` — включить логирование (по умолчанию); `false` — отключить для точного профилирования. |

## Поведение и ограничения

- В режиме подробного логирования каждый запуск и остановка таймера записываются в лог робота сразу.
- В режиме без логирования записи в лог выполняются только при запуске первого таймера и после остановки всех таймеров, чтобы не влиять на точность измерения.
- После остановки последнего работающего таймера данные всех таймеров автоматически сохраняются в базу данных в запись `RobotFullTest`.
- Несколько таймеров с одинаковым именем обрабатываются по принципу стека: останавливается последнее начатое действие с таким именем.
- Имена действий создаются или находятся в справочнике `RobotQualifierActions`. Если запись для имени отсутствует, она создаётся автоматически при первом запуске таймера с этим именем.
- Время фиксируется по системному времени (`GetLocalTime`) с точностью до миллисекунд.

## Примеры

Измерение времени выполнения операции робота (из `Robot.txt`):

```EME-L
'Создаём таймер без параметров'
timer = Object("Timer");

'Засечь время выполнения участка кода'
timer.Start();
'... выполняемые действия ...'
timeMs = timer.Stop();
Robot.Log("Операция выполнена за %d мс", timeMs);
```

Измерение времени выполнения поименованных действий (из `ClientClassifierRobot.txt`):

```EME-L
'Создаём таймер с подробным логированием по умолчанию'
timer = Object("Timer");

'Засечь время открытия диалога'
timer.Start("открытие диалога группы клиентов");
Robot.SelectMenuDialog("ClientsClassifier.Dialog");
timer.Stop("открытие диалога группы клиентов");

'Засечь время создания группы клиентов'
timer.Start("создание группы клиентов");
Robot.ButtonClick("ClientsClassifier.IntegratorAddBtn");
'... остальные действия ...'
timer.Stop("создание группы клиентов");
```

Точное профилирование с отключенным логированием:

```EME-L
'Отключить логирование для точных измерений'
timer = Object("Timer");
timer.SetUseLog(false);

timer.Start("быстрая операция");
'... измеряемый код ...'
duration = timer.Stop("быстрая операция");
```
