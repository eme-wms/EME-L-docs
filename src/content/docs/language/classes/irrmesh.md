# Класс IrrMesh

Класс `IrrMesh` в языке EME-L — класс полигональной сетки движка Irrlicht. Представляет трёхмерный объект-сетку, загружаемый из mesh-файла или создаваемый программно через объект `IrrMeshCreator`.

Наследует базовые возможности узла сцены Irrlicht и позволяет изменять используемую сетку методом `SetMesh`, управлять цветом и прозрачностью вершин, задавать зеркальный цвет материала первого буфера, а также добавлять и удалять объёмные тени. Используется в прикладных скриптах EME-L для отображения статических 3D-моделей в сцене Irrlicht — например, при визуализации складских стеллажей, напольной разметки и оборудования в 3D-органе управления EME.WMS.

Класс доступен только при сборке ядра с включённой поддержкой Irrlicht (макрос компиляции `IRRLICHT_IS_AVAILABLE`). Объект создаётся через `Object("IrrMesh")` и является узлом сцены: для отрисовки он должен быть добавлен как дочерний к корневому узлу `IrrDevice` или другому узлу `IrrNode`.

## Создание объекта

В блоке регистрации `BEGIN_IMPLEMENT(CIIrrMesh)` макросы `IMPLEMENT_CTOR` отсутствуют — класс использует единственный конструктор по умолчанию без аргументов. Источник полигональной сетки задается после создания методом `SetMesh`.

```EME-L
'Создать узел полигональной сетки Irrlicht без предустановленной сетки'
objMesh = Object("IrrMesh");
```

После создания объект не имеет связанной геометрии — для отображения необходимо вызвать `SetMesh`, передав путь к mesh-файлу или объект `IrrMeshCreator`. Внутренний конструктор C++ также принимает `IrrMeshBuffer`, однако через макрос `SetMesh` этот тип в текущей реализации не проводится (см. описание метода и раздел «Расхождения»).

## Сетка и её источник

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetMesh(arg0)` | arg0: String (путь к mesh-файлу) или IrrMeshCreator (по ссылке) | IrrMesh | Загружает или формирует новую полигональную сетку и устанавливает её для текущего узла. При передаче строки путь загружается менеджером сцены Irrlicht; при передаче объекта `IrrMeshCreator` сетка строится программно из описания. Возвращает текущий объект `IrrMesh` для цепочки вызовов. |

## Цвет и прозрачность вершин

Цвет задаётся как 32-битное целое в формате RGBA `0xAARRGGBB` (компоненты 0...255). `SetVertexColors` перекрашивает все вершины текущей сетки; `SetVertexColorAlpha` изменяет только альфа-канал, сохраняя RGB.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetVertexColors(arg0)` | arg0: Integer (RGBA, `0xAARRGGBB`) | Empty | Окрашивает все вершины текущей полигональной сетки заданным RGBA-цветом. |
| `SetVertexColorAlpha(arg0)` | arg0: Integer (0...255) | Empty | Задаёт прозрачность (альфа-канал) всех вершин: 0 — полностью прозрачные, 255 — полностью непрозрачные. |
| `SetSpecularColor(arg0)` | arg0: Integer (RGBA, `0xAARRGGBB`) | Empty | Задаёт зеркальный цвет материала первого буфера (`getMaterial(0)`) текущей полигональной сетки. |

## Тени

Узел объёмной тени (shadow volume) может быть добавлен к полигональной сетке для расчёта динамических теней в сцене Irrlicht. Повторный вызов `AddShadow` игнорируется, если тень уже добавлена; `RemoveShadow` безопасен при отсутствии тени.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddShadow()` | — | Empty | Добавляет к текущей полигональной сетке узел объёмной тени, если тень ещё не была добавлена. |
| `RemoveShadow()` | — | Empty | Удаляет узел объёмной тени, если тень была добавлена ранее. |

## Примеры

Создание узла с сеткой из файла и настройка материала:

```EME-L
'Создать узел сетки и загрузить 3D-модель из файла'
objMesh = Object("IrrMesh");
objMesh.SetMesh("3D\\rack.md2");

'Перекрасить вершины в белый цвет и задать зеркальный блик'
objMesh.SetVertexColors(0xFFFFFFFF);
objMesh.SetSpecularColor(0xFF333333);

'Добавить объёмную тень'
objMesh.AddShadow();
```

Программное построение сетки через `IrrMeshCreator` с последующей установкой в узел:

```EME-L
'Описать сетку стеллажа через IrrMeshCreator'
meshCreator = Object("IrrMeshCreator");
meshCreator.SetMaterial("3D\\rack.png", 500, 1000);
PlaneNode = meshCreator.AddPlane(-1);
meshCreator.SetImageRect(PlaneNode, 0, 0, 499, 999);

'Создать узел IrrMesh и установить в него построенную сетку'
objMesh = Object("IrrMesh");
objMesh.SetMesh(meshCreator);
objMesh.SetVertexColorAlpha(255);
```
