# Класс LDAP

Класс `LDAP` в языке EME-L — класс для подключения к серверу LDAP (Active Directory) и выполнения операций доменной аутентификации. Предоставляет методы для проверки доступа к домену, управления контекстом пользователя и домена, проверки членства пользователя в группах, верификации GUID доменного пользователя и получения списков пользователей групп.

Используется для интеграции с Active Directory в сценариях доменной аутентификации и авторизации. Объект класса создаётся через `Object()` и инициализируется подключением к домену от имени текущего пользователя операционной системы с повышением привилегий до администратора домена (учётные данные администратора читаются из записи «Список пользователей» и расшифровываются через DPAPI).

Класс не имеет перегрузок методов — каждый метод представлен в единственной сигнатуре. Конструктор существует только без аргументов.

## Создание объекта

```EME-L
'Конструктор без аргументов: инициализация под текущим доменным пользователем'
objLDAP = Object("LDAP");
```

Конструктор без аргументов создаёт объект и выполняет автоматическую инициализацию подключения к LDAP. Определяет домен и имя пользователя через системный API (`GetUserName`, `GetUserNameEx`), затем устанавливает подключение с правами администратора домена. Пароль администратора домена хранится в базе данных в зашифрованном виде (DPAPI + Base64) и расшифровывается только в режиме службы ядра (или в отладочной сборке).

Если домен или доменное имя администратора не заданы в записи «Список пользователей», выполняется попытка подключения от имени текущего пользователя ОС. Протокол (`LDAP` или `LDAPS`) выбирается системной настройкой протокола доменной аутентификации.

После создания объекта проверьте результат через `IsDomainAccess` и `IsBind` — конструктор не возбуждает исключений при неудаче инициализации.

## Состояние подключения

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `IsDomainAccess()` | — | Boolean | TRUE — активное подключение к серверу LDAP установлено, FALSE — отсутствует. |
| `IsBind()` | — | Boolean | TRUE — операция bind (привязка) к серверу LDAP выполнена успешно, FALSE — нет. |

`IsDomainAccess` проверяет, что был создан дескриптор сессии LDAP (инициализация через `ldap_init` / `ldap_sslinit`). `IsBind` дополнительно подтверждает успешную аутентификацию (`ldap_bind_s`). Подключение без bind не даёт права выполнять поисковые запросы к каталогу.

## Контекст пользователя и домена

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetDomain()` | — | String | Имя домена, сохранённое в контексте объекта. Пустая строка, если домен не задан. |
| `PutDomain(arg0)` | arg0: String (домен) | Empty | Устанавливает имя домена в контексте объекта. |
| `GetUser()` | — | String | Имя пользователя, сохранённое в контексте объекта. Пустая строка, если пользователь не задан. |
| `PutUser(arg0)` | arg0: String (пользователь) | Empty | Устанавливает имя пользователя в контексте объекта. |

Контекст пользователя и домена устанавливается автоматически в конструкторе и используется последующими методами (`UserInGroup`, `CheckDomainUserGuid`). При необходимости его можно переопределить через `PutDomain` и `PutUser` — например, для проверки другого пользователя в рамках той же сессии LDAP.

## Проверка членства в группе

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `UserInGroup(arg0)` | arg0: String (имя группы в Active Directory) | Boolean | TRUE — текущий пользователь входит в указанную группу, FALSE — не входит или произошла ошибка. |

Поиск выполняется по фильтру `(&(objectClass=group)(cn=<имя группы>))` в поддереве домена (`LDAP_SCOPE_SUBTREE`). Проверяется вхождение DN текущего пользователя в атрибут `member` группы. Имя группы передаётся как значение `CN` (например, `"EME_Admins"`), а не как полная строка DN.

## Проверка GUID доменного пользователя

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `CheckDomainUserGuid(arg0)` | arg0: Integer (ссылка на строку записи «Список пользователей») | Boolean | TRUE — GUID пользователя в базе совпадает с GUID из Active Directory и учётная запись активна. FALSE — GUID не совпадает, пользователь не найден или учётная запись отключена либо заблокирована. |

Метод сверяет атрибут `objectGUID` из Active Directory со значением поля GUID в записи пользователя базы EME.WMS. При расхождении обновляет домен, доменное имя и GUID в записи пользователя внутри серверной транзакции (`OpenServerTransaction` / `CloseServerTransaction`). Затем проверяет флаги учётной записи (`userAccountControl`): если установлены `ADS_UF_ACCOUNTDISABLE` или `ADS_UF_LOCKOUT`, возвращает FALSE и выставляет в записи пользователя флаг «Доступ временно запрещён» (`USER_ACCESS_DENIED`).

> **Внимание (поведение C++):** выставление `USER_ACCESS_DENIED` в поле `m_Flags` выполняется **за пределами** серверной транзакции — уже после `CloseServerTransaction` либо вообще без неё, если GUID совпал и ветка обновления GUID не выполнялась. Сравните с записью `m_Domain`/`m_DomainUser`/`m_GUID`, которая строго транзакционна. Это асимметрия в реализации `CheckDomainUserGuid` (`i_LDAP.cpp` строки 1011-1017 vs 1037-1039): при сбое записи флага изменения GUID уже зафиксированы в БД. Кроме того, признак «пустого GUID» в БД определяется по первым двум байтам (`userGUID[0] && userGUID[1]`): если оба нулевые — считается, что GUID в базе не задан, и метод немедленно перезапишет его значением из AD.

Поиск доменного пользователя выполняется по доменному имени; при неудаче — по EME-логину. Это позволяет использовать метод как для пользователей с совпадающим EME-логином и доменным именем, так и для случаев, когда они различаются.

## Получение списка пользователей группы

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetAllUsersInGroup(arg0, arg1)` | arg0: String (имя группы), arg1: Array (по ссылке) | Boolean | TRUE — список пользователей получен успешно, FALSE — группа не найдена или произошла ошибка. |

Метод заполняет переданный массив логинами пользователей (`sAMAccountName`) из атрибута `member` указанной группы. Сначала извлекаются значения `CN` участников группы, затем для каждого `CN` выполняется обратный поиск по фильтру `(&(objectClass=user)(cn=<CN>))` для получения логина. Группа ищется по `CN` в поддереве домена.

**Требование к версии ядра:** метод реализован только в ядре версии 51.11 и выше; в более ранних версиях возвращает пустое значение. Тип `arg1` обязан быть объектом класса `Array` — при передаче объекта другого типа метод выводит ошибку через `smart_error` и прерывает выполнение.

## Константы из тел методов

Следующие числовые значения и имена встречаются в реализации и зафиксированы как часть контракта класса:

| Константа | Значение | Назначение |
|-----------|----------|------------|
| `GUID_SIZE` | `16` | Размер бинарного представления `objectGUID` в байтах. |
| `LDAP_PORT` | системная константа WinLDAP | Порт для протокола `LDAP` (используется при `ldap_init`). |
| `LDAP_SSL_PORT` | системная константа WinLDAP | Порт для протокола `LDAPS` (используется при `ldap_sslinit`). |
| `LDAP_VERSION3` | `3` | Версия протокола LDAP, устанавливается через `LDAP_OPT_PROTOCOL_VERSION`. |
| `USER_ACCESS_DENIED` | битовый флаг записи пользователя | Выставляется методом `CheckDomainUserGuid` при отключённой или заблокированной учётной записи. |

## Примеры

Проверка подключения и членства текущего пользователя в группе:

```EME-L
'Создать объект и проверить подключение к домену'
objLDAP = Object("LDAP");
If (Not objLDAP.IsDomainAccess())
    is_catastrophic_log("Подключение к LDAP не установлено");
    Return;
End If

'Проверить членство в группе EME_Admins'
If (objLDAP.UserInGroup("EME_Admins"))
    IsAdmin = True;
End If
```

Проверка GUID пользователя в базе и блокировка при отключённой учётной записи:

```EME-L
objLDAP = Object("LDAP");
If (objLDAP.IsBind())
    'Ссылка на строку записи Список пользователей'
    UserRef = is_get_user_ref();
    If (Not objLDAP.CheckDomainUserGuid(UserRef))
        is_message("Внимание", "GUID не совпал или учётная запись заблокирована");
    End If
End If
```

Получение списка логинов участников группы:

```EME-L
'Массив заполняется по ссылке'
arrUsers = is_array();
objLDAP = Object("LDAP");
If (objLDAP.GetAllUsersInGroup("EME_Warehouse_Operators", arrUsers))
    Loop (arrUsers)
        Login = ValOf(arrUsers);
        'Обработка логина доменного пользователя'
    End Loop
End If
```
