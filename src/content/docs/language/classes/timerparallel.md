# Класс TimerParallel

Класс `TimerParallel` в языке EME-L — параллельный таймер для измерения временных интервалов выполнения действий в миллисекундах. Предназначен для профилирования производительности скриптов и операций базы данных. Поддерживает параллельный запуск нескольких таймеров с различными именами действий, что позволяет измерять время вложенных или одновременных операций.

Основные возможности:

- Запуск и остановка таймеров с указанием имени действия.
- Поддержка стекового порядка остановки при наличии нескольких действий с одинаковым именем.
- Ведение журнала работы таймера в текстовый файл.
- Режим подробного логирования и режим точного измерения (без логирования).

Класс доступен только в версиях ядра EME.WMS 45.1 и выше (`LAST_VERSION >= MAKE_VERSION(45, 1)`).

Объект создаётся через `Object()` и не привязан к контексту диалога или браузера — это самостоятельный вспомогательный класс для измерения производительности.

## Создание объекта

Класс `TimerParallel` имеет один конструктор с необязательным параметром `fileLog`.

```EME-L
'Таймер с журналом по умолчанию'
timer = Object("TimerParallel");
```

```EME-L
'Таймер с явным путём к файлу журнала'
timer = Object("TimerParallel", "D:/Logs/timer.log");
```

По умолчанию файл журнала располагается в директории данных проекта (`GetProjectDataDir()`) и называется `timer.log`. Подробное логирование включено по умолчанию (внутренний конструктор `TimerParallel` задаёт `isUseLog = true`). Логирование снижает точность измерения примерно на 1% из-за времени записи в файл; для максимальной точности вызовите `SetUseLog(false)` сразу после создания объекта.

## Методы

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Start()` | — | Empty | Запускает измерение для действия «БЕЗ НАЗВАНИЯ». |
| `Start(arg0)` | arg0: String | Empty | Запускает измерение для указанного действия. |
| `Stop()` | — | Integer | Останавливает последнее запущенное действие «БЕЗ НАЗВАНИЯ» и возвращает интервал в миллисекундах. |
| `Stop(arg0)` | arg0: String | Integer | Останавливает последнее запущенное действие с указанным именем. |
| `GetInterval()` | — | Integer | Возвращает `0` для действия «БЕЗ НАЗВАНИЯ». |
| `GetInterval(arg0)` | arg0: String | Integer | Возвращает `0` для указанного действия. |
| `SetUseLog(arg0)` | arg0: Boolean | Empty | Включает (`true`) или отключает (`false`) подробное логирование. |

`Start` и `Stop` работают со стеком таймеров. Если несколько действий с одним именем запущены, `Stop` останавливает последнее начатое. Время фиксируется в конце вызова `Start` и перед началом записи результатов в `Stop`, чтобы подготовительные операции не искажали измерение.

`Stop` возвращает неинициализированное значение, если действие с указанным именем не было запущено; в журнал при этом записывается ошибка.

`GetInterval` всегда возвращает `0` в текущей реализации (заглушка).

## Примеры

### Простое измерение

```EME-L
timer = Object("TimerParallel");
timer.Start();
'... выполняемая операция ...'
elapsed = timer.Stop();
```

### Измерение с именем действия и явным журналом

```EME-L
timer = Object("TimerParallel", "D:/Logs/perf.log");
timer.Start("импорт данных");
'... импорт ...'
importTime = timer.Stop("импорт данных");
```

### Режим точного измерения

```EME-L
timer = Object("TimerParallel");
'timer.SetUseLog(false);'
'timer.Start("быстрая операция");'
'... операция ...'
'elapsed = timer.Stop("быстрая операция");'
```

### Параллельные таймеры

```EME-L
timer = Object("TimerParallel");
timer.Start("внешняя операция");
timer.Start("внутренняя операция");
innerTime = timer.Stop("внутренняя операция");
outerTime = timer.Stop("внешняя операция");
```

## Примечания

В реестре C++ (`IMPLEMENT_CTOR`) конструктор декларирован с `argCount = 0` и подписью `CITimerParallel([fileLog])`, но тело конструктора и реальные скрипты принимают 0 или 1 аргумент. Документация отражает фактическое поведение — оба варианта вызова `Object("TimerParallel")` и `Object("TimerParallel", fileLog)` работают.
