# Класс TCP

Класс `TCP` в языке EME-L — класс для работы с TCP/IP-соединениями через сокеты.

Предоставляет возможность установления и разрыва TCP-соединений с удаленными хостами, отправки и получения текстовых данных, настройки таймаутов операций, а также асинхронной отправки сообщений в отдельном потоке. Поддерживает разрешение DNS-имен в IP-адреса.

Объект создается с указанием IP-адреса и порта хоста или с параметрами по умолчанию. Соединение устанавливается явным вызовом метода `Connect` и разрывается методом `Disconnect`. При уничтожении объекта активное соединение автоматически закрывается.

## Создание объекта

Класс `TCP` имеет два конструктора — один без аргументов и один с указанием хоста и порта.

```EME-L
'Конструктор без аргументов — используются константы по умолчанию'
objTcp = Object("TCP")
```

```EME-L
'Конструктор с явным IP-адресом (или DNS-именем) и портом'
objTcp = Object("TCP", "192.168.1.10", 8080)
```

Начальные значения в конструкторе без аргументов берутся из констант `TCP_DEFAULT_HOST_IP_ADRESS` (IP-адрес хоста по умолчанию), `TCP_DEFAULT_HOST_PORT` (порт по умолчанию) и `TCP_DEFAULT_*_TIMEOUT` (таймауты подключения, отключения, записи и чтения). Числовые значения этих констант не видны в доступном файле `i_TCP.cpp`.

## Методы

### Подключение и управление соединением

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Connect()` | — | Boolean | Устанавливает TCP-соединение с текущими настройками IP и порта. Возвращает `TRUE` (-1), если соединение установлено, и `FALSE` (0) в противном случае. |
| `Disconnect()` | — | Boolean | Разрывает установленное TCP-соединение. Возвращает `TRUE`, если соединение разорвано или уже было разорвано, и `FALSE` при неудаче. |
| `SetHostIpAndPort(HostIp, HostPort)` | HostIp: String, HostPort: Integer | Empty | Устанавливает IP-адрес или DNS-имя хоста и порт для последующих операций. |
| `AsyncConnectSendDisconnect(TextToSend)` | TextToSend: String | String | В отдельном потоке подключается к хосту, отправляет текстовое сообщение и закрывает соединение. Возвращает пустую строку сразу, не дожидаясь завершения операции. |

### Настройка таймаутов

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetTimeForConnection(Timeout)` | Timeout: Integer | Empty | Максимальное время ожидания установления соединения, в миллисекундах. |
| `SetTimeForDisconnection(Timeout)` | Timeout: Integer | Empty | Максимальное время ожидания завершения разрыва соединения, в миллисекундах. |
| `SetTimeForRead(Timeout)` | Timeout: Integer | Empty | Максимальное время ожидания получения ответа от хоста, в миллисекундах. |
| `SetTimeForWrite(Timeout)` | Timeout: Integer | Empty | Максимальное время ожидания завершения отправки данных, в миллисекундах. |

### Обмен данными

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Send(Text)` | Text: String | Boolean | Отправляет текстовое сообщение удаленному хосту. Текст предварительно преобразуется в UTF-8. Возвращает `TRUE` (-1) при успешной отправке и `FALSE` (0) при неудаче. |
| `Recieve()` | — | String | Получает ответ от удаленного хоста. В случае неудачи или отсутствия данных возвращает пустую строку. |

### Служебные методы

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetHostIpFromName(HostName)` | HostName: String | String | Выполняет разрешение DNS-имени хоста в IP-адрес. При неудаче возвращает пустую строку. |

## Константы по умолчанию

Класс `TCP` использует следующие константы для начальной инициализации:

- `TCP_DEFAULT_HOST_IP_ADRESS` — IP-адрес хоста по умолчанию (опечатка в исходнике: `ADRESS` вместо `ADDRESS`).
- `TCP_DEFAULT_HOST_PORT` — порт подключения по умолчанию.
- `TCP_DEFAULT_CONNECTION_TIMEOUT` — таймаут установления соединения.
- `TCP_DEFAULT_DISCONNECTION_TIMEOUT` — таймаут разрыва соединения.
- `TCP_DEFAULT_SEND_TIMEOUT` — таймаут отправки данных.
- `TCP_DEFAULT_RECIEVE_TIMEOUT` — таймаут получения данных (опечатка в исходнике: `RECIEVE` вместо `RECEIVE`).

Числовые значения констант не приведены в доступном файле `i_TCP.cpp`.

## Примеры

### Разрешение DNS-имени текущего компьютера

```EME-L
'Реальный пример: получить IP-адрес текущей рабочей станции'
ip = Object("TCP").GetHostIpFromName(is_computer_name())
```

### Полный цикл TCP-запроса

```EME-L
'Создание объекта с явным хостом и портом'
tcp = Object("TCP", "example.com", 80)

'Подключение к удаленному хосту'
If (tcp.Connect())
    'Отправка текстового запроса (преобразуется в UTF-8)'
    tcp.Send("GET / HTTP/1.1\r\nHost: example.com\r\n\r\n")

    'Получение ответа'
    answer = tcp.Recieve()

    'Закрытие соединения'
    tcp.Disconnect()
End If
```
