# Класс RecModeSaver

Класс `RecModeSaver` в языке EME-L — хранитель состояния обхода записи (или таблицы диалога) семейства `CEMERec`. Предназначен для временного сохранения и автоматического восстановления параметров обхода записи при выходе объекта из области видимости. Запоминает способ обхода, текущую строку, цепочку, обратную ссылку, признак использования обратной ссылки, список пропущенных строк (skip-записей) и признак проверки валидности.

Основной сценарий использования: создание объекта с передачей ссылки на запись, при необходимости изменение восстанавливаемой текущей строки методом `SetLine`, после чего при уничтожении объекта исходное состояние записи восстанавливается автоматически.

Не поддерживает создание из записи, находящейся в режиме обхода по массиву ссылок (`rmArrayMode`) — в этом случае генерируется ошибка «Обход по массиву ссылок не поддерживается». Используется в прикладных скриптах EME-L для защиты состояния обхода записи в локальных фрагментах кода (методах, обработчиках), где требуется временно переключить режим traversal и гарантированно вернуть запись в исходное состояние.

Объект класса `RecModeSaver` создаётся через `Object()` с обязательной передачей записи **по ссылке**. Объект не имеет открытых флагов и не требует отдельной инициализации — захват состояния происходит в конструкторе, восстановление — в деструкторе.

## Создание объекта

Класс `RecModeSaver` имеет один конструктор — ровно с одним обязательным аргументом (ссылка на запись).

```EME-L
'Конструктор с передачей записи по ссылке — захват состояния обхода'
saver = Object("RecModeSaver", r_DocLines);
```

Конструктор принимает ссылку на объект записи семейства `CEMERec`, состояние обхода которого требуется сохранить. Передача по ссылке обязательна — значение arg0 должно быть ссылкой на запись, а не её копией. При уничтожении объекта (выходе из области видимости) сохранённое состояние автоматически восстанавливается в исходной записи, включая позицию текущей строки.

## Состав сохраняемого состояния

При создании объекта захватываются следующие элементы состояния записи `CEMERec`:

| Элемент | Поле C++ | Описание |
|---------|----------|----------|
| Способ обхода | `m_rmRecMode` | Один из режимов `rmRealMode`, `rmSortMode`, `rmChainMode`, `rmSkipMode`. `rmArrayMode` не поддерживается — генерируется ошибка в конструкторе. |
| Текущая строка | `cur_line` | Позиция текущей строки на момент создания хранителя. |
| Цепочка | `CEMEChain` | Полное состояние динамической цепочки обхода. |
| Обратная ссылка | `back_ref` | Ссылка на родительскую запись. |
| Признак использования обратной ссылки | `m_fUseBackRef` | Флаг активности обратной ссылки. |
| Список пропущенных строк | `m_arrSkipEntries` | Массив skip-записей — указатели переносятся с сохранением счётчика ссылок. |
| Признак проверки валидности | `m_fMustBeValidChecked` | Требование проверки валидности строк. |

Восстановление выполняется строго в деструкторе объекта. Текущая строка устанавливается **после** переноса skip-списка и через вызов метода `SetLine` записи, а не прямой записью в `cur_line` — это важно для корректной работы внутренних инвариантов `CEMERec`.

## Методы

### Управление сохранённой позицией

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetLine(arg0)` | arg0: Integer (по значению) | Empty | Устанавливает номер текущей строки, который будет восстановлен в записи при уничтожении хранителя. |
| `GetLine()` | — | Integer | Возвращает номер текущей строки, сохранённый в хранителе. |

`SetLine` не меняет позицию немедленно — он лишь подменяет сохранённое значение, которое будет установлено в запись через `CEMERec::SetLine` в момент уничтожения хранителя (после настройки skip-списка). Используйте `GetLine`, чтобы прочитать ранее сохранённую позицию без восстановления.

> **Примечание:** методы `SetLine`/`GetLine` хранителя управляют **сохранённой** позицией, а не текущей позицией записи. Для прямой установки текущей строки записи используйте `SetLine` у самого объекта записи (`r_DocLines.SetLine(...)`), а не у хранителя.

## Способы обхода, поддерживаемые хранителем

Класс различает пять способов обхода записи `CEMERec`. Эти режимы соответствуют внутренним константам `CEMERec::rmRealMode`, `rmSortMode`, `rmChainMode`, `rmSkipMode`, `rmArrayMode`. Строковые имена режимов (`"Real"`, `"Sort"`, `"Chain"`, `"Skip"`, `"Array"`) используются только во внутренней бинарной сериализации состояния хранителя — в прикладном коде EME-L их передавать не нужно.

| Способ обхода | Поддержка хранителем |
|---------------|----------------------|
| `rmRealMode` — реальный физический порядок строк | Да |
| `rmSortMode` — отсортированный порядок | Да |
| `rmChainMode` — обход по цепочке | Да |
| `rmSkipMode` — обход с пропусками строк | Да |
| `rmArrayMode` — обход по массиву ссылок | Нет (генерируется ошибка в конструкторе) |

## Примеры

Защита состояния обхода перед временным переключением:

```EME-L
'Сохраняем текущий способ обхода строк записи, иначе UploadHTML переключит его'
rms = Object("RecModeSaver", dsDB);

dsDB.SetLine(is_line());

If (~dsDB.IsValidLine())
    Return;
End If

dsDB.UploadHTML();
```

Обход ведущих строк с сохранением исходной позиции вызывающей стороны:

```EME-L
'Заполняет массив ссылок на MasterLine для строки r_DocLines, от старшей к младшей'
rms = Object("RecModeSaver", r_DocLines);

While (r_DocLines.IsValidLine())
    lMasterLineRef = r_DocLines.GetMasterLineRef();
    If (lMasterLineRef == NULL_REF)
        Break;
    End If
    arrMasterLines.InsertAt(0, lMasterLineRef);
    r_DocLines.SetLine(lMasterLineRef);
End While
```

Подмена восстанавливаемой позиции через `SetLine` хранителя (метод не имеет реальных примеров в кодовой базе, показан канонический шаблон использования):

```EME-L
'Сохранить состояние обхода, но при восстановлении вернуть запись на строку 0'
rms = Object("RecModeSaver", r_DocLines);

r_DocLines.SetFirstLine();
While (r_DocLines.IsValidLine())
    'Обработка строк в собственном режиме обхода'
    r_DocLines.SetNextLine();
End While

'Переопределить восстанавливаемую строку: при уничтожении rms запись вернётся на строку 0'
rms.SetLine(0);
```
