# Класс CubiScan

Класс `CubiScan` в языке EME-L управляет 3D-сканером габаритов и веса CubiScan (модель VolumeOne) через TCP/IP-соединение. Предоставляет методы для измерения длины, ширины, высоты, веса и объемного веса объекта, проверки доступности устройства, калибровки, отправки произвольных команд и получения текстового описания ошибок и статусов.

Объект создаётся с указанием IP-адреса устройства и номера TCP-порта. Соединение открывается и закрывается на каждый командный запрос (`Ping`, `Measure`, `Calibration`, `RunCommand`) — отдельного метода подключения нет.

## Создание объекта

```EME-L
'Подключение к сканеру CubiScan по адресу 10.24.2.251, порт 443'
objCubi = Object("CubiScan", "10.24.2.251", 443);
```

Конструктор требует ровно два аргумента — `ip` (строка) и `port` (целое число). После создания измеренные значения сброшены в ноль, код ошибки — `msOk`, статус устройства — «Готово».

## Измерение и опрос устройства

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Measure()` | — | Integer | Запускает измерение (команда `M`). 0 — успех (`msOk`), 200 — устройство готово (`msReady`), прочие — код ошибки. Ответ устройства: `A` — успех, `N` — ошибка (подкод `C` — угловой датчик, `M` — измерение, `Z` — нуль). `msWrongResult` — в ответе присутствовали маркеры `__`/`--`/`~~` (отсутствие/нестабильность/превышение измерения). |
| `Ping()` | — | Integer | Проверяет доступность (команда `T`) и получает идентификатор устройства. 0 — устройство доступно. |
| `Calibration()` | — | Integer | Запускает калибровку (команда `D`). Вызывать повторно до `msReady` (200) или кода ошибки. |
| `RunCommand(arg0)` | arg0: String | Integer | Отправляет произвольную команду по протоколу CubiScan. Фрейминг `STX(0x02)+data+ETX(0x03)+CR(0x0D)+LF(0x0A)` добавляется автоматически — пользовательская команда не должна его содержать. Максимальная длина пользовательской команды — 252 байта (буфер 256 − 4 байта фрейминга). 0 — успех, прочие — код ошибки. Ответ `A` — успех, `N` — ошибка оборудования. |

Каждый метод сам открывает TCP-соединение, отправляет команду, читает ответ и закрывает сокет. Текст последнего ответа доступен через `GetResultString`.

### Калибровка и её этапы

`Calibration` переводит устройство в режим калибровки и последовательно проходит несколько этапов, требующих размещения калибровочного объекта размером 12″ в определённых позициях. Текущий этап возвращает `GetStatusDescription()`:

1. **`msStartCalibrate`** — «Удалите с платформы все объекты».
2. **`msProcCalibrate1`** — «Поместите объект 12" напротив левого сенсора лицевой стороной направо».
3. **`msProcCalibrate2`** — «Поместите объект 12" напротив правого сенсора лицевой стороной налево».
4. **`msProcCalibrate3`** — «Поместите объект 12" напротив задней панели лицевой стороной наружу».
5. **`msProcCalibrate4`** — «Поместите объект 12" напротив задней панели лицевой стороной вверх».
6. **`msEndCalibrate`** — «Калибровка завершена» (устройство переходит в `msReady`).

Код статуса калибровки вычисляется как `msReady (200) + индекс этапа`, полученный из ответа устройства.

## Результаты измерения

Значения обновляются только после успешного `Measure`. При отсутствии объекта, нестабильности или превышении размерности возвращается отрицательный код ошибки: `-1` (`msSTAT_UNDER` — объект отсутствует), `-2` (`msSTAT_UNSTABLE` — объект нестабилен), `-3` (`msSTAT_OVER` — превышение размерности).

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetLength()` | — | Real | Измеренная длина в единицах устройства (дюймы или сантиметры). |
| `GetWidth()` | — | Real | Измеренная ширина. |
| `GetHeight()` | — | Real | Измеренная высота. |
| `GetWeight()` | — | Real | Измеренный вес (фунты или килограммы). |
| `GetVolumeWeight()` | — | Real | Измеренный объемный вес. |
| `GetSizeMeasureUnit()` | — | String | Единица измерения габаритов: `"in"`, `"cm"` или `""` (если измерение не проводилось). |
| `GetWeightMeasureUnit()` | — | String | Единица измерения веса: `"lb"`, `"kg"` или `""`. |

## Статус, ошибки и диагностика

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetStatus()` | — | Integer | Текущий статус: 0 (`msOk`), 200 (`msReady`), промежуточные значения — этапы калибровки, прочие — ошибки или «занято» (`msBusu`). |
| `GetStatusDescription()` | — | String | Текстовое описание статуса на русском: «Устройство готово», «Удалите с платформы все объекты», «Калибровка завершена» и т. д. |
| `GetError()` | — | String | Текстовое описание последней ошибки. При отсутствии ошибок — «Операция завершена успешно.» |
| `GetDeviceId()` | — | Integer | Идентификатор устройства, полученный при последнем успешном `Ping`. 0, если `Ping` не выполнялся. |
| `GetResultString()` | — | String | Необработанная строка ответа устройства от последней команды. Пустая строка, если команда не выполнялась. Поля ответа `Measure`: `L`=длина, `W`=ширина, `H`=высота, `K`=вес, `D`=объёмный вес, `F`=коэффициент. Маркеры значения: `__` — отсутствие объекта (`msSTAT_UNDER`), `--` — нестабильность (`msSTAT_UNSTABLE`), `~~` — превышение (`msSTAT_OVER`). Единицы измерения определяются полями с индексами 4 (размер) и 7 (вес): `E` — английские (дюймы/фунты), `M` — метрические (см/кг). |
| `SetDebug(arg0)` | arg0: Boolean | Empty | Включает (`TRUE`) или отключает (`FALSE`) отладочный режим. В отладочном режиме все отправляемые и принимаемые команды пишутся в системный лог в шестнадцатеричном виде. Без аргументов режим не меняется. |

## Примеры

Полный цикл измерения ВГХ (весогабаритных характеристик) объекта:

```EME-L
'Создать объект сканера CubiScan'
objCubi = Object("CubiScan", "10.24.2.251", 443);

'Включить отладочный режим для диагностики TCP-обмена'
objCubi.SetDebug(True);

'Проверить доступность устройства'
nResult = objCubi.Ping();
If (nResult == 0)
    'Измерить габариты и вес объекта'
    nResult = objCubi.Measure();
    If (nResult == 0)
        strMsg = "Length = " + objCubi.GetLength() + ", Width = " + objCubi.GetWidth() + ", Height = " + objCubi.GetHeight() + ", Weight = " + objCubi.GetWeight();
        is_message("Cubi ВГХ", strMsg, 1, 1);
    Else
        'Вывести описание ошибки измерения'
        is_message("Cubi Ошибка", objCubi.GetError(), 1, 3);
    End If
Else
    is_message("Cubi Ошибка", objCubi.GetError(), 1, 3);
End If
```

Проверка единиц измерения после измерения:

```EME-L
'Определить систему единиц, используемую устройством'
strSizeUnit = objCubi.GetSizeMeasureUnit();
strWeightUnit = objCubi.GetWeightMeasureUnit();
If (strSizeUnit == "cm" && strWeightUnit == "kg")
    is_message("Cubi", "Метрическая система", 1, 0);
Else
    is_message("Cubi", "Империческая система", 1, 0);
End If
```
