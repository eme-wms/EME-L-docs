# Класс 1CItem

Класс `1CItem` в языке EME-L — это интерфейс для чтения, записи и манипулирования объектами данных системы 1С:Предприятие версии 7.7. Предоставляет методы для навигации по выборкам справочников и документов, получения и установки атрибутов объектов, поиска элементов по коду, наименованию и произвольным атрибутам, создания новых элементов справочников и документов, а также работы с табличными частями документов.

Объекты класса создаются через конструктор с необязательным параметром — ссылкой на объект 1С, полученной методом `CreateObject` класса [`1C`](./1c). Используется для интеграции прикладной логики EME с учетными данными, хранящимися в базе 1С:Предприятие 7.7.

## Создание объекта

```EME-L
objItem = Object("1CItem");
objItem = Object("1CItem", ConnectionTo1C.CreateObject("Справочники.Склады"));
```

Конструктор без аргументов создаёт объект без привязки к данным 1С — ссылка устанавливается позже методом `Attach`. Конструктор с одним аргументом сразу привязывает объект к данным 1С.

| Конструктор | Аргументы | Возвращает | Описание |
|-------------|-----------|------------|----------|
| `1CItem()` | — | 1CItem | Создаёт объект интерфейса без привязки к объекту 1С. |
| `1CItem([объект_1С])` | объект_1С: ссылка на объект данных 1С:Предприятие (необязательный) | 1CItem | Создаёт объект интерфейса и привязывает его к объекту данных 1С, полученному методом `CreateObject` класса `1C`. |

## Привязка объекта 1С

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Attach(объект_1С)` | объект_1С: ссылка на объект данных 1С:Предприятие | Boolean | Устанавливает ссылку на объект данных 1С для текущего экземпляра. TRUE — привязка выполнена успешно, FALSE — не выполнена. |

## Навигация по выборке

Методы `SelectItems`/`GetItem` обеспечивают обход элементов справочника. `SelectItems` открывает выборку, `GetItem` последовательно позиционируется на следующий элемент; при достижении конца выборки возвращает FALSE.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SelectItems([режим])` | режим: Integer (1 — с учётом иерархии по умолчанию, 0 — без учёта) | Boolean | Выполняет выборку элементов справочника. TRUE — выборка выполнена, FALSE — нет. |
| `GetItem([режим])` | режим: Integer (1 — включать подчинённые элементы по умолчанию, 0 — не включать) | Boolean | Получает очередной элемент из выборки. TRUE — элемент получен, FALSE — достигнут конец выборки. |
| `GetCurrentItem()` | — | значение (ссылка/строка/целое) | Возвращает значение текущего позиционированного элемента справочника. Тип зависит от типа справочника. |

## Атрибуты

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetAttrib(имя_атрибута)` | имя_атрибута: String | значение (строка/целое/вещественное/дата/Boolean/ссылка) | Возвращает значение атрибута (реквизита) текущего объекта по имени из конфигуратора 1С. |
| `SetAttrib(имя_атрибута, значение)` | имя_атрибута: String, значение: соответствующего типа | Boolean | Устанавливает значение атрибута. TRUE — установлено, FALSE — нет. |

## Поиск элементов

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `FindByCode(код)` | код: String | Boolean | Поиск элемента справочника по коду. |
| `FindItem(значение)` | значение: строка/целое/ссылка/другое | Boolean | Поиск элемента справочника по значению. |
| `FindByDescr(наименование, [поиск_в_подчинении], [точное_соответствие])` | наименование: String; поиск_в_подчинении: Integer (1 — внутри родителя по умолчанию, 0 — по всему справочнику); точное_соответствие: Integer (1 — точное совпадение, 0 — по первым символам по умолчанию) | Boolean | Поиск элемента справочника по наименованию. |
| `FindByAttribute(имя_реквизита, значение, [область_поиска])` | имя_реквизита: String; значение: соответствующего типа; область_поиска: Integer (0 — в пределах подчинения по умолчанию, 1 — по всему справочнику) | Boolean | Поиск элемента справочника по значению произвольного реквизита. |

## Создание и запись

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `New()` | — | Boolean | Создаёт новый элемент справочника или новый документ. |
| `Write()` | — | Boolean | Сохраняет текущий элемент справочника или документ в базе 1С. |
| `MakeActions([режим_проведения], [дополнительный_параметр])` | режим_проведения: Integer (0 — без сдвига ТА по умолчанию, 1 — проводить непроведённый реальным временем, 2 — перепроводить проведённый реальным временем, 3 — проводить любой реальным временем); дополнительный_параметр: произвольный (например, строка «Документ проведён из EME») | Boolean | Проводит текущий документ с управлением точкой актуальности. |
| `SetNewCode(префикс)` | префикс: String | Boolean | Устанавливает новый код элемента справочника с указанным префиксом. |
| `NewLine()` | — | Boolean | Создаёт новую строку в табличной части текущего документа. |

## Периодические значения и перечисления

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `UseDate([дата])` | дата: DateTime (необязательный) | значение (дата/ссылка) | Устанавливает дату для получения периодических значений реквизитов документа. |
| `GetValueByIdentifier(идентификатор)` | идентификатор: String | значение перечисления (ссылка/целое) | Возвращает значение перечисления 1С по его строковому идентификатору из конфигуратора. |

## Иерархия и подчинение

Методы возвращают предыдущее значение на момент до выполнения — это позволяет сохранить и восстановить контекст выборки.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `UseOwner([владелец])` | владелец: ссылка или другой тип (необязательный) | значение (ссылка) | Устанавливает выборку по владельцу — элементу связанного справочника, которому подчинён данный. |
| `UseParent([группа])` | группа: ссылка или другой тип (необязательный) | значение (ссылка) | Устанавливает выборку по группе (родителю). |

## Примеры

Подключение к 1С и поиск элемента справочника по наименованию:

```EME-L
'Подключиться к 1С и создать объект справочника'
ConnectionTo1C = Object("1C");
OneCInitString = "/d\"C:\\DATABASE_1C\" /nПользователь /p";
ConnectionTo1C.Connect(0, OneCInitString);
objWarehouse1C = Object("1CItem",
    ConnectionTo1C.CreateObject("Справочники.Склады"));
'Найти склад по наименованию СВХ внутри текущего подчинения'
objWarehouse1C.FindByDescr("СВХ", 1, 1);
```

Создание нового документа с табличной частью:

```EME-L
'Создать новый документ и заполнить шапку'
objDoc1C = Object("1CItem",
    ConnectionTo1C.CreateObject("Документы.ПриходныйОрдерНаТовары"));
objDoc1C.New();
objDoc1C.SetAttrib("Склад", objWarehouse1C.GetCurrentItem());
objDoc1C.SetAttrib("Номер", "12353");
'Записать документ в базе 1С'
objDoc1C.Write();
```

Поиск элемента по произвольному реквизиту и чтение атрибута:

```EME-L
'Найти номенклатуру по артикулу по всему справочнику'
objGood1C = Object("1CItem",
    ConnectionTo1C.CreateObject("Справочники.Номенклатура"));
objGood1C.FindByAttribute("Артикул", "11623341", 1);
Name = objGood1C.GetAttrib("НаименноеПолное");
```
