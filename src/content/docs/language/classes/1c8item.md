# Класс 1C8Item

Класс `1C8Item` в языке EME-L — это интерфейс для чтения, записи и манипулирования объектами данных системы 1С:Предприятие версии 8.0. Предоставляет методы для навигации по выборкам справочников и документов, получения и установки атрибутов объектов, поиска элементов по коду, наименованию и произвольным атрибутам, создания новых элементов справочников и документов, а также работы с табличными частями документов.

Объекты класса `1C8Item` обычно получаются из методов класса [`1C`](./1c) (например, `1C.CreateObject`) или из других объектов `1C8Item` (`GetAttribAsRef`, `CreateItem`, `CreateDocument`, `Get`, `AddRow`), а не создаются напрямую через `Object()`. Вторая форма конструктора с параметром-ссылкой используется для явного связывания с уже созданным объектом 1С.

> Класс предназначен для интеграции прикладной логики EME с учетными данными, хранящимися в базе 1С:Предприятие 8.0. Для работы с 1С версии 7.7 используйте класс `1CItem`.

## Создание объекта

```EME-L
'Типичный путь — объект возвращает класс 1C'
objDoc = obj1C.CreateObject("Документы.ПриходныйОрдерНаТовары");
'objDoc — это объект 1C8Item, связанный с документом 1С'

'Прямое создание через Object() — используется редко'
objItem = Object("1C8Item");
objItem = Object("1C8Item", objRef);
```

Конструктор без аргументов создаёт несвязанный объект-обёртку — привязка к объекту 1С выполняется методом `Attach`. Конструктор с одним аргументом сразу связывается с переданной ссылкой, полученной методом `CreateObject` класса `1C`.

## Навигация по выборке

Методы `Select` и `SelectEx` переводят объект в режим выборки, после чего перебор выполняется методом `Next`. Выборка применима к справочникам и документам.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Select()` | — | Boolean | Активирует режим выборки. TRUE — активирован, FALSE — неудача. |
| `SelectEx(arg0)` | arg0: String (начальная_дата) | Boolean | Выборка документов с указанной начальной даты. |
| `SelectEx(arg0, arg1)` | arg0: String (начальная_дата), arg1: String (конечная_дата) | Boolean | Выборка документов за период. |
| `SelectEx(arg0, arg1, arg2)` | + arg2: String (упорядочивание) | Boolean | То же с упорядочиванием по указанному полю. |
| `Next()` | — | Boolean | Переход к следующему объекту. Перед вызовом объект должен быть переведён в режим выборки. TRUE — переход выполнен, FALSE — достигнут конец выборки или объект не в режиме выборки. |

## Атрибуты и ссылки

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetAttrib(arg0, arg1)` | arg0: String (имя_атрибута), arg1: значение-образец типа | String / Integer / Real / Empty | Возвращает значение атрибута. Тип результата определяется типом второго аргумента: строка → строка, целое → целое, вещественное → вещественное. Если имя пустое, возвращает Empty. |
| `GetAttribAsRef(arg0)` | arg0: String (имя_атрибута) | 1C8Item / Empty | Возвращает объект `1C8Item`, обёртывающий ссылочное значение атрибута. Если имя пустое, возвращает Empty. |
| `SetAttrib(arg0, arg1)` | arg0: String (имя_атрибута), arg1: значение | Empty | Устанавливает значение атрибута. Поддерживаются типы: String, Integer, Real, DateTime, Boolean. При пустом имени или неподдерживаемом типе генерируется ошибка. |
| `SetAttribAsRef(arg0, arg1)` | arg0: String (имя_атрибута), arg1: 1C8Item (объект_ссылка) | Empty | Устанавливает ссылочный атрибут. Второй параметр обязан быть ссылкой на объект 1С, иначе генерируется ошибка. |
| `GetRef()` | — | ссылка | Ссылка на текущий объект 1С. Используется при записи ссылочных полей в другие объекты. |
| `GetThis()` | — | ссылка | Ссылка на текущий объект. Применяется для объектов типа «Ссылка» при записи ссылочных полей методом `SetAttribAsRef`. |
| `IsEmpty()` | — | Boolean | TRUE — ссылка пустая, FALSE — ссылка установлена. |
| `SetWriteMode()` | — | Boolean | Переводит объект-ссылку в режим чтения-записи. Необходим для объектов типа «Ссылка» перед изменением их атрибутов. TRUE — активирован, FALSE — неудача. |
| `Attach(arg0)` | arg0: ссылка (объект_1С) | Boolean | Устанавливает ссылку на существующий объект 1С. TRUE — установлена, FALSE — неудача. |

## Поиск элементов справочника

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `FindByCode(arg0)` | arg0: String (код) | 1C8Item | Найденный элемент справочника по коду. |
| `FindByDescription(arg0)` | arg0: String (наименование) | 1C8Item / Empty | Поиск по наименованию. Если несколько элементов совпадают, будет найден один. Если наименование пустое, возвращает Empty. |
| `FindByAttrib(arg0, arg1)` | arg0: String (имя_атрибута), arg1: String (значение) | 1C8Item / Empty | Поиск по значению произвольного атрибута. Если совпадающих элементов несколько, будет найден один. Если имя или значение пустые, возвращает Empty. |

## Создание и запись объектов

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `CreateItem()` | — | 1C8Item | Создаёт новый элемент справочника. |
| `CreateDocument()` | — | 1C8Item | Создаёт новый документ. |
| `Write()` | — | Boolean | Записывает изменения текущего объекта в базу 1С. Применимо к справочникам и документам. TRUE — запись выполнена, FALSE — не выполнена. |
| `SetNewNumber(arg0)` | arg0: String (префикс) | Boolean | Устанавливает новый номер документа. TRUE — установлен, FALSE — неудача. |
| `Posting(arg0)` | arg0: String (тип_проведения) | Boolean | Проводит текущий документ. TRUE — проведён, FALSE — проведение не выполнено. |

## Примеры

Создание документа и заполнение табличной части:

```EME-L
'Получить объект документа из класса 1C'
objDoc = obj1C.CreateObject("Документы.ПриходныйОрдерНаТовары");
objDoc.SetNewNumber("ПРТ");
objDoc.SetAttrib("ДатаДокумента", is_today());

'Найти склад и установить ссылочный атрибут'
objWh = obj1C.CreateObject("Справочники.Склады");
objWh.FindByDescription("Центральный склад");
objDoc.SetAttribAsRef("Склад", objWh.GetThis());

'Добавить строки табличной части'
objLines = objDoc.Get(0);
For (i = 0; i < 3; i = i + 1)
    objRow = objLines.AddRow();
    objRow.SetAttrib("Количество", 10.0 + i);
End For

objDoc.Write();
objDoc.Posting("Проведение");
```

Перебор выборки справочника:

```EME-L
objGoods = obj1C.CreateObject("Справочники.Номенклатура");
If (objGoods.Select())
    While (objGoods.Next())
        Code = objGoods.GetAttrib("Код", "");
        Name = objGoods.GetAttrib("Наименование", "");
        'Code и Name — значения текущего элемента справочника'
    End While
End If
```

Чтение ссылочного атрибута и переход в режим записи:

```EME-L
'GetAttribAsRef возвращает новый объект 1C8Item'
objOwner = objItem.GetAttribAsRef("Владелец");
If (~objOwner.IsEmpty())
    objOwner.SetWriteMode();
    objOwner.SetAttrib("Описание", "Обновлено из EME");
    objOwner.Write();
End If
```
