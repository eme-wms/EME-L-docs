# Класс UR4

Класс `UR4` в языке EME-L предназначен для работы с RFID-сканером UR4 через TCP-соединение. Предоставляет механизм подключения к устройству по IP-адресу и порту, выполнения инвентаризации RFID-меток и получения данных о найденных метках.

Класс поддерживает настройку таймаута ожидания ответа, порогового значения уровня сигнала и фильтрацию по антеннам. Для работы требуется наличие библиотеки `UHFAPI.dll`. Объект создаётся с указанием IP-адреса и порта устройства, опционально с таймаутом, порогом сигнала и списком антенн. Используется в прикладных скриптах EME-L для интеграции с RFID-оборудованием и автоматизации сбора данных с RFID-метками.

## Создание объекта

Класс `UR4` имеет четыре конструкторные перегрузки. В документированном реестре `IMPLEMENT_CTOR` описаны формы с 2, 3 и 4 аргументами; тело конструктора фактически принимает и пятый аргумент — список антенн.

```EME-L
'Подключение к сканеру по IP-адресу и порту'
objUR4 = Object("UR4", "192.168.1.100", 9090);

'Та же конфигурация с явным таймаутом 5000 мс'
objUR4 = Object("UR4", "192.168.1.100", 9090, 5000);

'С таймаутом и порогом сигнала'
objUR4 = Object("UR4", "192.168.1.100", 9090, 5000, -75.0);

'С ограничением сканирования антеннами 1 и 2 (hex-список через запятую)'
objUR4 = Object("UR4", "192.168.1.100", 9090, 5000, -75.0, "1,2");
```

Если IP-адрес задан пустой строкой, используется адрес по умолчанию. Если порт не передан, используется порт по умолчанию. Таймаут и порог сигнала при отсутствии также заменяются системными значениями по умолчанию. Список антенн — строка с номерами антенн в шестнадцатеричном виде, разделёнными запятой; при его задании в `GetData` записываются только метки от указанных антенн.

## Подключение и отключение

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Connect()` | — | Boolean | Устанавливает TCP-подключение к сканеру по заданным IP-адресу и порту. Если соединение уже установлено, возвращает TRUE без повторного подключения. TRUE — подключение установлено или уже существует; FALSE — не удалось установить подключение. |
| `Disconnect()` | — | Boolean | Выполняет отключение от сканера. TRUE — отключение выполнено (или функция отключения доступна в библиотеке); FALSE — в библиотеке отсутствует функция отключения. |

## Инвентаризация и отладка

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetData(query)` | query: Query (по ссылке) | Boolean | Выполняет инвентаризацию RFID-меток и заполняет переданный объект `Query` данными о найденных метках. Перед записью очищает существующие данные в запросе, автоматически подключается к сканеру, выполняет инвентаризацию и отключается. Поля запроса создаются автоматически: `Id` (String), `Signal` (String), `Antenna` (String), `User` (String), `TID` (String). TRUE — операция завершена (инвентаризация выполнена или не запущена, запрос может быть пустым); FALSE — не удалось подключиться к сканеру или передан недействительный объект Query. |
| `SetDebug(enable)` | enable: Boolean | Empty | Включает или отключает режим отладки объекта UR4. При включенном режиме в лог записывается дополнительная информация о работе сканера: данные антенн, параметры найденных меток, причины фильтрации. |

## Примеры

Сканирование меток и вывод результата:

```EME-L
'Создать объект UR4 с явным адресом, портом и таймаутом'
objUR4 = Object("UR4", "192.168.1.100", 9090, 5000);

'Подключиться к сканеру'
If (objUR4.Connect())
    objQuery = Object("Query");
    'Выполнить инвентаризацию и заполнить запрос'
    If (objUR4.GetData(objQuery))
        'Обработать найденные метки'
        Loop (objQuery)
            strId = objQuery.GetData("Id");
            strSignal = objQuery.GetData("Signal");
            strAntenna = objQuery.GetData("Antenna");
        End Loop
    End If
    objUR4.Disconnect();
End If
```

Сканирование только через антенны 1 и 2 с фильтрацией по уровню сигнала:

```EME-L
'Сканер с таймаутом 5000 мс, порогом -75.0 и ограничением антенн 1,2'
objUR4 = Object("UR4", "192.168.1.100", 9090, 5000, -75.0, "1,2");
objUR4.SetDebug(TRUE);

objQuery = Object("Query");
If (objUR4.GetData(objQuery))
    nTags = objQuery.GetNoOfLines();
End If
```
