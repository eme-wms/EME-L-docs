# Класс SmartPointer

Класс `SmartPointer` в языке EME-L — умный указатель на объект, обеспечивающий совместное владение объектом через механизм `shared_ptr`. Позволяет создавать экземпляры других классов EME-L по имени класса и передавать их между переменными и объектами, не заботясь об освобождении памяти: объект автоматически удаляется, когда уничтожается последний `SmartPointer`, который на него ссылается.

Поддерживает два способа создания: создание нового объекта заданного класса с передачей параметров его конструктору либо разделение владения с уже существующим объектом `SmartPointer`. Все вызовы методов, выполненные через `SmartPointer`, перенаправляются целевому объекту — сам класс не объявляет собственных методов.

Используется в прикладных скриптах EME-L для передачи сложных объектов между функциями и методами, а также для организации коллекций объектов с автоматическим управлением временем жизни (например, элементы [ArrayOfObjects](./arrayofobjects.md) хранятся именно как `SmartPointer`).

Объект класса `SmartPointer` создаётся через `Object()` и не привязан к контексту диалога или браузера — это самостоятельный класс-обёртка над произвольным объектом EME-L.

## Создание объекта

Класс `SmartPointer` имеет две перегрузки конструктора (вариативную и одноаргументную) — по числу `IMPLEMENT_CTOR`. Конструкторы в C++ объявлены с `argCount = -1` (вариативный, минимум один аргумент) и `argCount = 1` (фиксированный).

### Конструктор 1 — создание нового объекта

`SmartPointer(className[, arg1[, arg2[, ...]]])` — создаёт объект указанного строкой `className` класса и сохраняет на него умный указатель (`shared_ptr`). Созданный объект принадлежит новому экземпляру `SmartPointer`; при уничтожении последнего владельца объект автоматически удаляется.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| className | String | Да | Имя класса создаваемого объекта. Должно соответствовать зарегистрированному в проекте имени класса EME-L (например `MD5`, `AnvizFace`, `File`). |
| arg1, arg2, ... | произвольный | Нет | Параметры, передаваемые конструктору создаваемого объекта. Тип и количество параметров определяются целевым классом. |

**Возвращает**: новый объект `SmartPointer`, владеющий созданным объектом.

```EME-L
'Создаёт объект MD5 и сохраняет на него умный указатель'
sp = Object("SmartPointer", "MD5");
```

```EME-L
'Та же перегрузка с параметрами конструктора целевого класса'
sp = Object("SmartPointer", "AnvizFace", "192.168.1.50", 5010, 1);
```

**Вызов без аргументов недопустим**: в C++-теле конструктора срабатывает `too_rare()` (требуется минимум один аргумент).

### Конструктор 2 — разделение владения

`SmartPointer(sourceSmartPointer)` — создаёт новый объект `SmartPointer`, разделяющий владение объектом с существующим указателем `SmartPointer`. Оба указателя ссылаются на один и тот же целевой объект; при уничтожении последнего владельца объект удаляется.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| sourceSmartPointer | SmartPointer (ссылка) | Да | Существующий объект `SmartPointer`, владение которым будет разделено. |

**Возвращает**: новый объект `SmartPointer`, ссылающийся на тот же целевой объект.

```EME-L
'Создаёт второй SmartPointer, ссылающийся на тот же целевой объект'
sp2 = Object("SmartPointer", sp);
```

### Особенности разрешения аргумента

В одной C++ точке входа реализованы обе перегрузки. Разрешение выполняется по типу `args[0]`:

- Если `args[0]` — объект `SmartPointer`, новый указатель разделяет владение целевым объектом источника.
- Если `args[0]` **не** является `SmartPointer`, его строковое представление интерпретируется как имя класса и создаётся новый объект этого класса **без дополнительных параметров**. Остальные аргументы (`args[1]`, `args[2]`, ...) в этом случае передаются конструктору целевого класса.

Таким образом, вызов `Object("SmartPointer", "MD5")` формально проходит через ту же ветвь кода, что и вызов с одним строковым аргументом — интерпретируется как «имя класса MD5, без дополнительных параметров».

Если создание объекта завершилось неудачей, в C++-ядре срабатывает `ASSERT(false)` (помечено комментарием «на данный момент этот код никогда не будет работать») и вызывается `smart_error("Не удалось создать объект %s", ...)`.

## Методы

Класс `SmartPointer` **не объявляет собственных методов**: в `i_SmartPointer.cpp` отсутствуют `IMPLEMENT_METHOD` и `IMPLEMENT_MTYPED`. Все вызовы, адресованные объекту `SmartPointer` из EME-L, перенаправляются целевому объекту. Метод, фактически вызываемый при обращении `sp.Method(...)`, определяется интерфейсом объекта, на который ссылается указатель.

Например, если `sp` владеет объектом `MD5`, допустимо `sp.Calculate(str)` — вызов будет перенаправлен методу `MD5.Calculate`. Аналогично, если `SmartPointer` ссылается на объект `File`, доступны методы `GetFilePath`, `GetData`, `PutData` и остальные методы класса `File`.

## Примеры

> **Примечание.** В выгрузке прикладных скриптов EME-L (`Базовая выгрузка проекта/Классы/*.txt`) прямых вызовов `Object("SmartPointer", ...)` не обнаружено. Класс используется преимущественно опосредованно — через класс `ArrayOfObjects`, элементы которого хранятся как `SmartPointer`. Примеры ниже синтетические, но следуют канонической семантике класса и корректному синтаксису EME-L.

Создание объекта и разделение владения:

```EME-L
'Первый SmartPointer создаёт объект MD5'
sp = Object("SmartPointer", "MD5");
Hash = sp.Calculate("password");
'sp перенаправляет вызов методу MD5.Calculate'

'Второй SmartPointer разделяет владение тем же объектом'
sp2 = Object("SmartPointer", sp);
Hash2 = sp2.Calculate("password");
'sp и sp2 указывают на один и тот же объект MD5'
```

Передача параметров конструктору целевого класса:

```EME-L
'Создаёт объект AnvizFace и сразу передаёт ему IP, порт, deviceId'
sp = Object("SmartPointer", "AnvizFace", "192.168.1.50", 5010, 1);
```
