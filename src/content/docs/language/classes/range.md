# Класс Range

Класс `Range` в языке EME-L — класс для работы с одной или несколькими ячейками шаблона отчёта EME DB. Представоставляет программный доступ к ячейкам отчёта: получение и изменение значений, управление визуальным оформлением, навигация по бандам, строкам и столбцам, а также доступ к источникам данных, связанным с ячейками (биндинг).

Основные возможности:

- Выделение ячеек: одна ячейка, множество ячеек, столбец (вертикальный банд), строка банда, ячейка по имени или текущее выделение в отчёте.
- Чтение и запись значений ячеек с автоматическим преобразованием типов (строка, целое число, вещественное число, дата/время и др.).
- Управление цветами: фон (`GetBackColor`/`SetBackColor`), текст (`GetTextColor`/`SetTextColor`), рамка (`GetFrameColor`/`SetFrameColor`) — для отдельной ячейки, всех ячеек или диапазона через массив цветов.
- Управление видимостью, шириной, высотой (только при `REPORT_CHANGE_CELL_SIZE_IN_META`), границами и выравниванием текста ячеек.
- Получение адресной информации: номер строки банда (`GetLine`), номера строк родительских бандов (`GetParentLine`), вертикальный индекс (`GetVIndex`), номер строки вертикального банда (`GetVLine`), номер ячейки в общем списке (`GetCellNo`), имя ячейки (`GetCellName`).
- Навигация и выделение в окне отчёта: `Select`, `FixArea`, `GetSelectedCell`.
- Доступ к источнику привязки: объекты запроса (`FindQuery`), поля источника (`GetQueryData`, `FindBindSourceField`), номера строк оригинального запроса (`FindQueryLine`), источник связывания (`FindBindSource`, `FindBindSourceLine`).
- Клонирование выделения (`Clone`), проверка на пустоту (`IsEmpty`), очистка ячеек (`Clear`), удаление ячеек со сдвигом влево (`CellGoAway`, только при `REPORT_CALC_TEXT_WIDTH_FOR_CELL`).

Класс доступен только при включённой поддержке отчётов (C++ compile flag `I_REPORT`). Объекты `Range` создаются системой внутри контекста отчёта или возвращаются методами `Report.GetCell` / `Report.GetRow` / `Report.GetColumn`. Самостоятельное создание через `Object("Range")` возможно, но контекстом служит активное окно отчёта.

## Создание объекта

Конструктор без аргументов создаёт пустой объект `Range`. Как правило, объекты этого класса получают не прямым конструированием, а как результат методов `Report.GetCell`, `Report.GetRow`, `Report.GetColumn`, `Report.GetSelectedCell`, либо клонированием существующего `Range` через `Clone`.

```EME-L
'Создание пустого объекта Range, привязанного к активному окну отчёта'
objRange = Object("Range");
```

```EME-L
'Типичный способ: получить Range ячейки по имени из объекта отчёта'
objRange = objReport.GetCell("price_total");
```

## Состав выделения

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetCount()` | — | Integer | Количество ячеек в текущем выделении. Если индекс обновить не удалось — 0. |
| `Clone()` | — | Range (ссылка) | Полная копия объекта `Range`, включая правила выделения и состав ячеек. Возвращаемый объект — глобальный (создан через `CreateGObject`, его время жизни управляется `Alive`). |
| `IsEmpty()` | — | Boolean | TRUE, если все ячейки выделения пусты. |
| `IsEmpty(arg0)` | arg0: Integer (индекс) | Boolean | TRUE, если ячейка с указанным индексом пуста. |
| `Clear()` | — | Boolean | Очищает все ячейки выделения (заполняет нулевым буфером, 100 байт). |
| `Clear(arg0)` | arg0: Integer (индекс) | Boolean | Очищает ячейку с указанным индексом. |
| `Alive()` | — | Empty | Продлевает время жизни глобального объекта `Range`, предотвращая его автоматическое удаление. |

## Получение подчинённых Range

Эти методы создают новый объект `Range` на основе текущего выделения и возвращают ссылку на него.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetCell(arg0)` | arg0: Integer (индекс) | Range (ссылка) | Новый `Range`, содержащий одну ячейку из текущего выделения по её индексу. |
| `GetCell([arg0[, arg1[, arg2…]]])` | arg0: String (имя ячейки), arg1: Integer/Any (вертикальный индекс, необязательный), arg2…: Integer (номера строк родительских бандов, необязательные, до 10) | Range (ссылка) | Новый `Range` для ячейки, заданной по имени, с уточнением вертикального индекса и строк родительских бандов. Без аргументов диспетчер передаёт пустое имя ячейки, что соответствует критерию «любая ячейка» — итоговое выделение зависит от остальных правил обхода. |
| `GetRow(arg0[, arg1…])` | arg0: String (имя банда), arg1…: Integer (номера строк родительских бандов, необязательные, до 10) | Range (ссылка) | Новый `Range`, содержащий строку заданного банда с указанными строками родительских бандов. |
| `GetRow([arg0])` | arg0: Integer (индекс ячейки, по умолчанию 0) | Range (ссылка) | Новый `Range`, содержащий строку отчёта, в которой находится ячейка с заданным индексом. |
| `GetColumn()` | — | Range (ссылка) | Новый `Range`, содержащий ячейки столбца (вертикального банда), к которому относится первая ячейка выделения. |
| `GetColumn(arg0)` | arg0: Integer/Any | Range (ссылка) | **Внимание — фактически это overload для вертикальной строки, а не индекса ячейки.** Диспетчер передаёт `arg0` в перегрузку `GetColumn(CIRange&, COleVariant& vline)`, которая обрабатывает его как вертикальный идентификатор строки (`vline.oleline`), а не как индекс ячейки в выделении. Перегрузка `GetColumn(CIRange&, int index)`, выбирающая столбец по индексу ячейки, существует в C++, но из скрипта недостижима — диспетчер к ней не обращается. Для получения столбца конкретной ячейки сначала получите `Range` этой ячейки через `GetCell(индекс)`, затем вызовите `GetColumn()` без аргументов. |
| `GetSelectedCell()` | — | Range (ссылка) | Новый `Range` с ячейкой, выделенной в отчёте в данный момент. Требует включённого режима выделения (`is_selection_mode()`). Пустой объект, если выделение отсутствует. |
| `GetRect()` | — | Rect (ссылка) | Объект `Rect` с координатами первой ячейки выделения. |
| `GetRect(arg0)` | arg0: Integer (индекс) | Rect (ссылка) | Объект `Rect` с координатами ячейки по индексу. |

## Значения ячеек

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Get()` | — | Array (ссылка) или скаляр | Значения всех ячеек выделения. Если ячеек несколько — объект `Array`; если одна — её значение. |
| `Get(arg0)` | arg0: Integer (индекс) | скаляр | Значение ячейки по индексу. Тип зависит от типа ячейки: строка, целое, вещественное, дата/время. |
| `Put(arg0)` | arg0: скаляр или Array (ссылка) | Boolean | Записывает значение в первую ячейку. При передаче `Array` расписывает его элементы по ячейкам выделения. TRUE при успехе. |
| `Put(arg0, arg1)` | arg0: Integer (индекс), arg1: скаляр | Boolean | Записывает значение в ячейку по индексу. |
| `DirectPut(arg0)` | arg0: скаляр или Array (ссылка) | Boolean | То же, что `Put`, но запись напрямую в буфер ячейки, минуя механизм фиксации изменений. |
| `DirectPut(arg0, arg1)` | arg0: Integer (индекс), arg1: скаляр | Boolean | Прямая запись в ячейку по индексу. |

## Цвета

Для каждого цветового канала (фон, текст, рамка) предусмотрен симметричный набор методов: без аргументов — значение первой ячейки; один аргумент-индекс — значение конкретной ячейки; три аргумента `(массив, начало, конец)` — заполнение/чтение диапазона из массива `Array`. Цвета передаются как целочисленный `COLORREF` (например, результат `is_rgb()`).

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetBackColor()` | — | Integer | Цвет фона первой ячейки выделения (COLORREF). |
| `GetBackColor(arg0)` | arg0: Integer (индекс) | Integer | Цвет фона ячейки по индексу. |
| `GetBackColor(arg0, arg1, arg2)` | arg0: Array (по ссылке), arg1: Integer (начало), arg2: Integer (конец) | Integer | Заполняет массив цветами фона ячеек диапазона; возвращает цвет последней ячейки диапазона. |
| `SetBackColor(arg0)` | arg0: Integer (цвет) | Boolean | Устанавливает цвет фона для всех ячеек выделения. |
| `SetBackColor(arg0, arg1)` | arg0: Integer (индекс), arg1: Integer (цвет) | Boolean | Устанавливает цвет фона для ячейки по индексу. |
| `SetBackColor(arg0, arg1, arg2)` | arg0: Array цветов, arg1: Integer (начало), arg2: Integer (конец) | Boolean | Устанавливает цвет фона диапазона из массива. Если массив короче диапазона, цвета перебираются циклически. |
| `GetTextColor()` / `GetTextColor(arg0)` / `GetTextColor(arg0, arg1, arg2)` | симметрично `GetBackColor` | Integer / Boolean | Цвет текста ячеек. |
| `SetTextColor(arg0)` / `SetTextColor(arg0, arg1)` / `SetTextColor(arg0, arg1, arg2)` | симметрично `SetBackColor` | Boolean | Цвет текста ячеек. |
| `GetFrameColor()` / `GetFrameColor(arg0)` / `GetFrameColor(arg0, arg1, arg2)` | симметрично `GetBackColor` | Integer / Boolean | Цвет рамки ячеек. |
| `SetFrameColor(arg0)` / `SetFrameColor(arg0, arg1)` / `SetFrameColor(arg0, arg1, arg2)` | симметрично `SetBackColor` | Boolean | Цвет рамки ячеек. |

## Адресная информация

Все методы этого раздела работают в двух режимах: без аргумента — для всех ячеек (возвращает `Array` при нескольких ячейках, скаляр при одной); с индексом — для конкретной ячейки. Возвращаемые строковые идентификаторы строк бандов конвертируются через `CIReport::GetDBLine`, если отчёт связан с источником данных.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetLine()` / `GetLine(arg0)` | arg0: Integer (индекс) | Array (ссылка) или Integer | Номер строки банда, которому принадлежит ячейка. `NULL_REF`, если ячейка вне банда. |
| `GetParentLine()` / `GetParentLine(arg0)` | arg0: Integer (индекс) | Array (ссылка) или Integer | Номер строки родительского банда. `NULL_REF`, если родительского банда нет. |
| `GetVIndex()` / `GetVIndex(arg0)` | arg0: Integer (индекс) | Array (ссылка) или Integer | Вертикальный индекс ячейки (номер колонки в вертикальном банде). -1, если ячейка не входит в вертикальный банд. |
| `GetVLine()` / `GetVLine(arg0)` | arg0: Integer (индекс) | Array (ссылка) или Integer | Номер строки вертикального банда. `NULL_REF`, если ячейка не в вертикальном банде. |
| `GetCellNo()` / `GetCellNo(arg0)` | arg0: Integer (индекс) | Array (ссылка) или Integer | Номер ячейки в общем списке ячеек отчёта. |
| `GetCellName()` / `GetCellName(arg0)` | arg0: Integer (индекс) | Array (ссылка) или String | Имя ячейки (`tool_name` из параметров ячейки). Пустая строка, если имя не задано. |

## Навигация и отладка

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Select()` | — | Integer | Выделяет первую ячейку в окне отчёта. Возвращает номер ранее выделенной ячейки, либо -1. |
| `Select(arg0)` | arg0: Integer (индекс) | Integer | Выделяет ячейку по индексу. |
| `FixArea()` | — | Boolean | Фиксирует область отображения по первой ячейке. **Только при `REPORT_VERSION >= 1.8`.** |
| `FixArea(arg0)` | arg0: Integer (индекс) | Boolean | Фиксирует область отображения по ячейке с индексом. |
| `Dump(arg0)` | arg0: String (имя файла) | Boolean | Выводит дамп источника биндинга для первой ячейки. Используется для отладки. |
| `Dump(arg0, arg1)` | arg0: Integer (индекс), arg1: String (имя файла) | Boolean | Дамп источника биндинга для ячейки по индексу. |
| `GetTextWidth(arg0, arg1)` | arg0: Integer (индекс), arg1: String (текст) | Integer | Вычисляет ширину, достаточную для размещения текста в ячейке. **Только при `REPORT_CALC_TEXT_WIDTH_FOR_CELL`.** |
| `GetTextWidth(arg0, arg1, arg2)` | arg0: Integer (индекс), arg1: String (текст), arg2: Integer (макс. ширина) | Integer | То же с ограничением максимальной ширины. |
| `CellGoAway()` | — | Boolean | Удаляет первую ячейку, сдвигая все правые ячейки влево. **Только при `REPORT_CALC_TEXT_WIDTH_FOR_CELL`.** |
| `CellGoAway(arg0)` | arg0: Integer (индекс) | Boolean | Удаляет ячейку по индексу со сдвигом. |

## Примеры

Чтение и запись значения ячейки по имени:

```EME-L
'Получить Range ячейки и записать в неё новое значение'
objRange = objReport.GetCell("price_total");
If (objRange.GetCount() > 0)
    objRange.Put("1 240.00");
End If
```

Закрасить фон всех ячеек строки банда цветом:

```EME-L
'Выделить строку банда и установить цвет фона'
objRow = objReport.GetRow("Detail");
objRow.SetBackColor(is_rgb(255, 235, 200));
```
