# Класс FileSystem

Класс `FileSystem` в языке EME-L предназначен для работы с файловыми системами различных типов: локальной дисковой, FTP (включая FTPS с шифрованием) и WinSCP. Предоставляет унифицированный интерфейс для подключения к хранилищам файлов, выбора файлов по маске, последовательного перебора выбранных файлов, чтения и записи содержимого файлов, а также копирования, перемещения и удаления файлов. Поддерживает работу с бинарными данными через объекты `CDataStorage`.

Объект класса `FileSystem` создаётся через `Object()` без параметров. Перед выполнением файловых операций необходимо установить подключение методом `Connect`. Большинство операций возвращают пустую строку при успехе или строку с описанием ошибки.

## Создание объекта

Конструктор единственный — без аргументов. После создания объект не привязан ни к какой файловой системе и требует вызова `Connect`.

```EME-L
i_FS = Object("FileSystem");
'Клиент создан, но не подключён — далее вызовите Connect'
```

## Подключение и состояние

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Connect(arg0, arg1)` | arg0: String (строка подключения), arg1: Boolean (создавать каталоги) | String | Подключает клиента к файловой системе. Пустая строка — успех, иначе текст ошибки. Если клиент уже подключён, генерируется ошибка. |
| `Disconnect()` | — | String | Отключает от файловой системы и освобождает ресурсы. Пустая строка — успех. Если клиент не подключён, генерируется ошибка. |
| `IsConnected()` | — | Boolean | TRUE — клиент подключён, FALSE — подключение отсутствует. |
| `GetLastError()` | — | String | Текст последней ошибки. Пустая строка, если ошибок не было. |

### Строка подключения `Connect`

Тип файловой системы определяется префиксом строки подключения (всё до первого двоеточия, сравнение без учёта регистра):

| Префикс | Драйвер | Формат строки после префикса |
|---------|---------|------------------------------|
| `FTP:` | FTP | `ftp://user:password@host:port/path` |
| `FTPS:` | FTP + TLS | `ftps://user:password@host:port/path` (принудительно включаются SSL/TLS, пассивный режим, отключается проверка сертификата) |
| `WINSCP:` | WinSCP | `<параметры open>;<папка на сервере>;<локальная папка>` |
| `EME:` / `EMEL:` | — | Зарезервированы, в текущей версии вызывают внутреннюю ошибку (не поддерживаются). |
| без префикса / нераспознан | Дисковый драйвер | Полный или относительный путь к каталогу, например `C:\Data` или `.\Files`. Для путей, содержащих двоеточие, но не подпадающих под перечисленные префиксы, также выбирается дисковый драйвер. |

Параметр `arg1` (создавать каталоги) действует на дисковый и WinSCP-драйверы: `TRUE` — создать недостающие каталоги, `FALSE` — вернуть ошибку при отсутствии пути (поведение по умолчанию).

## Выборка и перебор файлов

Выборка выполняется по маске в текущем каталоге подключения. После вызова `SelectFiles` список доступен для навигационного перебора.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SelectFiles(arg0)` | arg0: String (маска) | String | Выбирает файлы по маске (например `*.txt` или `data_*.xml`). Пустая строка — успех. Для WinSCP файлы предварительно скачиваются с удалённого сервера в локальную папку и удаляются там. |
| `SetFirstLine()` | — | Empty | Устанавливает указатель на первый файл выборки. |
| `IsValidLine()` | — | Boolean | TRUE — текущий файл существует и доступен, FALSE — список пуст или достигнут конец. |
| `SetNextLine()` | — | Empty | Сдвигает указатель на следующий файл выборки. |
| `GetFileName()` | — | String | Имя текущего файла выборки. Пустая строка, если указатель не установлен. |

При переборе дисковой файловой системы каталоги и файлы нулевой длины пропускаются; также проверяется доступность файла на чтение/запись (чтобы избежать выбора файлов, которые ещё записываются).

## Чтение и запись данных

Данные файлов передаются через объекты `CDataStorage`.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetData(arg0)` | arg0: CDataStorage (по ссылке) | String | Читает содержимое текущего файла выборки в переданный объект. Пустая строка — успех. |
| `GetData(arg0, arg1)` | arg0: String (имя файла), arg1: CDataStorage (по ссылке) | String | Читает содержимое указанного файла. Путь относительно каталога подключения. |
| `PutData(arg0, arg1)` | arg0: String (имя файла), arg1: CDataStorage (по ссылке) | String | Записывает данные из объекта в файл. Существующий файл перезаписывается. Пустая строка — успех. |

Чтение и запись FTP выполняются в бинарном режиме (`FTP_TRANSFER_TYPE_BINARY`).

## Операции с файлами

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `CopyFile(arg0, arg1)` | arg0: String (имя файла), arg1: FileSystem (целевой объект, по ссылке) | String | Копирует файл в целевую файловую систему с сохранением имени. Целевой объект должен быть подключён. |
| `MoveFile(arg0, arg1)` | arg0: String (имя файла), arg1: FileSystem (целевой объект, по ссылке) | String | Перемещает файл: копирует в целевую систему, затем удаляет из исходной. |
| `DeleteFile(arg0)` | arg0: String (имя файла) | String | Удаляет файл из текущего каталога подключения. Пустая строка — успех. |

## Примеры

Подключение к FTP, запись файла и отключение:

```EME-L
i_FS = Object("FileSystem");
Result = i_FS.Connect("FTP:ftp://user:pass@host:21/inbox", TRUE);
If (Result != "")
    is_message("FileSystem", "Ошибка подключения: " + Result);
Else
    Result = i_FS.PutData("export.xml", d_Data);
    If (Result != "")
        is_message("FileSystem", "Ошибка записи: " + Result);
    End If
    i_FS.Disconnect();
End If
```

Выборка и перебор файлов по маске с чтением содержимого:

```EME-L
i_FS = Object("FileSystem");
Result = i_FS.Connect("WINSCP:ftps://eme.wms:pass@host:990 -certificate=*;inbox;C:\\WMS\\inbox", FALSE);
If (Result == "")
    Result = i_FS.SelectFiles("*.xml");
End If
If (Result == "")
    i_FS.SetFirstLine();
    While (i_FS.IsValidLine())
        FileName = i_FS.GetFileName();
        d_File = Object("DataStorage");
        Result = i_FS.GetData(d_File.Get());
        If (Result != "")
            Break
        End If
        'd_File содержит бинарные данные файла FileName'
        i_FS.SetNextLine();
    End While
End If
```

Перемещение файла между двумя файловыми системами:

```EME-L
i_Src = Object("FileSystem");
i_Dst = Object("FileSystem");
i_Src.Connect("C:\\Inbox", FALSE);
i_Dst.Connect("C:\\Archive", FALSE);
Result = i_Src.MoveFile("report.xml", i_Dst);
'Файл скопирован в C:\Archive\report.xml и удалён из C:\Inbox'
```
