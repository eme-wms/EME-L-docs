# Класс ExpImp

Класс `ExpImp` в языке EME-L — это интерфейс для чтения файлов ядерного экспорта/импорта системы EME. Предоставляет методы для открытия экспортных файлов, последовательного извлечения записей с заполнением объектов `Query`, а также получения метаданных файла (версия, филиал, дата, время).

Объект класса `ExpImp` создаётся через `Object()` и не привязан к контексту диалога или браузера — это самостоятельный класс для программного импорта данных из файлов экспорта, созданных ядром системы или другими филиалами. Поддерживает чтение истории экспорта через доступ к информации о предыдущем файле.

## Создание объекта

```EME-L
objExpImp = Object("ExpImp");
objExpImp = Object("ExpImp", false);
```

Конструктор без аргументов создаёт объект с 64-битным диапазоном ссылок по умолчанию. Необязательный флаг `use64BitRange` явно задаёт разрядность ссылочных полей: `true`/`"1"` — 64-битный диапазон (по умолчанию), `false`/`"0"` — 32-битный. Начиная с версии ядра 52.0 аргумент игнорируется — всегда используется 64-битный режим.

## Чтение файла и записей

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `LoadFile(filePath)` | filePath: String | String | Открывает файл экспорта для чтения. При успехе возвращает пустую строку, при ошибке — текст в формате `Ошибка <код>`. Если файл уже был открыт, предыдущий закрывается автоматически. |
| `ExtractNextRecord(query)` | query: Query (по ссылке) | Boolean | Извлекает следующую запись и заполняет переданный `Query` данными. Поля автоматически добавляются с соответствующими типами; для полей «Ключи» и «Флаги» применяется специальная обработка, для ссылочных полей — коррекция порядка байт. `TRUE` — запись извлечена, `FALSE` — записи закончились или ошибка. |
| `GetRecordName()` | — | String | Имя текущей записи, извлечённой методом `ExtractNextRecord`. Пустая строка, если запись ещё не извлекалась. |
| `GetExportType()` | — | String | Тип экспорта по последним двум символам имени файла: `"s1"` или `"s2"` для системных экспортных файлов. Пустая строка, если файл не системный. |

`ExtractNextRecord` заполняет `Query` построчно: каждое извлечение добавляет новую порцию строк и полей записи. Правила определения типов полей при чтении:

- Поля «Ключи» обрабатываются как 64-битное целое (`INT64_ATTRIBUTE`), «Флаги» — как 32-битное целое (`INT_ATTRIBUTE`).
- Поля с атрибутами `FLAGS_ATTRIBUTE` и `ARRAY_ATTRIBUTE` приводятся к `INT_ATTRIBUTE`.
- Ссылочные поля приводятся к `INT64_ATTRIBUTE`, для них выполняется коррекция порядка байт (обмен местами двух `long`-значений).
- Массивы ссылок (`ARRAY_OF_REFERENCE`) не поддерживаются — такие поля пропускаются.
- Текстовые поля (`TEXT_STRING_ATTRIBUTE`) без явной длины получают размер по умолчанию 256 байт.
- Поля с неподдерживаемым типом атрибута получают размер по умолчанию 64 байта.
- Поля переменной длины и хранилища данных (`DATA_STORAGE_ATTRIBUTE`, начиная с версии файла `IMPORT_FILE_VERSION4`) считывают длину из потока.

## Метаданные файла

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetVersion()` | — | Integer | Версия формата файла экспорта. |
| `GetFilialNo()` | — | Integer | Номер филиала, сформировавшего файл. |
| `GetFilialStatus()` | — | Integer | Статус филиала-источника. |
| `GetFileName()` | — | String | Имя файла экспорта из заголовка. |
| `GetDate()` | — | Date | Дата формирования файла экспорта. |
| `GetTime()` | — | Time | Время формирования файла экспорта. |

## История экспорта

Методы возвращают метаданные предыдущего файла экспорта, записанные в заголовке текущего.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetPrevFileName()` | — | String | Имя предыдущего файла экспорта по истории. Пустая строка, если информация отсутствует. |
| `GetPrevDate()` | — | Date | Дата предыдущего экспорта по истории. |
| `GetPrevTime()` | — | Time | Время предыдущего экспорта по истории. |

## Примеры

Последовательное чтение записей из файла экспорта:

```EME-L
objExpImp = Object("ExpImp", false);
Result = objExpImp.LoadFile("D:\\Import\\export.dat");
If (Result != "")
    is_message("Импорт", "Не удалось открыть файл: " + Result, 1, 3);
    Return 0;
End If

Query = Object("Query");
Query.Create();
While (objExpImp.ExtractNextRecord(Query))
    RecordName = objExpImp.GetRecordName();
    'Обработка записи RecordName — поля в Query'
    Query.Delete();
    Query.Create();
End While
```

Получение метаданных файла:

```EME-L
objExpImp = Object("ExpImp");
Result = objExpImp.LoadFile("D:\\Import\\export.dat");
If (Result == "")
    Version = objExpImp.GetVersion();
    FilialNo = objExpImp.GetFilialNo();
    ExportType = objExpImp.GetExportType();
    PrevFile = objExpImp.GetPrevFileName();
End If
```
