# Класс Trace

Класс `Trace` в языке EME-L — класс для трассировки (логирования) строковых сообщений в процессе выполнения скриптов EME-L. Предоставляет механизм накопления текстовых строк в именованном буфере трассировки с возможностью последующего просмотра, извлечения и очистки истории.

Объект создаётся с указанием уникального имени трассировщика, которое используется для идентификации буфера в глобальном менеджере трассировки. Основные возможности: добавление строк методом `AddLine`, получение всего содержимого единой строкой через `GetAsSingleString`, построчный перебор истории в прямом и обратном направлениях, очистка буфера `Empty` и открытие содержимого в окне браузера `OpenInBrowser`.

Используется для отладки, диагностики выполнения скриптов и сбора оперативной информации о ходе работы программы. Буфер трассировки существует в течение жизни объекта и автоматически освобождается при его уничтожении.

> **Версия ядра.** Класс зарегистрирован в ядре 16.49 и выше (`KERNEL_16_49`). Большинство методов опираются на внутренний менеджер трассировки, который создаётся в конструкторе только при наличии `KERNEL_16_52`. На ядрах 16.49–16.51, где `KERNEL_16_52` не определён, вызовы методов `Empty`, `GetFirstString`, `GetLastString`, `GetNextString`, `GetPreviousString` и `IsStringFound` обращаются к неинициализированному менеджеру — фактически класс неработоспособен. Метод `OpenInBrowser` дополнительно требует `KERNEL_16_55`.

## Создание объекта

Класс `Trace` имеет один конструктор — с одним аргументом.

```EME-L
'Создаёт объект трассировщика с именем буфера'
objTrace = Object("Trace", "MyTrace");
```

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `name` | String | Да | Имя трассировщика для идентификации буфера в глобальном менеджере трассировки. |

Хотя в C++ классе `CITrace` присутствуют конструкторы без аргументов и с `LPCTSTR`, они не зарегистрированы через `IMPLEMENT_CTOR` и недоступны из языка EME-L. В скриптах используется только форма `Object("Trace", name)`.

## Работа с буфером

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddLine(arg0)` | arg0: String | Empty | Добавляет строку текста в буфер трассировки. |
| `GetAsSingleString()` | — | String или Empty | Возвращает все строки трассировки, объединённые в одну строку. Если трассировщик недоступен (например, ядро ниже 16.52), возвращает пустое значение. |
| `Empty()` | — | Empty | Удаляет всю историю трассировки, очищая буфер. |
| `OpenInBrowser()` | — | Empty | Открывает содержимое трассировки в окне браузера. Доступен только в ядре 16.55 и выше. |

## Построчный перебор

Методы перебора используют внутренний курсор буфера. Перед перебором в прямом направлении вызовите `GetFirstString`, в обратном — `GetLastString`. После каждого вызова проверяйте `IsStringFound`: если предыдущий вызов вернул строку из буфера, метод возвращает `TRUE`, иначе `FALSE` (буфер пуст или достигнута граница).

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetFirstString()` | — | String или Empty | Возвращает первую строку истории и устанавливает курсор на начало буфера. |
| `GetLastString()` | — | String или Empty | Возвращает последнюю строку истории и устанавливает курсор на конец буфера. |
| `GetNextString()` | — | String или Empty | Возвращает следующую строку относительно текущей позиции курсора и сдвигает курсор вперёд. |
| `GetPreviousString()` | — | String или Empty | Возвращает предыдущую строку относительно текущей позиции курсора и сдвигает курсор назад. |
| `IsStringFound()` | — | Boolean | Проверяет, была ли найдена строка при предыдущем вызове метода получения строки. |

## Примеры

Создание трассировщика и очистка буфера перед поиском ячейки:

```EME-L
'Создать трассировщик с именем дампа и очистить старые записи'
objTrace = Object("Trace", dbLines.GetDumpName());
objTrace.Empty();

'Включить трассировку поиска в контексте'
context.SetTracingFind(1);

'После поиска проверить, остались ли строки в трассировке'
objTrace.GetFirstString();
If (objTrace.IsStringFound())
    'Есть сообщения трассировки — можно показать диалог или отчёт'
End If
```

Ручное накопление и чтение трассировки:

```EME-L
'Создать трассировщик для отладки метода'
objTrace = Object("Trace", "Debug");

'Добавить несколько диагностических строк'
objTrace.AddLine("Начало обработки");
objTrace.AddLine("Шаг 1 выполнен");
objTrace.AddLine("Обработка завершена");

'Получить всё содержимое одной строкой'
strFull = objTrace.GetAsSingleString();

'Перебрать строки от первой к последней'
For (str = objTrace.GetFirstString(); objTrace.IsStringFound(); str = objTrace.GetNextString())
    'Обработать очередную строку трассировки'
End For
```

Открыть трассировку в браузере для оперативного просмотра:

```EME-L
'Добавить диагностику и показать её в окне браузера'
objTrace = Object("Trace", "MyTrace");
objTrace.AddLine("Проверка параметров");
objTrace.AddLine("Поиск завершён");
objTrace.OpenInBrowser();
```
