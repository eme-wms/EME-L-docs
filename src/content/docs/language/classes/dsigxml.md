# Класс DSigXML

Класс `DSigXML` в языке EME-L предназначен для создания цифровой подписи XML-документов с использованием внешнего исполняемого файла на C#. Применяется для формирования электронной подписи XML-запросов в системе ФГИС Зерно.

Для работы требуются установленный КриптоПро CSP 5.0, .NET 6.0 и действующий сертификат с закрытым ключом в личном хранилище сертификатов Windows (хранилище «MY»).

Объект класса `DSigXML` создаётся через `Object()` с опциональным указанием серийного номера сертификата. При указании серийного номера выполняется автоматический поиск и установка сертификата в хранилище «MY». Подписание выполняется через запуск внешнего процесса, который обменивается данными через временные XML-файлы.

> Класс доступен начиная с версии ядра, где зарегистрирован в `p_System.cpp` под меткой `#ZIA 11.07.2023`.

## Создание объекта

```EME-L
objDSig = Object("DSigXML");
objDSig = Object("DSigXML", "123ABCDEF");
```

Конструктор без аргументов создаёт объект без установленного сертификата — сертификат задаётся позже методом `SetCertificate`. Каталог для работы с внешним исполняемым файлом определяется из параметра модуля «Предпочтения.УТМ.СДИЗ.Путь к каталогу генератора подписи для ФГИС Зерно».

Конструктор с серийным номером сразу выполняет поиск сертификата в хранилище «MY». Если сертификат не найден, объект создаётся, но `GetLastError` вернёт сообщение об ошибке.

## Методы

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetCertificate(arg0)` | arg0: String (серийный номер) | Boolean | Ищет сертификат в хранилище «MY» по серийному номеру без учёта регистра. TRUE — найден и установлен, FALSE — не найден или хранилище недоступно. |
| `Sign(arg0)` | arg0: String (XML-содержимое) | String | Формирует цифровую подпись XML через внешний C#-процесс. Возвращает подписанный XML. При ошибке — пустая строка. |
| `GetLastError()` | — | String | Текст последней ошибки. Пустая строка, если ошибок не было. |

### SetCertificate

Поиск сертификата выполняется в системном хранилище Windows «MY» по серийному номеру без учёта регистра. При передаче пустого аргумента или его отсутствии поиск выполняется, но совпадения не находится — метод возвращает FALSE, а сообщение об ошибке доступно через `GetLastError`.

### Sign

Перед вызовом `Sign` сертификат должен быть установлен — через конструктор с аргументом или методом `SetCertificate`. Метод сохраняет XML во временный файл, передаёт его внешнему C#-процессу и читает подписанный результат. Если сертификат не установлен, `Sign` возвращает пустую строку, а `GetLastError` возвращает «Сертификат не был найден».

## Примеры

Установка сертификата и подписание XML (по образцу метода `SigningOfXML` из производственного класса `SDIZ`):

```EME-L
'Создать объект и установить сертификат по серийному номеру'
XMLSigner = Object("DSigXML");
If (~XMLSigner.SetCertificate(CERT_SN))
    ErrorArr.Add(XMLSigner.GetLastError());
    Return "";
End If
'Подписать XML-документ'
ResultXML = XMLSigner.Sign(XMLText);
If (ResultXML == "")
    ErrorArr.Add(XMLSigner.GetLastError());
    Return "";
End If
Return ResultXML;
```

Создание объекта с сертификатом в конструкторе:

```EME-L
objDSig = Object("DSigXML", "123ABCDEF");
LastError = objDSig.GetLastError();
If (LastError != "")
    ErrorArr.Add(LastError);
End If
```
