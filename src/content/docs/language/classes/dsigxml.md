# Класс DSigXML

Класс `DSigXML` в языке EME-L предназначен для создания цифровой подписи XML-документов с использованием внешнего исполняемого файла на C#. Применяется для формирования электронной подписи XML-запросов в системе ФГИС Зерно.

Для работы требуются установленный КриптоПро CSP 5.0, .NET 6.0 и действующий сертификат с закрытым ключом в личном хранилище сертификатов Windows (хранилище «MY»).

Объект класса `DSigXML` создаётся через `Object()` с опциональным указанием серийного номера сертификата. При указании серийного номера выполняется автоматический поиск и установка сертификата в хранилище «MY». Подписание выполняется через запуск внешнего процесса, который обменивается данными через временные XML-файлы.

> Класс доступен начиная с версии ядра, где зарегистрирован в `p_System.cpp` под меткой `#ZIA 11.07.2023`.

## Создание объекта

```EME-L
'Без аргументов — сертификат задаётся позже методом SetCertificate'
objDSig = Object("DSigXML");
'С серийным номером сертификата — поиск выполняется в хранилище «MY» при создании'
objDSig = Object("DSigXML", "123ABCDEF");
```

Класс `DSigXML` имеет два overload конструктора:

- `Object("DSigXML")` — создаёт объект без установленного сертификата. Каталог для работы с внешним исполняемым файлом определяется из параметра модуля «Предпочтения.УТМ.СДИЗ.Путь к каталогу генератора подписи для ФГИС Зерно»; если параметр пуст, используется каталог по умолчанию, заданный в классе.
- `Object("DSigXML", "123ABCDEF")` — сразу выполняет поиск сертификата в системном хранилище Windows «MY» по серийному номеру без учёта регистра. При успешном поиске сертификат устанавливается для последующего подписания. Если сертификат не найден, объект создаётся, но `GetLastError` вернёт сообщение об ошибке («Сертификат не найден» или текст системной ошибки `GetLastError`).

Серийный номер сертификата сравнивается с возвратом `CertFindCertificateInStore` в верхнем регистре (приведение `MakeUpper()` для обеих сторон сравнения), поэтому регистр символов в аргументе не имеет значения.

## Методы

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetCertificate(arg0)` | arg0: String (серийный номер сертификата) | Boolean | Выполняет поиск и установку сертификата в хранилище «MY» по серийному номеру без учёта регистра. TRUE — сертификат найден и установлен, FALSE — сертификат не найден или хранилище недоступно. |
| `Sign(arg0)` | arg0: String (XML-содержимое) | String | Формирует цифровую подпись XML через внешний C#-процесс. Строго 1 аргумент. Возвращает подписанный XML. При ошибке — пустая строка. |
| `GetLastError()` | — | String | Текст последней ошибки, возникшей при работе с сертификатом или подписании XML. Пустая строка при отсутствии ошибок. |

### SetCertificate

Поиск сертификата выполняется в системном хранилище Windows «MY» (имя хранилища захардкожено как `"MY"`) по серийному номеру без учёта регистра. При невозможности открыть хранилище метод возвращает FALSE и устанавливает сообщение «Недоступно хранилище сертификатов». При передаче пустого аргумента или его отсутствии поиск выполняется, но совпадения не находится — метод возвращает FALSE, а сообщение об ошибке доступно через `GetLastError` (при отсутствии системной ошибки будет установлено «Сертификат не найден»).

### Sign

Перед вызовом `Sign` сертификат должен быть установлен — через конструктор с аргументом или методом `SetCertificate`. Если сертификат не установлен, `Sign` сразу возвращает пустую строку, а `GetLastError` возвращает «Сертификат не был найден». Метод сохраняет XML во временный файл `tobesignedxml.xml`, передаёт его внешнему C#-процессу (исполняемый файл `<m_sSignerExeName>`, размещённый в каталоге параметра модуля) и читает подписанный результат из файла `signedxml.xml`. Если внешний процесс сообщает об ошибке через файл-журнал (`m_sFileErrorLog`), содержимое этого файла попадает в `GetLastError`. Если исполняемый файл не найден в каталоге, `Sign` возвращает пустую строку, а `GetLastError` возвращает «<m_sSignerExeName> не найден». Если после выполнения процесса не найден ни файл ошибки, ни `signedxml.xml`, устанавливается сообщение «Не найден файл с подписью или файл для подписания некорректный». Метод строго требует 1 аргумент (`too_rare()`/`too_many()` при нарушении).

## Примеры

Установка сертификата и подписание XML (по образцу метода `SigningOfXML` из производственного класса `SDIZ`):

```EME-L
'Создать объект и установить сертификат по серийному номеру'
XMLSigner = Object("DSigXML");
If (~XMLSigner.SetCertificate(CERT_SN))
    ErrorArr.Add(XMLSigner.GetLastError());
    Return "";
End If
'Подписать XML-документ'
ResultXML = XMLSigner.Sign(XMLText);
If (ResultXML == "")
    ErrorArr.Add(XMLSigner.GetLastError());
    Return "";
End If
Return ResultXML;
```

Создание объекта с сертификатом в конструкторе:

```EME-L
objDSig = Object("DSigXML", "123ABCDEF");
LastError = objDSig.GetLastError();
If (LastError != "")
    ErrorArr.Add(LastError);
End If
```

## Константы и файлы из реализации

Следующие конкретные значения и имена файлов зафиксированы в теле методов C++ (`c_emel_class_method/i_DSigXML.cpp`) и определяют поведение класса:

- **Имя системного хранилища сертификатов**: `"MY"` — захардкожено в конструкторе с аргументом и в `SetCertificate`.
- **Имя параметра модуля** для каталога генератора подписи: `Предпочтения.УТМ.СДИЗ.Путь к каталогу генератора подписи для ФГИС Зерно`. При пустом значении параметра используется каталог по умолчанию (`m_sDirName`).
- **Входной XML-файл** для внешнего C#-процесса: `tobesignedxml.xml` (в каталоге параметра модуля).
- **Выходной подписанный XML-файл**: `signedxml.xml`.
- **Файл-журнал ошибок** внешнего процесса: `m_sFileErrorLog` — если этот файл существует после выполнения процесса, его содержимое попадает в `GetLastError`, а подпись не возвращается.
- **Исполняемый файл C#**: `m_sSignerExeName` — должен существовать в каталоге параметра модуля (проверка через `EMEFindFileCatalogue`).
- **Точные сообщения об ошибках**, устанавливаемые в `GetLastError`:
  - `«Сертификат не был найден»` — при вызове `Sign` без установленного сертификата.
  - `«Сертификат не найден»` — после неудачного поиска сертификата в `SetCertificate` (если CertFindCertificateInStore ничего не нашёл; в C++ написано с твёрдым знаком «Сертификатъ не найден» — это опечатка в исходнике).
  - `«Недоступно хранилище сертификатов»` — если `CertOpenSystemStore` вернул NULL.
  - `«<m_sSignerExeName> не найден»` — если исполняемый файл C# отсутствует в каталоге параметра модуля.
  - `«Не найден файл с подписью или файл для подписания некорректный»` — если после выполнения процесса не найден ни файл-журнал ошибки, ни `signedxml.xml`.
- **Сравнение серийного номера** выполняется в верхнем регистре (`MakeUpper()` применяется к обоим операндам).
- **Возврат Boolean** из `SetCertificate` реализован как `COleVariant((long)Result, VT_BOOL)` — соответствует правилу EME-L `TRUE = -1`.
