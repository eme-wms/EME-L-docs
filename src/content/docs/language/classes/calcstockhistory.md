# Класс CalcStockHistory

Класс `CalcStockHistory` в языке EME-L вычисляет остатки по складским регистрам на указанную дату и время. Остатки вычисляются методом обратного пересчёта от текущих остатков по истории движений строк документов. Класс поддерживает получение остатков на произвольную дату в прошлом и оптимизирован для многократных вызовов с убывающими датами.

Объект класса создаётся через `Object("CalcStockHistory")` без аргументов. Расчёт текущих остатков выполняется лениво — при первом вызове `GetStock`, а не в конструкторе, чтобы не увеличивать время старта программы.

## Создание объекта

```EME-L
'Создать объект для расчёта истории остатков'
CalcStockHistory = Object("CalcStockHistory");
```

Конструктор параметров не принимает. Повторное использование одного объекта для нескольких дат быстрее, чем создание нового объекта на каждую дату.

## Методы

### GetStock

`GetStock(objQuery, dateTime)` — вычисляет остатки по регистрам на указанные дату и время и заполняет переданный объект запроса.

При первом вызове выполняет вычисление текущих остатков. Для оптимизации производительности при получении остатков на несколько дат рекомендуется использовать один объект и передавать даты в обратном хронологическом порядке от последней к первой. Если запрос непустой, он предварительно очищается.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `objQuery` | Query (по ссылке) | Да | Объект запроса, в который добавляются строки с остатками по регистрам. |
| `dateTime` | DateTime | Да | Дата и время, на которые нужно получить остатки. Время не может быть больше текущего. При многократных вызовах даты передаются в обратном хронологическом порядке. |

**Возвращает**: `DateTime` — реальную дату и время, для которой вычислены остатки. Это время первой операции перед запрошенной датой/временем. Если запрошены остатки на начало времён, возвращается момент первого движения в базе.

### GetLastDocLineRef

`GetLastDocLineRef()` — возвращает ссылку на последнюю отгруженную строку документа, соответствующую остаткам, полученным последним вызовом `GetStock`. С помощью этой ссылки можно перебрать все строки документов, чтобы учесть движения за период между двумя вызовами `GetStock`.

**Возвращает**: `Reference` — ссылку на строку документа. Возвращает `NULL_REF` (-1), если метод `GetStock` не вызывался или запрашивались остатки на начало времён.

### MarkupStockDataQueyry

`MarkupStockDataQueyry(objQuery)` — размечает объект запроса, добавляя поля для хранения данных об остатках по регистрам.

Добавляет обязательные поля: `@Ячейка`, `Количество N`, `Количество S`, `Количество M`, `Количество P`, а также дополнительные поля: `Расширенное количество`, `Расширенное количество S`, `Расширенное количество M`, `Тип документа`, `@Регистр`, `Количество Buf`, `@SSCC`, `@Организация`, `@Партия товара`, `@Товарная единица`, `BBD`, `Стоковый статус`, `@Единица измерения товара`, `@Оператор`, `@Поддон`, `@ГТД`, `@Аналитика`, `@Склад`, `@Составная паллета`, `@Сертификат`, `Строки документов`, `@Регистратор`.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `objQuery` | Query (по ссылке) | Да | Объект запроса, который будет размечен под данные остатков. |

**Возвращает**: `Empty`.

> Название метода содержит опечатку оригинала (`Queyry` вместо `Query`) — сохранено для совместимости.

### CalcCurrentStock

`CalcCurrentStock()` — вычисляет текущие остатки по всем регистрам и сохраняет их во внутреннем массиве объекта. Вызывается автоматически при первом вызове `GetStock`. Явный вызов позволяет заранее прогреть расчёт, но обычно не требуется.

**Возвращает**: `Empty`.

### CalcStockAtDate

`CalcStockAtDate(dateTime)` — вычисляет остатки на указанные дату и время методом обратного пересчёта от текущих остатков. Перемещается по истории движений строк документов, корректируя счётчики количества. Дата следующего вызова должна быть меньше или равна дате предыдущего вызова.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `dateTime` | DateTime | Да | Дата и время, на которые нужно получить остатки. Время не может быть больше текущего. При многократных вызовах даты передаются в обратном хронологическом порядке. |

**Возвращает**: `DateTime` — реальную дату и время, для которой получены остатки (время первой операции перед запрошенной датой/временем).

### EnableChangeStockData

`EnableChangeStockData(isEnabled, isSuppressTransfer)` — включает или отключает режим фиксации изменений остатков при вычислении. В режиме фиксации все изменения количеств, происходящие при вызове `GetStock` или `CalcStockAtDate`, сохраняются во внутреннем массиве и могут быть получены методом `FillChangeStockDataQuery`. Второй параметр позволяет подавить фиксацию изменений при перемещениях внутри регистра.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `isEnabled` | Boolean | Да | `TRUE` (=-1) — фиксация изменений включена; `FALSE` (=0) — отключена (по умолчанию). |
| `isSuppressTransfer` | Boolean | Да | `TRUE` — изменения при перемещении подавляются; `FALSE` — изменения при перемещении фиксируются (по умолчанию). |

**Возвращает**: `Empty`.

### FillStockDataQuery

`FillStockDataQuery(objQuery)` — заполняет переданный объект запроса строками с текущими остатками по регистрам. Перед заполнением запрос очищается от старых данных. Запрос должен быть предварительно размечен методом `MarkupStockDataQueyry` или содержать совместимый набор полей.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `objQuery` | Query (по ссылке) | Да | Объект запроса, в который добавляются строки с остатками по регистрам. |

**Возвращает**: `Empty`.

### FillChangeStockDataQuery

`FillChangeStockDataQuery(objQuery)` — заполняет переданный объект запроса строками с изменениями остатков по регистрам, зафиксированными при включённом режиме фиксации изменений (`EnableChangeStockData`). Перед заполнением запрос очищается от старых данных.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `objQuery` | Query (по ссылке) | Да | Объект запроса, в который добавляются строки с изменениями остатков. |

**Возвращает**: `Empty`.

## Поля запроса остатков

Метод `MarkupStockDataQueyry` размечает следующие поля. Поля могут быть добавлены и вручную через методы объекта `Query` (`AddFLOAT`, `AddREF`, `AddDATE`, `AddTEXT`, `AddINT`).

| Поле | Тип | Назначение |
|------|-----|-----------|
| `@Ячейка` | Reference | Ячейка регистра. |
| `Количество N` | Float | Количество на счётчике N (доступный остаток). |
| `Количество S` | Float | Количество на счётчике S (резерв). |
| `Количество M` | Float | Количество на счётчике M (недостача/брак). |
| `Количество P` | Float | Количество на счётчике P (отгруженный подбор). |
| `Расширенное количество` | Float | Расширенное количество (в дополнительных ЕИ). |
| `Расширенное количество S` | Float | Расширенное зарезервированное количество. |
| `Расширенное количество M` | Float | Расширенное количество недостачи. |
| `Тип документа` | Reference | Тип документа последнего движения. |
| `@Регистр` | Reference | Ссылка на регистр (устаревшее, нельзя читать данные из регистра). |
| `Количество Buf` | Float | Количество в буфере. |
| `@SSCC` | Reference | SSCC транспортировочной единицы. |
| `@Организация` | Reference | Организация-партнёр (собственник). |
| `@Партия товара` | Reference | Партия товара. |
| `@Товарная единица` | Reference | Товарная единица. |
| `BBD` | Date | Срок годности (Best Before Date). |
| `Стоковый статус` | Text(2) | Стоковый статус (одиночный символ). |
| `@Единица измерения товара` | Reference | Единица измерения товара. |
| `@Оператор` | Reference | Пользователь-оператор. |
| `@Поддон` | Reference | Тип поддона. |
| `@ГТД` | Reference | Грузовая таможенная декларация. |
| `@Аналитика` | Reference | Аналитический признак. |
| `@Склад` | Reference | Склад. |
| `@Составная паллета` | Reference | Составная паллета. |
| `@Сертификат` | Reference | Сертификат. |
| `Строки документов` | Reference | Ссылка на строку документа последнего движения. |
| `@Регистратор` | Reference | Строка-регистратор изменения (только в режиме фиксации изменений). |

## Примеры

Базовый расчёт остатков на текущую дату:

```EME-L
'Разметить запрос под остатки'
queryStock = Object("Query");
queryStock.Create();
queryStock.AddREF("@Ячейка", "Ячейки");
queryStock.AddFLOAT("Количество N");
queryStock.AddFLOAT("Количество S");
queryStock.AddFLOAT("Количество M");
queryStock.AddFLOAT("Количество P");
queryStock.AddINT("Тип документа");

'Рассчитать остатки на текущую дату'
CalcStockHistory = Object("CalcStockHistory");
CalcStockHistory.GetStock(queryStock, is_date() + is_time(0, 0, 0));

'Перебрать строки результата'
Loop (queryStock)
    CellRef = queryStock.Get("@Ячейка");
    QtyN = queryStock.Get("Количество N");
End Loop
```

Ежедневные остатки за период (даты в обратном порядке — обязательно):

```EME-L
CalcStockHistory = Object("CalcStockHistory");
LastLine = 0;
For (Date = FinalDate; Date >= StartDate; Date = Date - 1)
    queryStock.DeleteAllLines();
    CalcStockHistory.GetStock(queryStock, Date);
    For (Lines = queryStock.GetNoOfLines(); LastLine < Lines; LastLine = LastLine + 1)
        queryStock.PutData("Дата", LastLine, Date);
    End For
End For
```

Фиксация изменений остатков между двумя датами:

```EME-L
CalcStockHistory = Object("CalcStockHistory");
CalcStockHistory.MarkupStockDataQueyry(queryStock);

'Включить фиксацию изменений, подавляя фиктивные перемещения'
CalcStockHistory.EnableChangeStockData(TRUE, TRUE);

'Первый расчёт — позже, второй — раньше'
CalcStockHistory.GetStock(queryStock, EndDate + is_time(0, 0, 0));
CalcStockHistory.GetStock(queryStock, StartDate + is_time(0, 0, 0));

'Получить изменения остатков за период'
queryChanges = Object("Query");
queryChanges.Create();
CalcStockHistory.MarkupStockDataQueyry(queryChanges);
CalcStockHistory.FillChangeStockDataQuery(queryChanges);
```
