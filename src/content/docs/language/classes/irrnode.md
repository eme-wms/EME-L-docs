# Класс IrrNode

Класс `IrrNode` в языке EME-L — базовый класс узла сцены движка Irrlicht. Представляет узел трёхмерной сцены и предоставляет операции для управления иерархией, положением, поворотом, масштабом, видимостью, именем, пользовательскими свойствами, материалом и текстурой узла. Является родительским классом для специализированных узлов: [`IrrCamera`](./irrcamera.md), IrrLight, IrrMesh, IrrAnimatedMesh, IrrOctree, IrrBillboard, IrrDummy, IrrSkyBox и IrrCube.

Через методы класса скрипт EME-L строит иерархию сцены: добавляет дочерние узлы специализированных типов (кубы, сетки, камеры, источники света, билборды, пустышки, скайбоксы), подключает аниматор движения по сплайну, сохраняет и загружает параметры узла в дерево свойств `PropertyTree`, а также получает ограничивающую рамку и точку пересечения с лучом.

Используется в EME-L-скриптах для построения и управления иерархией трёхмерной сцены Irrlicht.

## Создание объекта

В блоке `BEGIN_IMPLEMENT(CIIrrNode)` нет зарегистрированных конструкторов с аргументами — объект `IrrNode` не создаётся через `Object("IrrNode", ...)` напрямую. Канонический способ получить узел — обратиться к корневому узлу сцены через `GetRootNode()` устройства [`IrrDevice`](./irrdevice.md) либо создать дочерний узел одного из специализированных типов методом `Add*` (например, `AddCube`, `AddMesh`, `AddCamera`).

```EME-L
'Создать устройство Irrlicht и получить корневой узел сцены'
objDevice = Object("IrrDevice");
objRoot   = objDevice.GetRootNode();

'Задать имя корневого узла для поиска по имени'
objRoot.SetName("Root");
```

При создании узла применяются значения по умолчанию, заданные в конструкторе:

| Параметр | Значение по умолчанию |
|----------|-----------------------|
| Видимость | `TRUE` |
| Освещение | `TRUE` |
| Нормализация нормалей | `FALSE` |
| Отсечение задних граней | `TRUE` |
| Тип материала | `solid` |
| Реакция на мышь (clickable) | `FALSE` |
| Масштаб текстуры по U | `0` (не применяется) |
| Масштаб текстуры по V | `0` (не применяется) |

## Иерархия и поиск

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetParentNode(arg0)` | arg0: IrrNode (ссылка) | Empty | Устанавливает родительский узел. Положение и масштаб текущего узла пересчитываются с учётом нового родителя. |
| `FindNodeByName(arg0)` | arg0: String | IrrNode | Ищет в поддереве текущего узла дочерний узел по имени и возвращает обёртку `IrrNode`. |
| `AddNode(arg0)` | arg0: PropertyTree (ссылка) | Empty | Создаёт дочерний узел указанного типа из дерева свойств и загружает в него параметры. Поддерживаемые типы: `Cube`, `Mesh`, `Billboard`, `Dummy`, `SkyBox`, `Light`, `Camera`. |
| `Remove()` | — | Empty | Удаляет текущий узел вместе со всеми дочерними узлами, удаляет связанные спрайты, исключает узел из реестра имён устройства и освобождает память. |
| `IsValidNode()` | — | Boolean | `TRUE` — объект связан с внутренним узлом сцены Irrlicht; `FALSE` — узел не инициализирован. |

## Положение, поворот, масштаб

Положение и масштаб узла задаются в локальной системе координат относительно родителя и умножаются на глобальный масштаб устройства перед установкой в Irrlicht. Поворот задаётся в градусах без учёта глобального масштаба.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetPosition(arg0, arg1, arg2)` | arg0: Real (X), arg1: Real (Y), arg2: Real (Z) | Empty | Задаёт локальное положение узла. Координаты умножаются на глобальный масштаб. |
| `GetPosition(arg0)` | arg0: Array (по ссылке, 3 элемента) | Empty | Возвращает локальное положение узла. Координаты X, Y, Z записываются в элементы массива с индексами 0, 1, 2. |
| `SetRotation(arg0, arg1, arg2)` | arg0: Real (X°), arg1: Real (Y°), arg2: Real (Z°) | Empty | Задаёт углы поворота узла в градусах по осям X, Y, Z. |
| `GetRotation(arg0)` | arg0: Array (по ссылке, 3 элемента) | Empty | Возвращает углы поворота узла в градусах. Записывает X, Y, Z в элементы массива 0, 1, 2. |
| `SetScale(arg0, arg1, arg2)` | arg0: Real (X), arg1: Real (Y), arg2: Real (Z) | Empty | Задаёт локальный масштаб узла. Значения умножаются на глобальный масштаб. |

Методы `GetPosition` и `GetRotation` не возвращают значение напрямую — результат записывается в переданный массив. После вызова читайте координаты из элементов массива.

## Имя и свойства

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetName(arg0)` | arg0: String | Empty | Задаёт имя узла и регистрирует его в устройстве для поиска по имени. |
| `GetName()` | — | String | Возвращает имя узла. Если имя не задано, возвращается автоматически сгенерированный идентификатор (адрес объекта). |
| `GetType()` | — | String | Возвращает строковое представление типа узла. |
| `SetProperty(arg0, arg1)` | arg0: String (имя), arg1: Variant (значение) | Empty | Сохраняет произвольное пользовательское свойство узла по имени. |
| `GetProperty(arg0, arg1)` | arg0: String (имя), arg1: Variant (по умолчанию) | Variant | Возвращает значение свойства по имени. Если свойство не найдено, возвращается `arg1`. |

## Видимость и материал

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetVisible(arg0)` | arg0: Boolean | Empty | Устанавливает видимость узла: `TRUE` — видим, `FALSE` — скрыт. |
| `SetLighting(arg0)` | arg0: Boolean | Empty | Включает (`TRUE`) или отключает (`FALSE`) освещение узла источниками света сцены. |
| `SetNormalizeNormals(arg0)` | arg0: Boolean | Empty | Включает (`TRUE`) или отключает (`FALSE`) нормализацию нормалей узла. |
| `SetBackfaceCulling(arg0)` | arg0: Boolean | Empty | Включает (`TRUE`) или отключает (`FALSE`) отсечение задних граней. При включении тыльные стороны полигонов не отрисовываются. |
| `SetMaterialType(arg0)` | arg0: String | Empty | Задаёт тип материала. При неизвестном типе генерируется ошибка. Допустимые значения — см. таблицу ниже. |
| `SetMaterialTexture(arg0)` | arg0: String (путь к файлу) или IrrImage (ссылка) | Empty | Задаёт текстуру материала узла — путь к файлу изображения либо объект `IrrImage`. |
| `SetTextureScale(arg0, arg1)` | arg0: Real (scaleU), arg1: Real (scaleV) | Empty | Задаёт масштаб текстурных координат по U и V. Если оба значения отличны от нуля, масштаб применяется к матрице текстуры. |
| `SetClickable(arg0)` | arg0: Boolean | Empty | Включает (`TRUE`) или отключает (`FALSE`) реакцию узла на события мыши. При включении создаётся треугольный селектор по ограничивающей рамке и устанавливается младший бит идентификатора узла. |

## Сохранение и загрузка параметров

Методы сериализуют параметры узла (тип, имя, положение, поворот, масштаб, текстура, масштаб текстуры, видимость, освещённость, нормализация нормалей, отсечение задних граней, тип материала, кликабельность) в дерево свойств `PropertyTree` или загружают их из него.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SaveNode(arg0)` | arg0: PropertyTree (ссылка) | Empty | Сохраняет параметры текущего узла в дерево свойств. |
| `LoadNode(arg0)` | arg0: PropertyTree (ссылка) | Empty | Загружает параметры текущего узла из дерева свойств. |

## Создание дочерних узлов

Методы создают дочерние узлы специализированных типов и возвращают ссылку на новый объект.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddCube(arg0)` | arg0: Real (длина ребра) | IrrCube | Создаёт дочерний узел-куб. |
| `AddMesh(arg0)` | arg0: String (путь к mesh-файлу) или IrrMeshCreator (ссылка) | IrrMesh | Создаёт дочерний узел полигональной сетки. |
| `AddAnimatedMesh(arg0)` | arg0: String (путь к mesh-файлу) | IrrAnimatedMesh | Создаёт дочерний узел анимированной сетки. |
| `AddOctree(arg0)` | arg0: String (путь к файлу) или IrrMeshCreator (ссылка) | IrrOctree | Создаёт дочерний узел в виде октодерева для оптимизации рендеринга. |
| `AddLight()` | — | IrrLight | Создаёт дочерний узел-источник освещения. |
| `AddCamera()` | — | IrrCamera | Создаёт дочерний узел-камеру и делает её активной камерой устройства. |
| `AddBillboard()` | — | IrrBillboard | Создаёт дочерний узел-билборд, поворачивающийся лицом к камере. |
| `AddDummy()` | — | IrrDummy | Создаёт неотображаемый дочерний узел-пустышку (контейнер или точка привязки). |
| `AddSkyBox(arg0–arg5)` | arg0–arg5: String или IrrImage — текстуры top, bottom, left, right, front, back | IrrSkyBox | Создаёт дочерний узел-скайбокс с шестью текстурами. |
| `AddCameraMaya()` | — | IrrCamera | **Устаревший.** Создаёт дочернюю камеру Maya. |

## Аниматор и отладка

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddFollowSplineAnimator(arg0, arg1, arg2)` | arg0: Array (координаты X, Y, Z точек), arg1: Array (углы X, Y, Z в градусах), arg2: Real (скорость) | Empty | Добавляет аниматор, перемещающий узел по сплайну с поворотами в ключевых точках. Массивы упакованы тройками: X, Y, Z на каждую точку. |
| `SetDebugDataVisible(arg0)` | arg0: Integer (битовая маска) | Empty | Устанавливает, какие отладочные данные отображаются для узла. |

### Флаги отладочных данных

Битовая маска `arg0` метода `SetDebugDataVisible`:

| Значение | Описание |
|----------|----------|
| `0` | Отладочные данные не отображаются. |
| `1` | Ограничивающие рамки узла сцены. |
| `2` | Нормали вершин. |
| `4` | Скелет или теги. |
| `8` | Wireframe наложения mesh. |
| `16` | Временное использование прозрачности типа материала. |
| `32` | Ограничивающие рамки всех mesh-буферов. |
| `0xffffffff` | Отображать все отладочные данные. |

## Геометрия: ограничивающая рамка и пересечение

Методы возвращают координаты, записываемые в переданный массив из трёх элементов. Точка пересечения преобразуется в локальную систему координат узла.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetMinEdge(arg0)` | arg0: Array (по ссылке, 3 элемента) | Empty | Координаты ближней вершины ограничивающей рамки (X, Y, Z в индексы 0, 1, 2). |
| `GetMaxEdge(arg0)` | arg0: Array (по ссылке, 3 элемента) | Empty | Координаты дальней вершины ограничивающей рамки (X, Y, Z в индексы 0, 1, 2). |
| `GetIntersection(arg0)` | arg0: Array (по ссылке, 3 элемента) | Empty | Координаты последней точки пересечения луча с узлом, преобразованные в локальную систему координат. |

## Примеры

Построение сцены с корневым узлом, кубом и камерой:

```EME-L
'Создать устройство Irrlicht и получить корневой узел'
objDevice = Object("IrrDevice");
objRoot   = objDevice.GetRootNode();

'Добавить дочерний куб с длиной ребра 10.0'
objCube = objRoot.AddCube(10.0);

'Назначить текстуру из файла'
objCube.SetMaterialTexture("D:\\Data\\box.png");

'Добавить камеру и сделать её активной'
objCam = objRoot.AddCamera();
```

Поиск дочернего узла по имени и чтение его положения:

```EME-L
'Найти узел по имени в поддереве корневого узла'
objFound = objRoot.FindNodeByName("Box01");

'Массив для приёма координат X, Y, Z'
arrPos = is_array(3);

If (objFound.IsValidNode())
    objFound.GetPosition(arrPos);
    PosX = arrPos[0];
    PosY = arrPos[1];
    PosZ = arrPos[2];
End If
```
