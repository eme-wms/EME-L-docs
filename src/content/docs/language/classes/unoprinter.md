# Класс UnoPrinter

Класс `UnoPrinter` в языке EME-L предназначен для управления струйным принтером Inc Jet UNO в складской системе WMS. Обеспечивает полный цикл работы с принтером: установку TCP/IP-соединения, передачу заданий печати, контроль состояния печати, получение журнальных сообщений по UDP и отключение от принтера.

CI-имя класса — `CIUnoPrinter`.

Основные возможности:

- подключение к принтеру по заданному IP-адресу через TCP/IP (порты 10000 и 10001);
- задание имени Job-файла (шаблона печати), загруженного в принтер;
- запуск и остановка заданий печати с передачей массива серийных номеров;
- получение статуса соединения (0 — не подключен, 1 — подключается, 2 — подключен);
- контроль количества напечатанных и запланированных страниц;
- проверка режима активной печати;
- автоматическое фоновое сохранение напечатанных серийных номеров в базу данных.

Объект класса должен быть размещён в классе-резиденте. Перед использованием необходимо задать IP-адрес и имя Job-файла, после чего вызвать метод `Connect` для установки соединения.

> **Внимание:** в C++-исходнике `i_UnoPrinter.cpp` инициализация внутреннего рабочего компонента и запуск фонового потока находятся в конструкторе `CIUnoPrinter(int argn, COleVariant args[])`, тогда как в `BEGIN_IMPLEMENT` зарегистрирован только конструктор без аргументов (`IMPLEMENT_CTOR(CIUnoPrinter, 0, ...)`), и его тело пустое. Это расхождение между REGISTRY-контрактом и C++-реализацией. При использовании в конкретной сборке ядра проверяйте, что объект корректно инициализируется (например, метод `Connect` не вызывает ошибок доступа к неинициализированному компоненту).

## Создание объекта

Класс `UnoPrinter` имеет один конструктор — без аргументов.

```EME-L
'Создать объект управления принтером UnoPrinter'
objUnoPrinter = Object("UnoPrinter");
```

Согласно контракту реестра, при создании объекта инициализируется внутренний рабочий компонент, настраивается подписка на события принтера и запускается фоновый поток для сохранения напечатанных серийных номеров в базу данных.

## Подключение и настройка соединения

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetIpAddress(ipAddress)` | ipAddress: String | Empty | Устанавливает IP-адрес принтера для TCP/IP-соединения. Адрес используется при последующем вызове метода `Connect`. |
| `SetJobName(jobName)` | jobName: String | Empty | Устанавливает название задачи печати (имя Job-файла), загруженного в принтер. Название должно быть задано перед вызовом `StartPrint`. |
| `Connect()` | — | Boolean | Устанавливает TCP/IP-соединение с принтером по ранее заданному IP-адресу. Если соединение уже установлено и принтер находится в состоянии "Подключен", возвращает `TRUE` без повторного подключения. `TRUE` — соединение установлено или уже было активно; `FALSE` — не удалось установить соединение. |
| `Disconnect()` | — | Empty | Разрывает TCP/IP-соединение с принтером и освобождает связанные ресурсы. |
| `GetConnectionStatus()` | — | Integer | Возвращает текущее состояние TCP/IP-соединения: `0` — не подключен, `1` — выполняется подключение, `2` — подключен. |
| `IsPrinting()` | — | Boolean | `TRUE` — принтер выполняет печать; `FALSE` — принтер не печатает. |

## Управление печатью

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `StartPrint(serialNumbers)` | serialNumbers: Array (по ссылке) | Empty | Запускает задание печати серийных номеров на принтере. Перед запуском должны быть заданы имя Job-файла (методом `SetJobName`) и IP-адрес принтера. Сбрасывает счётчик напечатанных страниц и передаёт принтеру массив серийных номеров (тип 252 — ссылки на записи `SerialNumber`). |
| `StopPrint()` | — | Empty | Останавливает текущее задание печати на принтере. Сбрасывает счётчики напечатанных и запланированных страниц в ноль. |

> **Примечание:** реестр декларирует `StopPrint()` без аргументов, но в теле метода проверка выполняется как `if (argn > 1) too_many();`. Фактически метод примет один аргумент, который будет проигнорирован. Для совместимости с документированным контрактом вызывайте `StopPrint()` без аргументов.

## Счётчики страниц

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetNumberPrintedPage()` | — | Integer | Возвращает количество страниц, уже напечатанных в рамках текущего задания печати. Счётчик увеличивается по событию от принтера после печати каждой страницы. |
| `GetNumberPrintPage()` | — | Integer | Возвращает общее количество страниц для печати, установленное при запуске задания методом `StartPrint`. Равно размеру переданного массива серийных номеров. |

## Константы и детали реализации

- TCP/IP-порты управления принтером: **10000** (передача команд) и **10001** (приём ответов/событий).
- UDP-порт для получения журнальных сообщений: **20000**.
- Таймаут установки TCP-соединения: **1000 мс**.
- Фоновый поток сохранения серийных номеров открывает серверную транзакцию и помечает записи `SerialNumber` как напечатанные (`SetSerialPrinted`).
- Массив, передаваемый в `StartPrint`, должен содержать ссылки на строки записей серийных номеров (тип 252), а не произвольные целые числа.

## Примеры

### Создание объекта и подключение

```EME-L
'Создать объект UnoPrinter в резиденте'
objUnoPrinter = Object("UnoPrinter");
objUnoPrinter.SetIpAddress("192.168.1.10");
objUnoPrinter.SetJobName("Job1.job");

'Установить соединение с принтером'
If (objUnoPrinter.Connect())
    Status = objUnoPrinter.GetConnectionStatus();
End If
```

### Запуск печати серийных номеров

```EME-L
'Собрать массив ссылок на серийные номера'
arrSerials = Object("Array");
Loop (r_SerialNumbers)
    arrSerials.Add(r_SerialNumbers.GetLine());
End Loop

'Отправить массив на печать'
objUnoPrinter = Object("UnoPrinter");
If (objUnoPrinter.Connect())
    objUnoPrinter.StartPrint(arrSerials);
End If
```

### Контроль состояния по таймеру

```EME-L
'Обновить поле со статусом подключения'
Switch (objUnoPrinter.GetConnectionStatus())
Case 0:
    StatusTxt = tr("Принтер не подключен");
    Break;
Case 1:
    StatusTxt = tr("Подключение к принтеру...");
    Break;
Case 2:
    StatusTxt = tr("Принтер подключен");
    Break;
End Switch
ctrlStatePrinterProduction.Put(StatusTxt);
ctrlQtyPrinted.PutText(is_format("%d", objUnoPrinter.GetNumberPrintedPage()));
ctrlQtyAll.PutText(is_format("%d", objUnoPrinter.GetNumberPrintPage()));
```

### Остановка печати

```EME-L
'Прервать текущее задание печати'
objUnoPrinter.StopPrint();
ctrlQtyPrinted.PutText("0");
ctrlQtyAll.PutText("0");
```
