# Класс KeyResolver

Класс `KeyResolver` в языке EME-L — класс для определения соответствия между ключами строк и номерами строк записей базы данных EME. Предоставляет механизм разрешения ключей строк: поиск строки по ключу, загрузка ключей в определитель, формирование и разрешение псевдоключей для импорта/экспорта данных. Поддерживает работу с Worker Data (записи с битом `WORKER_DATA_BIT`), где используются внутренние идентификаторы строк, и с обычными записями, где псевдоключ формируется из номера записи и строки.

Используется при импорте данных для сопоставления ссылок на строки между разными базами данных и филиалами, где прямые номера строк могут различаться, а ключи обеспечивают стабильную идентификацию.

Объект класса `KeyResolver` создаётся через `Object()` и не привязан к контексту диалога или браузера — это самостоятельный класс для работы с внутренними структурами ключей. Перед использованием методов поиска (`GetLine`, `GetPseudoKeyLine`) необходимо загрузить ключи методом `LoadKey` или заполнить карту псевдоключей методом `ResolvePseudoKeys`.

## Создание объекта

Класс `KeyResolver` имеет один конструктор — без аргументов.

```EME-L
'Создание пустого объекта определителя ключей'
objResolver = Object("KeyResolver");
```

Конструктор создаёт пустой объект. Ключи загружаются отдельными вызовами `LoadKey` или `ResolvePseudoKeys` после создания.

## Методы

### Загрузка ключей

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `LoadKey(Rec, Line)` | arg0: Integer (запись), arg1: Integer (строка) | Integer | Загружает ключ строки `Line` записи `Rec` во внутреннее хранилище. При первой загрузке для записи инициализирует хранилище и возвращает `1` (все ключи записи добавлены автоматически). При повторной загрузке возвращает ключ указанной строки. |

### Поиск по ключу

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetLine(Rec, Key)` | arg0: Integer (запись), arg1: Integer (ключ) | Integer или `NULL_REF` | Возвращает номер строки по ключу. Если строка не найдена — `NULL_REF`. При недопустимом номере записи генерируется ошибка. В ядре версии ≥ 46.0 ключ читается как 64-битное значение (`variant2int64`). |

### Работа с псевдоключами

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `ResolvePseudoKeys(Rec, Query, Field)` | arg0: Integer/String (запись), arg1: Query (по ссылке), arg2: String/Integer (поле) | Empty | Заполняет внутреннюю карту псевдоключей из значений поля запроса. Выполняет пакетный поиск строк блоками по 1000 (`BATCH_SIZE`). Для Worker Data ищет по внутренним идентификаторам; для обычных записей псевдоключ формируется из номера записи и строки. |
| `GetPseudoKeyLine(Key)` | arg0: Integer (псевдоключ, 64-битное значение) | Integer | Возвращает номер строки по псевдоключу, ранее загруженному через `ResolvePseudoKeys`. Если ключ не найден — генерируется ошибка. |
| `GetLinePseudoKey(Rec, Line)` | arg0: Integer/String (запись), arg1: Integer (строка) | Integer (64-битное значение) | Возвращает псевдоключ для строки. Для Worker Data — внутренний идентификатор строки (`LINE_ID`); для обычных записей — значение, сформированное из номера записи и строки (`line + 1`). |

## Константы

| Имя | Значение | Назначение |
|------|----------|------------|
| `BATCH_SIZE` | `1000` | Размер пакета при блочном поиске псевдоключей в `ResolvePseudoKeys`. Определяет количество строк, читаемых за один вызов `get_elementary_data_block`. |

## Примеры

Загрузка ключей и поиск строки по ключу:

```EME-L
objResolver = Object("KeyResolver");
nRec = 15;
'Загрузить все ключи записи — при первом вызове вернёт 1'
Result = objResolver.LoadKey(nRec, 0);
If (Result = 1)
    'Ключи инициализированы, ищем строку по ключу'
    nLine = objResolver.GetLine(nRec, 123456);
    If (nLine != NULL_REF)
        Message("Строка найдена: " & nLine);
    End If
End If
```

Разрешение псевдоключей из запроса и получение номера строки:

```EME-L
'argField — имя поля с псевдоключами в результате запроса'
objResolver = Object("KeyResolver");
objResolver.ResolvePseudoKeys("Товары", objQuery, "ИдентификаторСтроки");
'После разрешения — получить номер строки по псевдоключу'
nLine = objResolver.GetPseudoKeyLine(nPseudoKey);
'Получить псевдоключ для произвольной строки записи'
nPseudoKey = objResolver.GetLinePseudoKey("Товары", nLine);
```
