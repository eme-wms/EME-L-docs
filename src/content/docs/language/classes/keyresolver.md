# Класс KeyResolver

Класс `KeyResolver` в языке EME-L — класс для определения соответствия между ключами строк и номерами строк записей базы данных EME. Предоставляет механизм разрешения ключей строк: поиск строки по ключу, загрузка ключей в определитель, формирование и разрешение псевдоключей для импорта/экспорта данных. Поддерживает работу с Worker Data (записи с битом `WORKER_DATA_BIT`), где используются внутренние идентификаторы строк, и с обычными записями, где псевдоключ формируется из номера записи и строки.

Используется при импорте данных для сопоставления ссылок на строки между разными базами данных и филиалами, где прямые номера строк могут различаться, а ключи обеспечивают стабильную идентификацию.

Объект класса `KeyResolver` создаётся через `Object()` и не привязан к контексту диалога или браузера — это самостоятельный класс для работы с внутренними структурами ключей. Перед использованием методов поиска (`GetLine`, `GetPseudoKeyLine`) необходимо загрузить ключи методом `LoadKey` или заполнить карту псевдоключей методом `ResolvePseudoKeys`.

> **Ограничение версии ядра.** Методы `GetLine` и `LoadKey` работают только в ядре версии ниже 52.0. В версии 52.0 и выше они вызывают внутреннюю ошибку (`internal_error`). Методы `ResolvePseudoKeys`, `GetPseudoKeyLine` и `GetLinePseudoKey` продолжают работать во всех версиях, но в ядре ≥ 52.0 используют единое поле ключа (`KEY_FIELD_ID`) вместо раздельной логики Worker Data / обычных записей.

## Создание объекта

Класс `KeyResolver` имеет один конструктор — без аргументов.

```EME-L
'Создание пустого объекта определителя ключей'
objResolver = Object("KeyResolver");
```

Конструктор создаёт пустой объект. Ключи загружаются отдельными вызовами `LoadKey` или `ResolvePseudoKeys` после создания.

## Методы

### Загрузка ключей

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `LoadKey(Rec, Line)` | arg0: Integer (запись), arg1: Integer (строка) | Integer | Загружает ключ строки `Line` записи `Rec` во внутреннее хранилище. При первой загрузке для записи инициализирует хранилище и возвращает `1` (все ключи записи добавлены автоматически). При повторной загрузке возвращает ключ указанной строки. Метод работает только в ядре версии < 52.0. |

### Поиск по ключу

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetLine(Rec, Key)` | arg0: Integer (запись), arg1: Integer (ключ) | Integer или `NULL_REF` | Возвращает номер строки по ключу. Если строка не найдена — `NULL_REF`. При недопустимом номере записи генерируется ошибка. В ядре версии ≥ 46.0 ключ читается как 64-битное значение (`variant2int64`). Метод работает только в ядре версии < 52.0. |

### Работа с псевдоключами

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `ResolvePseudoKeys(Rec, Query, Field)` | arg0: Integer/String (запись), arg1: Query (по ссылке), arg2: String/Integer (поле) | Empty | Заполняет внутреннюю карту псевдоключей из значений поля запроса. Выполняет пакетный поиск строк блоками по 1000 (`BATCH_SIZE`). Для Worker Data ищет по внутренним идентификаторам; для обычных записей псевдоключ формируется из номера записи и строки. Работает во всех версиях ядра. |
| `GetPseudoKeyLine(Key)` | arg0: Integer (псевдоключ, 64-битное значение) | Integer | Возвращает номер строки по псевдоключу, ранее загруженному через `ResolvePseudoKeys`. Если ключ не найден в карте, генерируется ошибка. Работает во всех версиях ядра. |
| `GetLinePseudoKey(Rec, Line)` | arg0: Integer/String (запись), arg1: Integer (строка) | Integer (64-битное значение) | Возвращает псевдоключ для строки. Для Worker Data — внутренний идентификатор строки (`LINE_ID`); для обычных записей — значение, сформированное из номера записи и строки (`line + 1`). Работает во всех версиях ядра. |

## Константы

| Имя | Значение | Назначение |
|------|----------|------------|
| `BATCH_SIZE` | `1000` | Размер пакета при блочном поиске псевдоключей в `ResolvePseudoKeys`. Определяет количество строк, читаемых за один вызов `get_elementary_data_block`. |

## Примеры

Загрузка ключей и поиск строки по ключу (ядро < 52.0):

```EME-L
'Создать определитель и загрузить ключи записи (ядро < 52.0)'
objResolver = Object("KeyResolver");
nRec = r_DocLines.GetRecord();
Result = objResolver.LoadKey(nRec, 0);
If (Result = 1)
    'Ключи инициализированы, ищем строку по ключу'
    nLine = objResolver.GetLine(nRec, nKey);
    If (nLine != NULL_REF)
        Message("Строка найдена: " & nLine);
    End If
End If
```

Поиск строки по шестнадцатеричному ключу из внешней БД — типовой паттерн
из модуля синхронизации остатков с ERP (ядро < 52.0):

```EME-L
'#DEV_INITIALS 27.06.2025 EME company
Синхронизация остатков: поиск строки документа по ключу из внешней БД'
KeyResolver = Object("KeyResolver");
r_DocLines = Object("dsDB", "DocLines");

For (Line = 0; Line < TotalCount; Line = Line + 1)
    'Ключ хранится в первых 8 символах поля id как HEX-строка'
    HexLineKey = is_left(RemainsQuery.GetData("id", Line), 8);
    IntLineKey = HexToInt(HexLineKey);
    r_DocLines.SetLine(KeyResolver.GetLine(r_DocLines.GetRecord(), IntLineKey));
    If (r_DocLines.IsValidLine())
        'Строка найдена — обработать данные'
    End If
End For
```

Разрешение псевдоключей из запроса и получение номера строки (все версии ядра):

```EME-L
'argField — имя поля с псевдоключами в результате запроса'
objResolver = Object("KeyResolver");
objResolver.ResolvePseudoKeys("Товары", objQuery, "ИдентификаторСтроки");
'После разрешения — получить номер строки по псевдоключу'
nLine = objResolver.GetPseudoKeyLine(nPseudoKey);
'Получить псевдоключ для произвольной строки записи'
nPseudoKey = objResolver.GetLinePseudoKey("Товары", nLine);
```

Передача `KeyResolver` по ссылке в метод-обёртку — паттерн из модуля
репликации (все версии ядра):

```EME-L
/* #DEV_INITIALS 27.06.2025 EME company
Возвращает ключ строки в реплике */
GetReplicaLineKey(KeyResolver As "KeyResolver", r_Record As "CEMERec")
{
    Return KeyResolver.GetLinePseudoKey(r_Record.GetRecord(), r_Record.GetLine());
}
```
