# Класс ExpImp64

Класс `ExpImp64` в языке EME-L — это 64-разрядный интерфейс к файлам ядерного экспорта/импорта EME. Предоставляет методы для открытия бинарного файла экспорта (сигнатура `EXIM`), последовательного извлечения записей и строк, а также доступа к метаданным файла (версия формата, филиал, дата/время, история предыдущих выгрузок).

Объект класса `ExpImp64` создаётся через `Object()` без аргументов и не привязан к контексту диалога или браузера. Данные из файла читаются во внешний объект `Query`, который передаётся по ссылке в метод `ExtractNextLines`.

## Создание объекта

```EME-L
i_ExpImp = Object("ExpImp64");
```

Конструктор без аргументов создаёт объект с закрытым файлом. Открытие файла выполняется методом `LoadFile`, после чего доступны методы чтения записей и метаданных.

## Открытие файла и управление чтением

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `LoadFile(filePath)` | filePath: String | String | Открывает файл экспорта EME и проверяет сигнатуру `EXIM`. При успехе возвращает пустую строку; при ошибке — текст сообщения (открытие файла, неверная сигнатура). Если файл уже был открыт, предыдущий закрывается автоматически. |
| `ExtractNextRecord()` | — | Boolean | Извлекает следующую запись из файла и подготавливает структуру полей. `TRUE` — запись извлечена; `FALSE` — записи закончились. При неверном формате (отсутствие сигнатур `HDR3`/`HDR4`) генерирует исключение. |
| `ExtractNextLines(query, lineCount)` | query: Query (по ссылке), lineCount: Integer | Empty | Извлекает `lineCount` строк текущей записи и заполняет переданный запрос данными. Перед вызовом необходимо извлечь запись методом `ExtractNextRecord`. Поддерживает специальную обработку полей «Ключи» (64-битное целое) и «Флаги» (32-битное целое); длины текстовых полей ограничиваются размером поля в базе данных. |
| `GetNoOfLines()` | — | Integer | Общее количество строк в текущей записи, извлечённой методом `ExtractNextRecord`. |
| `GetLine()` | — | Integer | Текущая позиция чтения в записи (0-based) после вызова `ExtractNextLines`. |

## Метаданные файла

Все методы метаданных требуют предварительно открытого файла методом `LoadFile`, иначе генерируют исключение.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetVersion()` | — | Integer | Версия формата файла экспорта. |
| `GetExportType()` | — | String | Тип экспорта по последним двум символам имени файла для системных экспортных файлов (`"s1"`, `"s2"`). Пустая строка, если файл не является системным. |
| `GetFilialNo()` | — | Integer | Номер филиала, сформировавшего файл. |
| `GetFilialStatus()` | — | Integer | Статус филиала-источника. |
| `GetFileName()` | — | String | Имя файла экспорта из заголовка. |
| `GetDate()` | — | DateTime | Дата формирования файла экспорта. |
| `GetTime()` | — | DateTime | Время формирования файла экспорта. |
| `GetRecordName()` | — | String | Имя текущей записи, извлечённой `ExtractNextRecord`. Пустая строка, если запись ещё не извлекалась. |

## История предыдущего экспорта

Методы возвращают значения из заголовка текущего файла о предыдущей выгрузке по истории. Требуют открытого файла.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetPrevFileName()` | — | String | Имя предыдущего файла экспорта по истории. Пустая строка, если информация отсутствует. |
| `GetPrevDate()` | — | DateTime | Дата предыдущего файла экспорта по истории. |
| `GetPrevTime()` | — | DateTime | Время предыдущего файла экспорта по истории. |

## Порядок вызова методов

Типичный цикл импорта файла:

1. `LoadFile(path)` — открыть файл, проверить сигнатуру.
2. В цикле: `ExtractNextRecord()` — извлечь запись; `FALSE` — конец файла.
3. `GetRecordName()` / `GetNoOfLines()` — опционально, для маршрутизации.
4. `ExtractNextLines(query, n)` — заполнить порцию строк в `Query`.
5. Повторять шаг 4, пока `GetLine()` не достигнет `GetNoOfLines()`, затем вернуться к шагу 2.

## Примеры

Открытие файла и проверка результата:

```EME-L
i_ExpImp = Object("ExpImp64");
Result = i_ExpImp.LoadFile(FileName);
If (Result != "")
    is_message(tr("Импорт файла"), Result, "OK", "STOP");
    Return;
End If
```

Последовательное извлечение записей и строк в объект `Query`:

```EME-L
i_ExpImp = Object("ExpImp64");
Result = i_ExpImp.LoadFile(FileName);
If (Result == "")
    Query = Object("Query");
    Query.Create();

    While (i_ExpImp.ExtractNextRecord())
        'ExtractNextRecord возвращает TRUE, пока есть записи'
        RecordName = i_ExpImp.GetRecordName();

        While (i_ExpImp.GetLine() < i_ExpImp.GetNoOfLines())
            'Заполнить пакет строк в Query'
            i_ExpImp.ExtractNextLines(Query, 100);
            'Query содержит строки — обработать и очистить'
            Query.Delete();
            Query.Create();
        End While
    End While
End If
```

Сверка имени предыдущего файла с историей импорта:

```EME-L
i_ExpImp = Object("ExpImp64");
Result = i_ExpImp.LoadFile(Folder + FileName);
If (Result == "")
    PrevName = i_ExpImp.GetPrevFileName();
    'PrevName содержит имя предыдущего файла экспорта по истории'
End If
```
