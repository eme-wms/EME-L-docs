# Класс IrrOctree

Класс `IrrOctree` в языке EME-L — класс полигональной сетки (октодерева) движка Irrlicht. Представляет статический трёхмерный объект, хранимый в виде октодерева для оптимизации рендеринга и пространственных запросов в сцене. Позволяет загружать полигональную сетку из mesh-файла или формировать её на основе объекта `IrrMeshCreator` с помощью метода `SetMesh`.

Наследует все методы базового класса [`IrrNode`](./irrnode.md) — управление положением, поворотом, масштабом, видимостью, именем, материалом и текстурой узла.

Используется в EME-L-скриптах для отображения статических 3D-моделей в сцене Irrlicht, когда важна эффективность отрисовки крупных или детальных сеток: октодерево ускоряет отсечение невидимых полигонов по сравнению с обычным узлом `IrrMesh`.

## Создание объекта

В блоке `BEGIN_IMPLEMENT(CIIrrOctree)` нет зарегистрированных конструкторов (`IMPLEMENT_CTOR` отсутствует), поэтому объект `IrrOctree` не создаётся через `Object("IrrOctree", ...)` напрямую. Канонический способ получить узел октодерева — вызвать `AddOctree(meshSource)` у родительского узла `IrrNode`: этот метод создаёт дочерний узел октодерева, инициализирует его внутреннее представление Irrlicht и возвращает ссылку на новый объект `IrrOctree`.

```EME-L
'Создать устройство Irrlicht и корневой узел сцены'
objDevice = Object("IrrDevice");
objRoot   = objDevice.GetRootNode();

'Добавить дочерний узел октодерева из mesh-файла'
objOctree = objRoot.AddOctree("D:\\Models\\warehouse.mesh");
```

`AddOctree` принимает на вход тот же тип аргумента, что и `SetMesh` — путь к mesh-файлу (строка) либо объект `IrrMeshCreator`. После создания к узлу сразу применяются масштаб `(1, 1, 1)` и пустое имя; в дальнейшем имя задаётся методом `SetName` базового класса.

## Метод SetMesh

Класс `IrrOctree` регистрирует единственный собственный метод — `SetMesh`. Все прочие операции (положение, поворот, масштаб, текстура, видимость, имя) наследуются от [`IrrNode`](./irrnode.md).

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetMesh(arg0)` | arg0: String (путь к mesh-файлу) **или** IrrMeshCreator (ссылка) | IrrOctree (ссылка) | Загружает или формирует новую полигональную сетку и устанавливает её для текущего узла IrrOctree (октодерева). При передаче строки путь загружается менеджером сцены Irrlicht; при передаче объекта `IrrMeshCreator` сетка строится вызовом `CreateMesh` этого объекта. Возвращает текущий объект `IrrOctree` для цепочки вызовов. |

Метод `SetMesh` удобен для динамической замены сетки уже созданного узла: он перестраивает внутренний указатель Irrlicht, не меняя остальных свойств узла (имя, положение, текстура). Возвращаемая ссылка на `IrrOctree` позволяет объединять настройку в цепочку.

## Примеры

Создание узла октодерева и настройка позиции и текстуры:

```EME-L
'Корневой узел сцены Irrlicht'
objDevice = Object("IrrDevice");
objRoot   = objDevice.GetRootNode();

'Создать октодерево из mesh-файла и настроить свойства'
objOctree = objRoot.AddOctree("D:\\Models\\rack_sector.mesh");
objOctree.SetPosition(10.0, 0.0, 5.0);
objOctree.SetMaterialTexture("D:\\Textures\\metal.png");
objOctree.SetLighting(TRUE);
objOctree.SetName("Rack#A1");
```

Замена сетки через `IrrMeshCreator` с цепочкой вызовов:

```EME-L
'Программно собрать полигональную сетку'
meshCreator = Object("IrrMeshCreator");
meshCreator.AddCube(2.0);

'Установить новую сетку в существующий узел октодерева'
objOctree.SetMesh(meshCreator).SetClickable(TRUE);
```
