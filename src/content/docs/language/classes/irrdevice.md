# Класс IrrDevice

Класс `IrrDevice` в языке EME-L — корневой объект 3D-движка Irrlicht. Управляет трехмерной сценой в составе 3D-органа управления EME.WMS: создаёт и сбрасывает устройство Irrlicht, предоставляет доступ к корневому узлу сцены и активной камере, хранит реестры именованных узлов и спрайтов, отрисовывает спрайты, привязанные к узлам сцены («верёвочки»), и настраивает глобальные параметры рендеринга — рассеянное освещение, цвет теней, глобальный масштаб, режим предзагрузки ресурсов.

Через методы класса скрипт EME-L получает текущий FPS и размеры экрана/окна вывода видеодрайвера, управляет автоматическим обновлением 3D-органа управления и регистрирует спрайты по имени или из дерева свойств `PropertyTree`. Класс является точкой входа для построения интерактивной трёхмерной визуализации в EME-L — от него получают дочерние узлы (`IrrNode`, `IrrCamera`, `IrrSprite`), на которых строится вся сцена.

## Создание объекта

Класс `IrrDevice` имеет один конструктор — без аргументов.

```EME-L
'Создать 3D-устройство Irrlicht без привязки к окну'
m_Irrlicht = Object("IrrDevice");
```

Конструктор создаёт внутреннее устройство Irrlicht с типом драйвера `EDT_NULL` (без вывода в окно). Для привязки к 3D-органу управления EME.WMS объект обычно создаётся в обработчике `OnGetAnswer` и сохраняется в члене класса с префиксом `m_`.

## Управление сценой

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Reset()` | — | Empty | Сбрасывает 3D-орган управления: удаляет вспомогательный узел клика, активную камеру и корневой узел сцены, очищает связи спрайтов с узлами, уничтожает все созданные спрайты и очищает реестры именованных узлов и спрайтов. |
| `Update()` | — | Empty | Принудительно обновляет 3D-орган управления, вызывая обновление окна-хоста. |
| `SetAutoUpdate(arg0)` | arg0: Boolean | Empty | Включает (`TRUE`) или отключает (`FALSE`) автоматическое обновление 3D-органа управления. |
| `GetRootNode()` | — | IrrNode | Корневой узел сцены. При первом обращении создаётся и кэшируется объект-обёртка `IrrNode`, связанный с внутренним корневым узлом Irrlicht. |
| `GetActiveCamera()` | — | IrrCamera или Empty | Активная камера сцены. Возвращает `Empty`, если активная камера не задана. При каждом вызове обновляет внутренний объект-обёртку `IrrCamera` данными текущей активной камеры Irrlicht. |
| `SetGlobalScale(arg0)` | arg0: Real | Empty | Устанавливает глобальный масштаб сцены. Влияет на масштаб и положение узлов, имеющих родителем корневой узел сцены. |

## Поиск узлов и спрайтов

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `FindNodeByName(arg0)` | arg0: String | IrrNode или Empty | Находит ранее зарегистрированный узел сцены по имени. Возвращает `Empty`, если узел не найден. |
| `FindSpriteByName(arg0)` | arg0: String | IrrSprite или Empty | Находит созданный спрайт по имени. Возвращает `Empty`, если спрайт не найден. |
| `GetNodeNames(arg0)` | arg0: Array (по ссылке) | Empty | Заполняет переданный массив именами всех зарегистрированных узлов сцены. |
| `GetSpriteNames(arg0)` | arg0: Array (по ссылке) | Empty | Заполняет переданный массив именами всех созданных спрайтов. |

## Создание спрайтов

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddSprite(arg0, arg1)` | arg0: String (имя), arg1: Rect (по ссылке) | IrrSprite | Создаёт спрайт с заданным именем и прямоугольником положения/размера. Если спрайт с таким именем уже существует, возвращает ранее созданный объект. |
| `AddSprite(arg0)` | arg0: PropertyTree (по ссылке) | IrrSprite | Создаёт спрайт на основе параметров из дерева свойств. |

## Параметры рендеринга

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetFPS()` | — | Integer | Текущее количество кадров в секунду (FPS), рассчитанное видеодрайвером Irrlicht. |
| `GetScreenWidth()` | — | Integer | Ширина экрана/окна вывода видеодрайвера Irrlicht, в пикселях. |
| `GetScreenHeight()` | — | Integer | Высота экрана/окна вывода видеодрайвера Irrlicht, в пикселях. |
| `SetAmbientLight(arg0)` | arg0: Integer (RGBA, `0xAARRGGBB`, компоненты 0..255) | Empty | Задаёт цвет рассеянного (окружающего) освещения сцены Irrlicht. |
| `SetShadowColor(arg0)` | arg0: Integer (RGBA, `0xAARRGGBB`, компоненты 0..255) | Empty | Задаёт цвет теней, используемый менеджером сцены Irrlicht. |
| `SetPreloadResources(arg0)` | arg0: Integer (0 — нет, ненулевое — да) | Empty | Задаёт признак необходимости предварительной загрузки ресурсов на сервере. Значение сохраняется в свойстве корневого узла. |
| `IsPreloadResources()` | — | Integer | Возвращает `1`, если предварительная загрузка ресурсов включена, `0` — если отключена. Значение считывается из свойства корневого узла. |

## Примеры

Создание 3D-устройства и базовая настройка сцены (по мотивам `ATWms3D.txt`):

```EME-L
'Создать IrrDevice и задать масштаб и режим предзагрузки ресурсов'
m_Irrlicht = Object("IrrDevice");
m_Irrlicht.SetGlobalScale(10.0);
m_Irrlicht.SetPreloadResources(FALSE);
```

Настройка освещения и теней (по мотивам `Wms3DLightComponent.txt`):

```EME-L
'Рассеянный свет и цвет теней в формате 0xAARRGGBB'
m_Irrlicht.SetAmbientLight(is_RGBA(80, 80, 80, 255));
m_Irrlicht.SetShadowColor(is_RGBA(80, 80, 80, 150));
```

Поиск курсора по имени и создание спрайта-этикетки (по мотивам `Wms3DCursorComponent.txt`):

```EME-L
'Найти зарегистрированный узел курсора'
CursorNode As "IrrMesh" = m_Irrlicht.FindNodeByName("Cursor");
If (is_empty(CursorNode))
    'Узел не найден — создать через корневой узел сцены'
    RootNode = m_Irrlicht.GetRootNode();
End If

'Создать спрайт-этикетку с привязкой к узлу курсора'
CursorSpriteLabel = m_Irrlicht.AddSprite("Cursor#label", Object("Rect", 0, 0, 200, 50));
CursorSpriteLabel.LinkToNode(CursorNode, 100);
```
