# Класс Legend

Класс `Legend` в языке EME-L — класс для создания и отображения графических легенд с цветовыми маркерами и текстовыми подписями. Представляет собой обертку над ядерным классом `CLegendElement` и предоставляет методы для формирования легенды из набора пунктов, каждый из которых характеризуется RGB-цветом, текстовой меткой и опциональным числовым тегом.

Основные возможности:

- Добавление пунктов легенды с указанием цвета, текста и тега.
- Удаление всех пунктов легенды.
- Установка заголовка легенды.
- Выделение пункта легенды по цвету (отображается жирным шрифтом).
- Вычисление размеров легенды (ширина и высота) с учетом шрифта, отступов и размеров цветовых маркеров.
- Отрисовка легенды на объекте `IrrImage` с заданными координатами.
- Поиск пунктов легенды по цвету или тегу.
- Получение цвета пункта по индексу и количества пунктов.
- Сохранение и загрузка состава легенды в дерево свойств (`PropertyTree`).

При отрисовке легенда формирует прямоугольную область с заголовком (если задан), цветовыми квадратами-индикаторами и соответствующими текстовыми подписями. Размеры вычисляются автоматически на основе метрик шрифта Arial. Используется в графических отчетах и визуализациях для пояснения цветовой кодировки данных.

## Создание объекта

Класс `Legend` имеет один конструктор — без аргументов (единственная перегрузка, `argCount = 0`).

```EME-L
'Создает объект легенды с параметрами по умолчанию'
Legend = Object("Legend");
```

Параметры по умолчанию, устанавливаемые в конструкторе:

| Параметр | Значение | Описание |
|----------|----------|----------|
| Высота текста | 8 | Размер шрифта в пунктах |
| Размер маркера | 20 x 10 | Ширина и высота цветового квадрата в пикселях |
| Отступы | 3 x 3 | Внутренние отступы легенды в пикселях |
| Ограничители | 3 x 3 | Расстояние между элементами в пикселях |
| Фоновый цвет | RGBA(255, 255, 230, 225) | Полупрозрачный светло-жёлтый фон (альфа 225) |

## Настройка и управление пунктами

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetCaption(arg0)` | arg0: String | Empty | Задает текстовый заголовок легенды. При изменении сбрасывается кэш размера изображения. |
| `AddInfo(arg0, arg1)` | arg0: Integer (цвет), arg1: String (текст) | Boolean | Добавляет пункт с цветом и текстом. Возвращает `TRUE` (-1), если пункт добавлен; `FALSE` (0), если пункт с таким сочетанием цвета и текста уже существует. Сбрасывает кэш размера. |
| `AddInfo(arg0, arg1, arg2)` | + arg2: Integer (тег) | Boolean | Добавляет пункт с цветом, текстом и числовым тегом. Возвращает `TRUE` (-1) при успехе, `FALSE` (0) при дубликате. Сбрасывает кэш размера. |
| `RemoveAll()` | — | Empty | Удаляет все пункты легенды, включая заголовок и цветовые маркеры. Сбрасывает кэш размера. |
| `SelectColor(arg0)` | arg0: Integer (цвет) | Empty | Выделяет пункт с указанным цветом. При отрисовке выделенный пункт отображается жирным шрифтом. Сбрасывает кэш размера. |

## Размеры и отрисовка

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetWidth(arg0)` | arg0: IrrImage (по ссылке) | Integer | Ширина легенды в пикселях с учетом текущего состава пунктов, заголовка, шрифта, отступов и размеров маркеров. Размер вычисляется на основе метрик шрифта Arial и кэшируется до следующего изменения состава. |
| `GetHeight(arg0)` | arg0: IrrImage (по ссылке) | Integer | Высота легенды в пикселях. Вычисляется аналогично `GetWidth`. |
| `Draw(arg0, arg1, arg2)` | arg0: IrrImage (по ссылке), arg1: Integer (x), arg2: Integer (y) | Empty | Выполняет отрисовку легенды на указанном изображении в заданных координатах. |

### Детали отрисовки `Draw`

`Draw` последовательно выполняет:

1. **Фон и рамка** — полупрозрачный прямоугольник цвета фона `RGBA(255, 255, 230, 225)` и рамка того же цвета по контуру (толщина 1 пиксель).
2. **Заголовок** (если задан `SetCaption`) — рисуется **жирным** шрифтом Arial, выравниванием по левому краю; под ним добавляется вертикальный ограничитель.
3. **Пункты** — для каждого пункта рисуется цветовой маркер (квадрат 20x10) и текстовая подпись:
   - маркер заливается цветом пункта с альфа 255 (непрозрачный), рамка маркера — затемнённый цвет (RGB, делённый на 2), после чего цвет пера сбрасывается на чёрный;
   - текст подписи рисуется шрифтом Arial; **выделенный** методом `SelectColor` пункт отображается жирным, остальные — обычным начертанием;
   - **лидирующие пробелы текста отбрасываются** перед отрисовкой — они используются в EME-L для управления порядком сортировки пунктов и не должны попадать в вывод;
   - между пунктами добавляется вертикальный ограничитель (последний ограничитель убирается).

> **Примечание о кэше размера:** `GetWidth`/`GetHeight` вычисляют ширину по метрикам **жирного** шрифта для всех пунктов (в Qt-пути), поэтому возвращаемая ширина может быть чуть больше реальной ширины при отрисовке обычным шрифтом невыбранных пунктов.

## Поиск и доступ к данным

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `FindColor(arg0)` | arg0: Integer (цвет) | Integer | Ищет пункт по RGB-цвету. Возвращает индекс (>= 0) или -1, если не найден. |
| `FindByTag(arg0)` | arg0: Integer (тег) | Integer | Ищет пункт по числовому тегу. Возвращает индекс (>= 0) или -1, если не найден. |
| `GetColor(arg0)` | arg0: Integer (индекс) | Integer | Возвращает RGB-цвет пункта по индексу (от 0 до `GetSize()-1`). |
| `GetSize()` | — | Integer | Количество пунктов в текущей легенде. |

## Сериализация

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SaveLegend(arg0)` | arg0: PropertyTree (по ссылке) | Empty | Сохраняет состав легенды в дерево свойств: поле `caption` и дочерний узел `items`, где каждый пункт хранит поля `color` (long), `text` (string), `tag` (long). |
| `LoadLegend(arg0)` | arg0: PropertyTree (по ссылке) | Empty | Загружает состав легенды из дерева свойств. Перед загрузкой очищает текущий состав. При отсутствии полей используются значения по умолчанию (`color`/`tag` = 0, `text` = ""). Сбрасывает кэш размера. |

## Примеры

### Формирование легенды и отрисовка на IrrImage (из `Wms3DLegendComponent.OnDraw`)

Реальный фрагмент из кодовой базы: формируется легенда с тремя пунктами, выделяется красный, вычисляются размеры и легенда рисуется на прозрачном изображении, которое затем помещается в спрайт на экране.

```EME-L
Legend = Object("Legend");
Legend.SetCaption(tr("Тип ячеек:"));
Legend.AddInfo(is_RGB(255, 0, 0), tr("Красный"));
Legend.AddInfo(is_RGB(0, 255, 0), tr("Зеленый"));
Legend.AddInfo(is_RGB(0, 0, 155), tr("Синий"));
Legend.SelectColor(is_RGB(255, 0, 0));

'Вычисление размеров и отрисовка'
TestImage = Object("IrrImage");
Width = Legend.GetWidth(TestImage);
Height = Legend.GetHeight(TestImage);

Image = Object("IrrImage", Width, Height);
Image.Fill(is_RGBA(255, 255, 255, 0));
Legend.Draw(Image, 0, 0);
```

### Сохранение легенды в дерево свойств (из `TestImage.TestLegend`)

Реальный фрагмент: состав легенды сериализуется в `PropertyTree`, затем его можно получить как JSON для передачи или хранения.

```EME-L
'Сохранение состава легенды для передачи или хранения'
Legend = Object("Legend");
Legend.SetCaption(tr("Цвет"));
Legend.AddInfo(is_RGB(255, 0, 0), tr("Красный"));
Legend.AddInfo(is_RGB(0, 255, 0), tr("Зеленый"));
Legend.AddInfo(is_RGB(0, 0, 255), tr("Синий"));

PropertyTree = Object("PropertyTree");
Legend.SaveLegend(PropertyTree);
Content = PropertyTree.GetJSON();
```

### Полный цикл: перерисовка легенды по запросу (из `Wms3DRackComponent.UpdateLegend`)

Реальный фрагмент: при смене раскраски стеллажей обновляется заголовок и пункты легенды, пересчитываются размеры, удаляется старый экранный спрайт и создаётся новый.

```EME-L
'Обновляет легенду при смене типа раскраски'
TestImage = Object("IrrImage");
Width = m_Legend.GetWidth(TestImage);
Height = m_Legend.GetHeight(TestImage);
ScreenWidth = m_Irrlicht.GetScreenWidth();
ScreenHeight = m_Irrlicht.GetScreenHeight();

X = ScreenWidth - Width - 10;
Y = 10;
Rect = Object("Rect", X, Y, X + Width, Y + Height);
LegendSprite = m_Irrlicht.FindSpriteByName("Rack#Legend");
If (~is_empty(LegendSprite))
    LegendSprite.Remove();
End If
LegendSprite = m_Irrlicht.AddSprite("Rack#Legend", Rect);
LegendSprite.SetAlignment("lowerRight", "lowerRight",,);

Image = Object("IrrImage", Width, Height);
Image.Fill(is_RGBA(255, 255, 255, 0));
m_Legend.Draw(Image, 0, 0);
LegendSprite.SetImage(Image);
```
