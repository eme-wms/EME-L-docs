# Класс IrrAnimatedMesh

Класс `IrrAnimatedMesh` в языке EME-L — класс анимированной полигональной сетки движка Irrlicht. Представляет трёхмерный объект с поддержкой ключевой анимации, загружаемой из mesh-файла. Позволяет управлять диапазоном и скоростью воспроизведения анимации, окрашивать вершины в RGBA-цвет, задавать прозрачность (альфа-канал) вершин, а также добавлять и удалять объёмные тени.

Наследует все методы базового класса [`IrrNode`](./irrnode.md) — управление положением, поворотом, масштабом, видимостью, именем, материалом и текстурой узла.

Используется в EME-L-скриптах для отображения анимированных 3D-моделей в сцене Irrlicht (например, движущиеся персонажи, механизмы, циклические анимации).

## Создание объекта

В блоке `BEGIN_IMPLEMENT(CIIrrAnimatedMesh)` нет зарегистрированных конструкторов (`IMPLEMENT_CTOR` отсутствует), поэтому объект `IrrAnimatedMesh` не создаётся через `Object("IrrAnimatedMesh", ...)` напрямую. Канонический способ получить анимированную полигональную сетку — вызвать `AddAnimatedMesh(filePath)` у родительского узла `IrrNode`: этот метод создаёт дочерний узел, загружает mesh-файл и возвращает ссылку на новый объект `IrrAnimatedMesh`.

```EME-L
'Создать устройство Irrlicht и корневой узел сцены'
objDevice = Object("IrrDevice");
objRoot   = objDevice.GetRootNode();

'Добавить дочерний узел анимированной сетки из mesh-файла'
objAnim = objRoot.AddAnimatedMesh("D:\\Models\\worker.mesh");
```

`AddAnimatedMesh` принимает путь к mesh-файлу (строка). После создания к узлу сразу применяются масштаб `(1, 1, 1)` и пустое имя; в дальнейшем имя задаётся методом `SetName` базового класса. Если mesh-файл не удалось загрузить, ядро EME-L выводит ошибку через `smart_error`.

## Замена сетки

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetMesh(arg0)` | arg0: String (путь к mesh-файлу) | IrrAnimatedMesh (ссылка) | Загружает новый mesh-файл и заменяет текущую полигональную сетку объекта на загруженную модель. Возвращает ссылку на текущий объект `IrrAnimatedMesh` для цепочки вызовов. |

`SetMesh` удобен для динамической замены анимированной модели уже созданного узла: он перестраивает внутренний указатель Irrlicht, не меняя остальных свойств узла (имя, положение, текстура, настройки анимации). Возвращаемая ссылка позволяет объединять настройку в цепочку.

## Цвет и прозрачность вершин

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetVertexColors(arg0)` | arg0: Integer (RGBA) | Empty | Окрашивает все вершины текущей полигональной сетки в указанный RGBA-цвет (32-битное значение `0xAARRGGBB`). |
| `SetVertexColorAlpha(arg0)` | arg0: Integer (0–255) | Empty | Задаёт прозрачность (альфа-канал) вершин текущей полигональной сетки. Диапазон: `0` — полностью прозрачно, `255` — непрозрачно. |

Цветовые методы работают с вершинами сетки напрямую через `IMeshManipulator` Irrlicht — они не меняют материал узла. Для полной замены цвета используйте `SetVertexColors` с непрозрачным значением (`255` в альфа-канале), а для управления прозрачностью существующих вершин — `SetVertexColorAlpha`.

## Анимация

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetFrameLoop(arg0, arg1)` | arg0: Integer (начальный кадр), arg1: Integer (конечный кадр) | Empty | Устанавливает диапазон кадров для циклического воспроизведения анимации. |
| `SetAnimationSpeed(arg0)` | arg0: Integer (кадров в секунду) | Empty | Задаёт скорость воспроизведения анимации в кадрах в секунду. |

`SetFrameLoop` выбирает поддиапазон ключевых кадров анимированной сетки, который будет проигрываться циклически. `SetAnimationSpeed` задаёт темп воспроизведения в кадрах в секунду; внутри значение приводится к вещественному типу Irrlicht `f32`.

## Тени

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddShadow()` | — | Empty | Добавляет к объекту объёмную тень (shadow volume). Если тень уже добавлена, повторного добавления не происходит. |
| `RemoveShadow()` | — | Empty | Удаляет ранее добавленную объёмную тень из сцены. Если тень не была добавлена, метод ничего не делает. |

Оба метода идемпотентны: повторный вызов `AddShadow` не накапливает тени, а `RemoveShadow` безопасно вызывает на узле без тени. Для отображения теней в сцене Irrlicht требуется включить соответствующий режим устройства `IrrDevice`.

## Примеры

Создание анимированной модели и настройка воспроизведения:

```EME-L
'Корневой узел сцены Irrlicht'
objDevice = Object("IrrDevice");
objRoot   = objDevice.GetRootNode();

'Загрузить анимированную модель и настроить анимацию'
objAnim = objRoot.AddAnimatedMesh("D:\\Models\\worker.mesh");
objAnim.SetPosition(10.0, 0.0, 5.0);
objAnim.SetAnimationSpeed(30);
objAnim.SetFrameLoop(0, 100);
objAnim.SetName("Worker#A1");
```

Подсветка вершин и добавление тени:

```EME-L
'Окрасить вершины в жёлто-зелёный (непрозрачный)'
objAnim.SetVertexColors(0xFFCCFF00);

'Задать полупрозрачность вершин (128 из 255)'
objAnim.SetVertexColorAlpha(128);

'Добавить объёмную тень'
objAnim.AddShadow();
```

Динамическая замена сетки с цепочкой вызовов:

```EME-L
'Заменить модель в существующем узле'
objAnim.SetMesh("D:\\Models\\worker_v2.mesh").SetClickable(TRUE);
```
