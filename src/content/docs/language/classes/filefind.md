# Класс FileFind

Класс `FileFind` в языке EME-L предназначен для поиска файлов и каталогов на локальной файловой системе.

Предоставляет механизм последовательного перебора файлов и каталогов, соответствующих заданной маске имени. Поддерживает фильтрацию по атрибутам файла и проверку типа найденного объекта (файл, каталог, служебные метки).

Основной сценарий использования: создание объекта, вызов `FindFile` с указанием маски, циклический вызов `FindNextFile` до исчерпания результатов, получение имени и пути через `GetFileName` и `GetFilePath`, проверка атрибутов через `IsDirectory`, `IsDots` и `MatchesMask`. По завершении работы рекомендуется вызывать `Close` для освобождения ресурсов.

## Создание объекта

```EME-L
'Поиск файлов по маске с последующим перебором результатов
objFileFind = Object("FileFind");
```

Конструктор без аргументов создаёт объект для последовательного перебора файлов и каталогов. После создания объекта для начала поиска необходимо вызвать метод `FindFile`.

## Методы

### Перебор файлов

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `FindFile([mask])` | mask: String | Boolean | Начинает поиск файлов или каталогов по маске. Маска может содержать символы подстановки `*` и `?`, например `"C:\\*.txt"` или `"D:\\Data\\*.*"`. Возвращает `TRUE`, если найден хотя бы один объект. Если параметр не указан, используется пустая строка. |
| `FindNextFile()` | — | Boolean | Переходит к следующему найденному файлу или каталогу. Возвращает `TRUE`, если следующий объект найден, и `FALSE`, когда объекты закончились. |
| `Close()` | — | Empty | Завершает поиск и освобождает связанные системные ресурсы. |

### Информация о текущем объекте

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetFileName()` | — | String | Имя текущего найденного файла или каталога без пути. Пустая строка, если поиск не начат или объект не найден. |
| `GetFilePath()` | — | String | Полный путь к текущему найденному файлу или каталогу, включая имя. Пустая строка, если поиск не начат или объект не найден. |

### Проверки атрибутов

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `IsDirectory()` | — | Boolean | `TRUE` — текущий найденный объект является каталогом. `FALSE` — обычный файл или поиск не начат. |
| `IsDots()` | — | Boolean | `TRUE` — имя текущего найденного объекта равно `.` или `..`. `FALSE` — не служебная метка или поиск не начат. |
| `MatchesMask(mask)` | mask: Integer | Boolean | Проверяет, соответствуют ли атрибуты текущего файла заданной битовой маске. Маска формируется объединением (побитовым ИЛИ) констант файловых атрибутов Windows. |

### Константы файловых атрибутов для MatchesMask

| Константа | Значение | Описание |
|-----------|----------|----------|
| `FILE_ATTRIBUTE_READONLY` | `0x00000001` | Только для чтения. |
| `FILE_ATTRIBUTE_HIDDEN` | `0x00000002` | Скрытый файл. |
| `FILE_ATTRIBUTE_SYSTEM` | `0x00000004` | Системный файл. |
| `FILE_ATTRIBUTE_DIRECTORY` | `0x00000010` | Каталог. |
| `FILE_ATTRIBUTE_ARCHIVE` | `0x00000020` | Архивный. |
| `FILE_ATTRIBUTE_NORMAL` | `0x00000080` | Обычный файл. |
| `FILE_ATTRIBUTE_TEMPORARY` | `0x00000100` | Временный файл. |
| `FILE_ATTRIBUTE_COMPRESSED` | `0x00000800` | Сжатый файл. |

## Примеры

### Перебор всех файлов в каталоге

```EME-L
'#DEV_INITIALS 29.06.2026 EME company
Перебор текстовых файлов в каталоге и вывод их имён
objFileFind = Object("FileFind");
Found = objFileFind.FindFile("D:\\Data\\*.txt");
While (Found)
    If (Not objFileFind.IsDots())
        FileName = objFileFind.GetFileName();
        FilePath = objFileFind.GetFilePath();
    End If
    Found = objFileFind.FindNextFile();
End While
objFileFind.Close();
```

### Рекурсивный сбор файлов по маске

```EME-L
'#DEV_INITIALS 29.06.2026 EME company
Собрать все лог-файлы из каталога, исключая служебные метки
objFileFind = Object("FileFind");
arrFiles = Object("Array");
IsFind = objFileFind.FindFile(m_csLogDir + "*.*");
While (IsFind)
    If (Not objFileFind.IsDots())
        arrFiles.Add(objFileFind.GetFilePath());
    End If
    IsFind = objFileFind.FindNextFile();
End While
objFileFind.Close();
```
