# Класс CryptoPro

Класс `CryptoPro` в языке EME-L обеспечивает формирование электронной подписи CADES-BES с использованием сертификатов КриптоПро и библиотеки `cades.dll`. Предоставляет методы для выбора сертификата из системных хранилищ Windows, создания усовершенствованной подписи по российским криптографическим стандартам ГОСТ Р 34.11-2012, настройки алгоритма хеширования и получения информации об ошибках.

Объект класса `CryptoPro` создаётся через `Object()` и не привязан к контексту диалога или браузера. Для работы требуются установленная библиотека `cades.dll` и действующий сертификат в системном хранилище Windows.

## Создание объекта

```EME-L
'Конструктор без аргументов — сертификат выбирается позже методом SetCertificate'
objCrypto = Object("CryptoPro");

'Конструктор с серийным номером — сертификат ищется в хранилище "MY"'
objCrypto = Object("CryptoPro", "02B537A6001BACA59848C12354E25B4985");

'Конструктор с серийным номером и именем хранилища'
objCrypto = Object("CryptoPro", "02B537A6001BACA59848C12354E25B4985", "MY");
```

Серийный номер указывается в шестнадцатеричном представлении; поиск выполняется без учёта регистра. Имя хранилища по умолчанию — `"MY"` (личные сертификаты пользователя).

## Выбор сертификата

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetCertificate()` | — | Boolean | Выполняет поиск сертификата в хранилище `"MY"` с пустым серийным номером. |
| `SetCertificate(arg0)` | arg0: String (серийный номер) | Boolean | Ищет сертификат по серийному номеру в хранилище `"MY"`. |
| `SetCertificate(arg0, arg1)` | arg0: String (серийный номер), arg1: String (хранилище) | Boolean | Ищет сертификат по серийному номеру в указанном хранилище. |
| `GetCertificate()` | — | Reference | Системный контекст сертификата Windows (`PCCERT_CONTEXT`), установленный ранее. `0` — сертификат не установлен. |

Допустимые имена хранилищ: `"MY"` (личные, по умолчанию), `"CA"` (центры сертификации), `"ROOT"` (доверенные корневые), `"SPC"` (отозванные).

## Формирование подписи

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Sign(arg0)` | arg0: String или CDataStorage | String | Формирует присоединённую подпись CADES-BES. Base64 без символов перевода строки. |
| `Sign(arg0, arg1)` | arg0: String или CDataStorage, arg1: Boolean | String | То же; `arg1=TRUE` — откреплённая (detached) подпись, `FALSE` (по умолчанию) — присоединённая. |

Параметр данных принимает строку (подписывается содержимое в кодировке системной локали) или ссылку на объект `CDataStorage` с бинарными данными. При ошибке возвращается пустая строка — текст ошибки доступен через `GetLastError`.

## Настройка алгоритма хеширования

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetGOST(arg0)` | arg0: String (OID алгоритма) | Integer | Устанавливает алгоритм хеширования ГОСТ. `1` — установлен, `0` — аргумент не передан. |
| `SetGOST()` | — | Integer | Без аргументов возвращает `0`, алгоритм не изменяется. |

По умолчанию используется ГОСТ Р 34.11-2012 с длиной хеша 256 бит (OID `1.2.643.7.1.1.2.2`). Передаётся строковый OID, например `"1.2.643.7.1.1.2.2"`.

## Информация об ошибках

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetLastError()` | — | String | Текст последней ошибки сертификата или подписи на языке системной локали. Пустая строка — ошибок не было. |

## Примеры

Установка сертификата и формирование откреплённой подписи (шаблон из реального использования, серийный номер и данные заменены на плейсхолдеры):

```EME-L
objCrypto = Object("CryptoPro");
objCrypto.SetCertificate("02B537A6001BACA59848C12354E25B4985", "MY");
Sign = objCrypto.Sign(DocumentText, True);
If (Sign == "")
    is_catastrophic_log("Ошибка подписи " + objCrypto.GetLastError());
End If
```

Использование конструктора с серийным номером и формирование присоединённой подписи для авторизационного запроса:

```EME-L
m_objCrypto = Object("CryptoPro", CERT_SN, "MY");
SignData = m_objCrypto.Sign(Data, False);
If (SignData == "")
    is_catastrophic_log("RequestAuthToken Ошибка подписи " + m_objCrypto.GetLastError());
    Return "";
End If
```

Явная смена алгоритма хеширования перед подписанием:

```EME-L
objCrypto = Object("CryptoPro", "02B537A6001BACA59848C12354E25B4985");
objCrypto.SetGOST("1.2.643.7.1.1.2.3");
Sign = objCrypto.Sign(Payload, False);
```
