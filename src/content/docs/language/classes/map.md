# Класс Map

Класс `Map` в языке EME-L — класс ассоциативного массива (хэш-таблицы) для хранения пар «ключ-значение» и быстрого доступа к данным по ключу. Предоставляет контейнер, в котором каждое значение ассоциировано с уникальным ключом.

Поддерживает ключи четырёх типов: строка (`String`), целое число (`Integer`), вещественное число (`Real`) и 64-битное целое (`Long Integer`). Тип ключа задаётся при создании объекта или изменяется позже; при смене типа содержимое объекта полностью очищается.

Объект создаётся через `Object("Map", …)` и не привязан к контексту диалога или браузера — это самостоятельный класс для построения словарей, кэшей, индексов и промежуточных коллекций с произвольным доступом по идентификатору.

## Создание объекта

Класс `Map` имеет три конструктора — один на каждое число аргументов.

```EME-L
'Без аргументов — размер хэш-таблицы по умолчанию 17, тип ключа String'
mapNames = Object("Map");
```

```EME-L
'С размером хэш-таблицы — тип ключа String'
mapNames = Object("Map", 100);
```

```EME-L
'С размером хэш-таблицы и типом ключа — Integer'
mapIds = Object("Map", 100, 1);
```

Размер хэш-таблицы должен быть больше 0 и приблизительно равен ожидаемому количеству элементов, умноженному на 1.2. Избыточно большой размер приводит к неиспользуемым ячейкам памяти, а слишком маленький замедляет поиск из-за последовательного перебора ключей с совпадающим хэшем.

Тип ключа определяется типом второго аргумента:

| Аргумент `keyType` | Тип ключа |
|--------------------|-----------|
| `1` (целое число) | Integer |
| `1.0` (вещественное число) | Real |
| `"str"` (строка) | String |
| `is_int64(1)` (Long Integer) | Long Integer |

## Доступ по ключу

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Lookup(key)` | key: Integer / Real / String / Long Integer | любой тип | Значение по ключу либо `Empty`, если ключ отсутствует. Тип ключа должен соответствовать типу ключа объекта. |
| `Lookup(key, defaultValue)` | key: ключ, defaultValue: любой тип, кроме Object | любой тип | Значение по ключу либо `defaultValue`. Выбрасывает исключение, если в качестве значения по умолчанию передан Object — используйте `Lookup` с одним параметром и проверяйте результат на `is_empty()`. |
| `IsKeyExists(key)` | key: ключ | Boolean | TRUE — ключ найден, FALSE — ключ отсутствует. |
| `SetAt(key, value)` | key: ключ, value: любой тип | Empty | Добавляет пару «ключ-значение». Если ключ уже существует, значение перезаписывается. Для типа ключа String допускается передача целого или вещественного числа, которое будет преобразовано в строку. Выбрасывает исключение при несовпадении типа ключа (кроме String + Integer/Real). |
| `RemoveKey(key)` | key: ключ | Boolean | Удаляет ключ и связанное значение. TRUE — ключ удалён, FALSE — ключ отсутствовал. При удалении текущего ключа итератор `NextKey` автоматически смещается на один элемент вперёд. |
| `RemoveAll()` | — | Empty | Полностью очищает объект. |

## Перебор элементов

Два способа последовательного перебора пар.

### FirstKey / NextKey / KeyFound

Перебор с возвратом ключей:

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `FirstKey()` | — | ключ или Empty | Устанавливает итератор на первую пару, возвращает её ключ. Empty — объект пуст. |
| `NextKey()` | — | ключ или Empty | Перемещает итератор на следующую пару, возвращает её ключ. Empty — достигнут конец. |
| `KeyFound()` | — | Boolean | Результат предыдущей итерации. TRUE — переход выполнен, FALSE — достигнут конец. |

### FirstValue / NextValue

Перебор с возвратом значений:

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `FirstValue()` | — | любой тип или Empty | Устанавливает итератор на первую пару, возвращает её значение. Empty — объект пуст. |
| `NextValue()` | — | любой тип или Empty | Перемещает итератор на следующую пару, возвращает её значение. Empty — достигнут конец. |

### SetFirstLine / SetNextLine / IsValidLine

Перебор через механизм текущей «строки» — совместим с конструкцией `Loop`:

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetFirstLine()` | — | Empty | Устанавливает итератор на первую пару. |
| `SetNextLine()` | — | Empty | Перемещает итератор на следующую пару. |
| `IsValidLine()` | — | Boolean | TRUE — итератор указывает на существующую пару, FALSE — достигнут конец. |
| `GetKey()` | — | ключ | Ключ текущей пары. Выбрасывает исключение, если объект пуст или текущая строка недопустима. |
| `GetValue()` | — | любой тип | Значение текущей пары. Выбрасывает исключение, если объект пуст или текущая строка недопустима. |

## Метаданные и тип ключа

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetCount()` | — | Integer | Количество пар «ключ-значение». |
| `IsEmpty()` | — | Boolean | TRUE — объект пуст, FALSE — содержит хотя бы одну пару. |
| `GetHashTableSize()` | — | Integer | Текущий размер хэш-таблицы. |
| `InitHashTable(hashSize)` | hashSize: Integer | Empty | Задаёт размер хэш-таблицы. **Очищает содержимое**, поэтому вызывается сразу после конструктора. Должен быть больше 0. |
| `SetKeyType(keyType)` | keyType: Integer / Real / String / Long Integer | Boolean | Изменяет тип ключа. **Очищает содержимое**. TRUE — тип изменён, FALSE — переданный тип совпадает с текущим. |
| `GetKeyType()` | — | ключ | Пустое значение, тип которого соответствует типу ключа объекта. |
| `GetContent()` | — | String | Строковое представление содержимого для отладки. |

## Копирование и сериализация

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Copy(sourceMap)` | sourceMap: Map (по ссылке) | String | Копирует все пары из другого объекта Map. Текущий объект полностью перезаписывается, включая тип ключа и размер хэш-таблицы. При пустом источнике размер хэш-таблицы устанавливается в 19. Выбрасывает исключение, если аргумент не является объектом Map. |
| `ToBase64()` | — | String | Сериализует объект с типом ключа String в строку Base64. Выбрасывает исключение, если тип ключа отличен от String. |
| `FromBase64(base64String)` | base64String: String | Empty | Загружает содержимое из строки Base64 в объект с типом ключа String. Текущий объект полностью перезаписывается. Выбрасывает исключение, если тип ключа отличен от String. |

## Примеры

Построение словаря «код товара → количество» с целочисленным ключом:

```EME-L
mapQty = Object("Map", 100, 1);
mapQty.SetAt(1001, 5);
mapQty.SetAt(1002, 12);
nQty = mapQty.Lookup(1001, 0);
```

Перебор элементов через `Loop`:

```EME-L
mapNames = Object("Map", 17);
mapNames.SetAt("Иванов", "Склад 1");
mapNames.SetAt("Петров", "Склад 2");
Loop (mapNames)
    csKey = mapNames.GetKey();
    csVal = mapNames.GetValue();
End Loop
```
