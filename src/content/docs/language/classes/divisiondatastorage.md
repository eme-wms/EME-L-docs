# Класс DivisionDataStorage

Класс `DivisionDataStorage` в языке EME-L предназначен для переноса данных раздела из одного раздела базы данных в другой. Используется в межразделных процедурах: один раздел (например, сервер терминалов) наполняет объект экспортируемыми строками, а другой (основной раздел) импортирует их в свою базу данных.

Объект создаётся через `Object()` без аргументов — раздел, выполняющий импорт, создаёт пустой объект и передаёт его в процедуру раздела-экспортёра.

> **Примечание.** Номер целевого раздела (`DIVISION_TO`) фиксируется при создании объекта и равен текущему разделу. Номер исходного раздела (`DIVISION`) обновляется при **каждом** вызове `ExportLine` и соответствует разделу, из которого выполняется экспорт. Все вызовы `ExportLine` в один объект должны идти из одного раздела — иначе номер раздела-экспортёра будет переписан последним вызовом.

## Создание объекта

```EME-L
'Создать пустое хранилище для приёма данных из другого раздела'
objStorage = Object("DivisionDataStorage");
```

Конструктор параметров не имеет. Объект должен быть создан разделом, который будет выполнять `Import` в свою базу.

## Экспорт данных

Методы наполнения объекта данными на стороне раздела-экспортёра.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `ExportLine(arg0, arg1)` | arg0: Integer (номер записи), arg1: Integer (номер строки) | Empty | Экспортирует строку записи из текущего раздела в объект. При **каждом** вызове обновляет номер текущего раздела как раздел-экспортёр (`DIVISION`). |
| `AllowNullRef(arg0, arg1)` | arg0: Integer/String (запись), arg1: Integer/String (поле) | Empty | Разрешает для указанного ссылочного поля неразименованные ссылки при импорте: вместо исключения записывается `NULL_REF` (-1). Принимает как номер, так и имя записи/поля (поиск через `smart_find_record` / `smart_find_field`). |

При экспорте данных, содержащих ссылки, они должны быть логически замкнуты: ссылки указывают либо на мастер-данные, либо на строки, также добавленные в объект. Например, при экспорте строки документа необходимо добавить и заголовок документа.

## Импорт и проверка

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Import()` | — | Empty | Выполняет импорт данных из объекта в базу текущего раздела. Для каждой экспортированной строки разименовывает ссылочные поля; неразименованные ссылки генерируют исключение, кроме полей из списка `AllowNullRef` — туда записывается `NULL_REF` (-1). |

## Инспекция объекта

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetCount()` | — | Integer | Количество экспортированных строк. |
| `GetDivisionNo()` | — | Integer | Номер раздела-экспортёра. Обновляется при каждом вызове `ExportLine`. |
| `GetDivisionNoTo()` | — | Integer | Номер целевого раздела. Устанавливается при создании объекта и равен текущему разделу. |
| `GetContent()` | — | String | Текстовое представление содержимого для отладки. Формат: `DIVISION=<n>; DIVISION_TO=<n>; <запись>:<строка>; ...`. Пустая строка при отсутствии данных. |

## Примеры

> Примеры синтезированы на основе сигнатур и описаний методов — реальных использований в выгрузке проекта не найдено. Класс узкоспециализированный и применяется в межразделных процедурах.

Межразделный перенос данных. Раздел 0 (основной) создаёт объект и передаёт его в процедуру раздела 2 (сервер терминалов), который наполняет его строками подтверждённых приказов:

```EME-L
'Сторона раздела 0: создать пустой объект и вызвать процедуру раздела 2'
objStorage = Object("DivisionDataStorage");
is_run_procedure_in_division(2, "ExportOrdersToStorage", objStorage);

'Сторона раздела 0: импорт данных в базу раздела 0'
is_transaction(1, "Импорт данных из раздела 2");
objStorage.Import();
is_transaction(-1);
```

Процедура `ExportOrdersToStorage` на стороне раздела 2 наполняет объект:

```EME-L
'Сторона раздела 2: наполнить объект строками подтверждённых приказов'
Loop (objQuery)
    nRec = objQuery.Get_r();
    nLine = objQuery.Get_l();
    objStorage.ExportLine(nRec, nLine);
End Loop

'Разрешить неразименованные ссылки в поле «Документ-основание» записи заказа'
objStorage.AllowNullRef("Order", "SourceDoc");
```

Проверка содержимого объекта перед импортом:

```EME-L
If (objStorage.GetCount() > 0)
    'Логирование: номер раздела-экспортёра и количество строк'
    sLog = objStorage.GetContent();
    is_message("Импорт", sLog);
End If
```
