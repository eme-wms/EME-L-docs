# Класс MultiArray

Класс `MultiArray` в языке EME-L — двумерный динамический массив для хранения табличных данных. Массив имеет фиксированное число столбцов (вторая размерность N, по умолчанию 2) и переменное число строк. Элементы могут содержать значения любого типа. Столбцам можно назначать строковые имена и обращаться к элементам как по числовому индексу, так и по имени. Нумерация строк и столбцов начинается с 0.

Используется в прикладных скриптах EME-L для хранения и обработки табличных наборов данных, промежуточных результатов вычислений, параметров диалогов и других структурированных коллекций значений. Объект класса создаётся через `Object("MultiArray", ...)`. Внутри класса данные хранятся в линейном буфере: на каждый основной (первый) индекс приходится N элементов, доступ к которым — по второму индексу.

## Создание объекта

Класс имеет четыре перегрузки конструктора — по числу и типу переданных аргументов.

```EME-L
'Без аргументов — 2 столбца, 0 строк (значение N по умолчанию)'
arr = Object("MultiArray");
```

```EME-L
'Одна строковая последовательность — столбцы получают имена'
arr = Object("MultiArray", "code", "name", "qty");
```

```EME-L
'Один числовой аргумент — число столбцов'
arr = Object("MultiArray", 3);
```

```EME-L
'Два числовых аргумента — число столбцов и число строк'
arr = Object("MultiArray", 3, 5);
```

| Конструктор | Аргументы | Описание |
|-------------|-----------|----------|
| `MultiArray()` | — | Пустой массив 2×0 (2 столбца по умолчанию, 0 строк). Все элементы — Empty. |
| `MultiArray(имяСтолбца1[, ...[, имяСтолбцаN]])` | имена столбцов: String/Integer/Real | Массив с N столбцами и 0 строк. Integer и Real преобразуются в строку. Выбрасывает исключение при дублировании имён или пустой строке. |
| `MultiArray(числоСтолбцов)` | числоСтолбцов: Integer | Пустой массив с заданным числом столбцов и 0 строк. Если аргумент ≤ 0, используется значение по умолчанию 2. |
| `MultiArray(числоСтолбцов, числоСтрок)` | числоСтолбцов: Integer, числоСтрок: Integer | Массив заданных размеров. Если числоСтолбцов ≤ 0 — используется 2. При числоСтрок ≤ 0 строк нет. |

Конструктор с именами столбцов срабатывает, когда первый аргумент имеет тип String; конструктор с числовыми аргументами — когда первый аргумент Integer.

Во всех перегрузках внутренний курсор «текущей строки» инициализируется значением -1 — до вызова `SetFirstLine` / `SetLine` методы `GetLine()` и `IsValidLine()` возвращают -1 / FALSE соответственно. Метод `Add` после добавления строки делает её текущей.

## Имена столбцов

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetColumnNames(имя1[, ...[, имяN]])` | имена: String/Integer/Real | Empty | Задаёт имена столбцов. Количество аргументов должно точно совпадать с числом столбцов массива. После этого к элементам можно обращаться по имени столбца. Выбрасывает исключение при несовпадении количества, дублировании имён, пустой строке или недопустимом типе аргумента. |

## Доступ к элементам по индексам

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetAt(индексСтроки, индексСтолбца)` | строка: Integer, столбец: Integer или String (имя) | Любой тип | Значение элемента. Выбрасывает исключение при выходе индексов за пределы, пустом массиве или несуществующем имени столбца. |
| `SetAt(индексСтроки, индексСтолбца, значение)` | строка: Integer, столбец: Integer/String, значение: Любой тип | Empty | Присваивает значение элементу. Выбрасывает исключение при выходе индексов за пределы, пустом массиве или несуществующем имени столбца. |
| `SetAtGrow(индексСтроки, индексСтолбца, значение)` | строка: Integer, столбец: Integer/String, значение: Любой тип | Empty | Присваивает значение элементу; при выходе индекса строки за пределы — автоматически расширяет массив, заполняя новые элементы Empty. Выбрасывает исключение при отрицательном индексе строки, выходе индекса столбца за размерность или несуществующем имени столбца. |
| `Lookup(индексСтроки, индексСтолбца)` | строка: Integer, столбец: Integer/String | Любой тип или Empty | Безопасное чтение: при выходе индексов за пределы возвращает Empty (без исключения). Выбрасывает исключение только при несуществующем имени столбца. |
| `Lookup(индексСтроки, индексСтолбца, значениеПоУмолчанию)` | + значениеПоУмолчанию: Любой тип | Любой тип | То же, но при выходе за границы возвращает `значениеПоУмолчанию`. |

## Доступ через текущую строку

Методы работы с текущей строкой удобны при переборе массива или в контексте, где строка уже установлена.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Get(индексСтолбца)` | столбец: Integer/String | Любой тип | Значение элемента в текущей строке. Выбрасывает исключение при выходе индекса столбца, пустом массиве, недопустимой текущей строке или несуществующем имени столбца. |
| `Put(индексСтолбца, значение)` | столбец: Integer/String, значение: Любой тип | Empty | Присваивает значение элементу текущей строки. Исключения те же, что у `Get`. |

## Навигация по строкам

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetLine()` | — | Integer | Номер текущей строки. Если текущая строка не установлена — возвращает -1. |
| `SetLine(номерСтроки)` | номерСтроки: Integer | Empty | Устанавливает текущую строку. |
| `SetFirstLine()` | — | Empty | Устанавливает текущей первую строку. |
| `SetNextLine()` | — | Empty | Переход к следующей строке. Обычно используется совместно с `SetFirstLine` и `IsValidLine` для перебора. |
| `IsValidLine()` | — | Boolean | TRUE — текущая строка установлена и в пределах массива; FALSE — не установлена или вышла за пределы. |
| `IsValidLine(номерСтроки)` | номерСтроки: Integer | Boolean | TRUE — строка с указанным номером существует. |
| `DeleteLine()` | — | Empty | Удаляет текущую строку. Текущая строка должна быть установлена. Выбрасывает исключение при недопустимой текущей строке или пустом массиве. |

Для перебора строк предпочтительно использовать `Loop (arr)` — он автоматически вызывает `SetFirstLine()`, `IsValidLine()` и `SetNextLine()`.

## Размер и размерность

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetSize()` | — | Integer | Текущее количество строк. |
| `GetDimension()` | — | Integer | Количество столбцов (размерность по второму измерению). |
| `IsEmpty()` | — | Boolean | TRUE — массив пуст (0 строк); FALSE — содержит хотя бы одну строку. |
| `SetSize(числоСтрок)` | числоСтрок: Integer | Empty | Задаёт количество строк. При увеличении новые элементы — Empty; при уменьшении лишние строки удаляются с конца. Число столбцов не меняется. |
| `SetSize(текущееЧислоСтрок, расширяемоДо)` | текущееЧислоСтрок: Integer, расширяемоДо: Integer | Empty | То же, но заранее резервирует память под `расширяемоДо` строк — ускоряет последующее расширение. |

## Добавление, вставка и удаление строк

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Add([значение1[, ...[, значениеN]]])` | значения: Любой тип | Integer | Добавляет строку в конец массива. Недостающие элементы заполняются Empty. Количество значений не может превышать число столбцов. Возвращает индекс добавленной строки и делает её текущей. Выбрасывает исключение при превышении числа столбцов. |
| `InsertAt(индексСтроки[, значение1[, ...[, значениеN]]])` | индексСтроки: Integer, значения: Любой тип | Empty | Вставляет строку по индексу; существующие строки сдвигаются вниз. Выбрасывает исключение при выходе индекса за пределы, пустом массиве или превышении числа столбцов. |
| `AddArray(массив)` | массив: MultiArray (по ссылке) | Empty | Добавляет все строки из другого MultiArray в конец текущего. Размерности должны совпадать. Выбрасывает исключение при несовпадении размерностей или если аргумент — не MultiArray. |
| `Copy(массив)` | массив: MultiArray (по ссылке) | Empty | Полностью перезаписывает текущий массив содержимым источника. Размерности должны совпадать. Исключения те же, что у `AddArray`. |
| `Remove()` | — | Empty | Удаляет последнюю строку. Если массив пуст — вызов игнорируется. |
| `RemoveAt(индексСтроки)` | индексСтроки: Integer | Empty | Удаляет строку по индексу. Выбрасывает исключение при пустом массиве или выходе индекса за пределы. |
| `RemoveAll()` | — | Empty | Очищает массив, удаляя все строки. Размерность (число столбцов) сохраняется. |

## Поиск и отладка

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Find(искомоеЗначение)` | искомоеЗначение: Любой тип | Integer | Индекс первого вхождения значения в первом столбце. Если не найдено — -1. |
| `Find(искомоеЗначение, индексСтолбца)` | + индексСтолбца: Integer/String | Integer | То же в указанном столбце. Выбрасывает исключение при выходе индекса столбца или несуществующем имени. |
| `GetContent()` | — | String | Строковое представление содержимого массива для отладки. Элементы разделяются `; `. |

## Примеры

Создание массива с именованными столбцами и заполнение:

```EME-L
'Создать массив товаров: код, наименование, количество'
arr = Object("MultiArray", "code", "name", "qty");
arr.Add("001", "Винт М6", 100);
arr.Add("002", "Гайка М6", 200);
arr.Add("003", "Шайба М6", 150);
'arr содержит 3 строки по 3 столбца'
```

Перебор строк и безопасное чтение:

```EME-L
arr.SetFirstLine();
While (arr.IsValidLine())
    csName = arr.Get("name");
    nQty = arr.Get("qty");
    'обработать csName и nQty'
    arr.SetNextLine();
End While;
```
