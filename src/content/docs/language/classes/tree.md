# Класс Tree

Класс `Tree` в языке EME-L — класс абстрактного дерева для организации иерархических структур данных. Представляет собой контейнер, состоящий из узлов, организованных в древовидную структуру. Каждый узел дерева может хранить произвольное значение, набор именованных свойств и ссылки на дочерние узлы, образующие иерархию отношений родитель-потомок.

Основные возможности:

- Создание пустого дерева с единственным корневым узлом.
- Навигация по дереву: установка текущего узла, переход к корню, получение текущего узла.
- Поиск значений в дереве с рекурсивным обходом всех узлов с опциональным изменением текущего узла при успешном поиске.
- Удаление текущего узла со всеми подузлами или полная очистка дерева.
- Проверку дерева на наличие узлов.

Узлы дерева представлены объектами вспомогательного класса `Node` (C++ `CINode`) и поддерживают добавление потомков в начало или конец списка, вставку перед или после указанного узла, доступ к родителю, навигацию по дочерним узлам, хранение основных данных и именованных значений. Объекты `Node` не создаются напрямую через `Object("Node")` — они получаются из методов `Tree` и других методов `Node`.

Используется в прикладных скриптах EME-L для организации иерархических коллекций данных, таких как деревья отделов, классификаторы, конфигурационные структуры.

## Создание объекта

Класс `Tree` имеет единственный конструктор без аргументов — объект создаётся с пустым деревом, состоящим из одного корневого узла без данных.

```EME-L
'Создать пустое дерево с корневым узлом'
objTree = Object("Tree");
```

При создании инициализируется корневой узел без данных, который автоматически становится текущим узлом дерева.

## Навигация по дереву

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetRoot()` | — | Node | Устанавливает текущий узел дерева в корневой узел и возвращает его. |
| `GetRoot()` | — | Node | Возвращает объект корневого узла дерева. |
| `Get()` | — | Node | Возвращает объект текущего узла дерева. |
| `Set(arg0)` | arg0: Node | Node | Устанавливает указанный узел в качестве текущего. Должен быть валидным узлом, полученным из этого дерева. Возвращает установленный узел. |

> **Внимание:** метод `Set` не проверяет внутренними средствами, что переданный узел действительно принадлежит данному дереву. Передача узла из другого дерева может привести к неопределённому поведению. Всегда используйте узлы, полученные из методов того же объекта `Tree`.

## Поиск в дереве

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Find(arg0)` | arg0: любой тип | Boolean | Рекурсивный поиск значения, начиная с корневого узла. При успешном поиске найденный узел становится текущим. Возвращает `TRUE`, если значение найдено, и `FALSE` в противном случае. |
| `IsExist(arg0)` | arg0: любой тип | Boolean | Рекурсивный поиск значения, начиная с корневого узла. Текущий узел не изменяется. Возвращает `TRUE`, если значение присутствует в дереве, и `FALSE` в противном случае. |

## Удаление и очистка

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Remove()` | — | Node | Удаляет текущий узел со всеми его дочерними узлами (поддеревом). После удаления текущим узлом становится родительский узел удаленного. Если удаляется корневой узел (родитель отсутствует), дерево переинициализируется с созданием нового пустого корневого узла. Возвращает объект нового текущего узла. |
| `RemoveAll()` | — | Node | Полностью очищает дерево, удаляя все узлы включая корневой, и создает новое пустое дерево с единственным корневым узлом. Возвращает объект нового корневого узла. |
| `IsEmpty()` | — | Boolean | Проверяет наличие дочерних узлов у корневого узла. Возвращает `TRUE`, если корневой узел имеет дочерние узлы, и `FALSE`, если дерево содержит только корневой узел без потомков. |

> **Примечание:** семантика `IsEmpty` обратная интуитивной — `TRUE` означает «в дереве есть узлы», а не «дерево пустое». Это соответствует контракту реестра и реализации C++.

## Класс Node

Объекты `Node` возвращаются методами `Tree` (`GetRoot`, `Get`, `Set`, `SetRoot`, `Remove`, `RemoveAll`) и другими методами `Node` (`AddTail`, `AddHead`, `InsertBefore`, `InsertAfter`, `GetParent`, `GetFirstChild`, `GetLastChild`, `GetPrevChild`, `GetNextChild`). Напрямую создать объект `Node` через `Object("Node")` нельзя — это вспомогательный класс, регистрированный через `REGISTRY_EMEL_CLASS_FOR_HELP`.

### Добавление дочерних узлов

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddTail()` | — | Node | Создаёт новый узел без данных и добавляет его в конец списка дочерних узлов текущего узла. Возвращает созданный дочерний узел. |
| `AddTail(arg0)` | arg0: любой тип | Node | Создаёт новый узел с указанными данными и добавляет его в конец списка дочерних узлов. Возвращает созданный дочерний узел. |
| `AddHead()` | — | Node | Создаёт новый узел без данных и добавляет его в начало списка дочерних узлов. Возвращает созданный дочерний узел. |
| `AddHead(arg0)` | arg0: любой тип | Node | Создаёт новый узел с указанными данными и добавляет его в начало списка дочерних узлов. Возвращает созданный дочерний узел. |
| `InsertBefore(arg0)` | arg0: Node | Node | Создаёт новый узел без данных и вставляет его перед указанным дочерним узлом текущего узла. Указанный узел должен присутствовать в списке дочерних узлов. Если узел не найден, генерируется ошибка выполнения. Возвращает созданный узел. |
| `InsertBefore(arg0, arg1)` | arg0: Node, arg1: любой тип | Node | Создаёт новый узел с данными и вставляет его перед указанным дочерним узлом. |
| `InsertAfter(arg0)` | arg0: Node | Node | Создаёт новый узел без данных и вставляет его после указанного дочернего узла текущего узла. Указанный узел должен присутствовать в списке дочерних узлов. Если узел не найден, генерируется ошибка выполнения. Возвращает созданный узел. |
| `InsertAfter(arg0, arg1)` | arg0: Node, arg1: любой тип | Node | Создаёт новый узел с данными и вставляет его после указанного дочернего узла. |

> **Важно:** в текущей реализации C++ одноаргументные формы `InsertBefore(node)` и `InsertAfter(node)` содержат ошибку: тело метода читает `args[1]`, которое выходит за пределы переданного массива аргументов. Фактически при вызове с одним аргументом вместо пустых данных может быть использовано мусорное значение из стека. В одноаргументных формах рекомендуется использовать `AddTail()` / `AddHead()` или двухаргументную форму `InsertBefore(node, Empty)` / `InsertAfter(node, Empty)`.

### Навигация по родственным узлам

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetParent()` | — | Node | Возвращает объект родительского узла. Для корневого узла дерева возвращает пустую ссылку. |
| `GetFirstChild()` | — | Node | Возвращает первый дочерний узел и устанавливает внутренний итератор на начало списка дочерних узлов. Если дочерние узлы отсутствуют, возвращает пустую ссылку. |
| `GetLastChild()` | — | Node | Возвращает последний дочерний узел и устанавливает внутренний итератор на конец списка. Если дочерние узлы отсутствуют, возвращает пустую ссылку. |
| `GetPrevChild()` | — | Node | Возвращает предыдущий дочерний узел относительно текущей позиции внутреннего итератора. Если достигнуто начало списка или итератор не установлен, возвращает пустую ссылку. |
| `GetNextChild()` | — | Node | Возвращает следующий дочерний узел относительно текущей позиции внутреннего итератора. Если достигнут конец списка или итератор не установлен, возвращает пустую ссылку. |

### Проверка состояния узла

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `IsEmptyChild()` | — | Boolean | Возвращает `TRUE`, если у текущего узла нет дочерних узлов, и `FALSE`, если есть хотя бы один дочерний узел. |
| `GetCount()` | — | Integer | Возвращает количество дочерних узлов текущего узла. |

### Данные узла и именованные свойства

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `PutData(arg0)` | arg0: любой тип | Empty | Сохраняет указанное значение в текущем узле, заменяя ранее сохраненные данные. |
| `GetData()` | — | любой тип | Возвращает значение, сохраненное в текущем узле. Если данные не были установлены, возвращает пустое значение. |
| `Put(arg0, arg1)` | arg0: String (имя свойства), arg1: любой тип | Empty | Сохраняет именованное значение в текущем узле. Именованные значения хранятся отдельно от основных данных узла и позволяют организовать набор свойств узла, доступных по текстовому имени. |
| `Get(arg0)` | arg0: String (имя свойства) | любой тип | Возвращает именованное значение из текущего узла по указанному имени. Если свойство не найдено, возвращает пустое значение. |

## Константы

| Константа | Значение | Назначение |
|-----------|----------|------------|
| Размер хеш-таблицы именованных свойств | 30 | Внутренний размер хеш-таблицы `CMap`, используемой для хранения именованных значений узла (метод `Put`). |

## Примеры

### Построение дерева и обход в ширину

```EME-L
'Создать дерево отделов'
objTree = Object("Tree");
rootNode = objTree.GetRoot();
rootNode.PutData("Компания");

'Добавить дочерние узлы'
salesNode = rootNode.AddTail("Отдел продаж");
logisticsNode = rootNode.AddTail("Отдел логистики");

'Добавить подчинённые узлы'
salesNode.AddTail("Менеджер 1");
salesNode.AddTail("Менеджер 2");
logisticsNode.AddTail("Курьер");

'Сохранить коды отделов как именованные свойства'
salesNode.Put("code", "SALES");
logisticsNode.Put("code", "LOG");
```

### Поиск значения и обход дочерних узлов

```EME-L
'Найти узел с данными "Отдел продаж"'
found = objTree.Find("Отдел продаж");
If (found)
    foundNode = objTree.Get();
    'Перебрать всех дочерних узлов найденного отдела'
    child = foundNode.GetFirstChild();
    While (child)
        employeeName = child.GetData();
        'employeeName = имя сотрудника'
        child = foundNode.GetNextChild();
    End While
End If
```

### Проверка существования и удаление поддерева

```EME-L
'Проверить, есть ли в дереве узел с данными "Курьер"'
exists = objTree.IsExist("Курьер");

'Установить текущий узел на логистику и удалить его поддерево'
objTree.SetRoot();
found = objTree.Find("Отдел логистики");
If (found)
    objTree.Remove();
End If
```

### Работа с именованными свойствами

```EME-L
'Прочитать сохранённый код отдела'
code = salesNode.Get("code");
'code = "SALES"'

'Прочитать несуществующее свойство — вернёт пустое значение'
missing = salesNode.Get("manager_count");
```
