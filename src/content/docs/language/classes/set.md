# Класс Set

Класс `Set` в языке EME-L — класс для работы с набором строк записи базы данных. Предоставляет механизм формирования, фильтрации и выполнения теоретико-множественных операций над подмножествами строк записи. Объект создаётся для конкретной записи базы данных и позволяет накладывать условия отбора строк, перебирать отобранные строки, получать ссылки из ссылочных полей, а также выполнять объединение, пересечение, симметрическую разность и дополнение наборов строк.

Поддерживает динамическую генерацию методов сравнения для полей и ссылочных полей записи (вида `GetИмяПоляEQ`, `GetИмяПоляNE`, `GetИмяПоляGT`, `GetИмяПоляLT`, `GetИмяПоляGE`, `GetИмяПоляLE`, `GetИмяRefNE`, `GetИмяRefEQ`, `GetИмяRefSet`, `IsИмяEQ`, `IsИмяNE`), что позволяет накладывать ограничения в краткой форме без явного вызова `Constrain`.

Используется в прикладных скриптах EME-L для организации выборок строк записей, множественной фильтрации и обхода отобранных строк в циклах.

Объект класса `Set` создаётся через `Object()` с обязательным указанием имени или номера записи базы данных. Внутренний итератор набора строк инициализируется в неизвестное состояние — до вызова `SetFirstLine` методы `GetLine()` и `IsValidLine()` возвращают специальное значение отсутствия строки и `FALSE` соответственно.

## Создание объекта

Класс `Set` имеет один конструктор с переменным числом аргументов. Допустимы только формы с 1 или 3 аргументами; вызов без аргументов или с 2 аргументами вызывает ошибку `too_rare`.

```EME-L
'Конструктор с указанием имени записи — без условия отбора'
setRows = Object("Set", "Goods");
```

```EME-L
'Конструктор с указанием условия отбора и параметра'
setRows = Object("Set", "Goods", "GetGroup() ==", 15);
```

```EME-L
'Пустая строка в качестве имени записи — набор без привязки к конкретной записи'
setEmpty = Object("Set", "");
```

Конструктор с одним аргументом создаёт набор строк для указанной записи без наложения условий отбора — в набор входят все строки записи. Конструктор с тремя аргументами дополнительно накладывает условие на строки через вызов `Constrain`. Пустая строка в качестве имени записи создаёт набор без привязки к конкретной записи; при этом внутренний объект записи создаётся пустым, а `GetRecord()` возвращает `NULL_RECORD`.

Передача двух аргументов вызывает ошибку — при числе аргументов больше одного требуется полный набор из трёх (запись, условие, параметр).

## Ограничение и фильтрация

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Constrain(condition, param)` | condition: String, param: Variant | Set | Накладывает ограничение на текущий набор строк, оставляя только строки, удовлетворяющие условию. Модифицирует текущий объект и возвращает его. Формат условия: `"ИмяМетодаПоля() <оператор> "`, где оператор — `<`, `>`, `<=`, `>=`, `==`, `!=`. Поддерживаются поля (FLD), битовые поля (BIT) и ссылочные поля (REF). Для ссылочного поля при операторе `==` параметр может быть целым числом (ссылка) или другим набором `Set`, строки которого должны входить в ссылочное поле. |
| `Pick(condition, param)` | condition: String, param: Variant | Set | Возвращает **новый** набор строк, отобранных из текущего по заданному условию. Исходный набор не изменяется. Формат условия и поддерживаемые операторы аналогичны `Constrain`. |

Метод `Constrain` работает через систему фильтров записи (`SetSkipMode`), поэтому последовательные вызовы суммируют ограничения. Метод `Pick` выполняет независимую выборку итеративным обходом, не затрагивая исходный набор.

## Навигация по строкам

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetFirstLine()` | — | Empty | Устанавливает итератор набора строк на первую строку в соответствии с текущим состоянием отбора. |
| `IsValidLine()` | — | Boolean | `TRUE` — итератор указывает на валидную строку. `FALSE` — строка отсутствует или итератор не инициализирован. |
| `SetNextLine()` | — | Empty | Перемещает итератор набора строк на следующую строку в соответствии с текущим состоянием отбора. |
| `GetLine()` | — | Integer | Номер текущей строки объекта записи, на которую установлен итератор. Возвращает `NULL_REF` (специальное значение отсутствия), если текущая строка не валидна. |

Для обхода строк набора используйте `Loop`:

```EME-L
'Обход отобранных строк набора'
setRows.SetFirstLine();
Loop (setRows)
    nLine = setRows.GetLine();
    'Обработка строки nLine'
End Loop
```

## Информация о записи

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetRecord()` | — | Integer | Номер записи базы данных, строки которой входят в набор. Возвращает `NULL_RECORD` (специальное значение), если запись не задана. |
| `GetRecordObject()` | — | CEMERec | Объект записи базы данных, для которой сформирован набор строк. Пустое значение, если запись не задана. |
| `GetRefSet(fieldName)` | fieldName: String | Set | Возвращает **новый** набор строк, содержащий ссылки из ссылочного поля текущей записи. `fieldName` — имя метода-получателя ссылочного поля в форме `GetИмяRefFld()`. |

> **Внимание:** параметр `GetRefSet` — это не произвольное «емельное выражение», а именно имя метода-получателя ссылочного поля, например `"GetGoodsRefFld()"`. Внутри метода по этому имени находится ссылочное поле, и для каждой строки текущего набора из него извлекается ссылка.

## Теоретико-множественные операции

Все операции возвращают **новый** объект набора строк. Оба набора-операнда должны относиться к одной и той же записи базы данных.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Or(otherSet)` | otherSet: Set | Set | Объединение: строки, присутствующие хотя бы в одном из наборов. |
| `And(otherSet)` | otherSet: Set | Set | Пересечение: строки, присутствующие в обоих наборах. |
| `Xor(otherSet)` | otherSet: Set | Set | Симметрическая разность: строки, присутствующие только в одном из наборов. |
| `Not()` | — | Set | Дополнение: все строки записи, отсутствующие в текущем наборе. |

> **Примечание о реализации `Not()`:** в C++-теле метода используется выражение `~pNotSet->m_bb_Lines;` — унарное побитовое отрицание без присваивания результата. По контракту реестра метод должен возвращать дополнение набора строк, однако фактическое поведение зависит от того, как компилятор обрабатывает это выражение. Используйте `Not()` с осторожностью и проверяйте результат на целевой версии ядра.

## Динамические методы сравнения

Класс `Set` генерирует методы сравнения для каждого поля записи на лету через механизм `FindMethod` / `CallMethod`. Суффикс метода определяет оператор сравнения. Это позволяет накладывать ограничения в краткой форме без явного вызова `Constrain`.

### Поля данных (FLD)

Для каждого поля данных записи генерируются методы:

| Метод | Оператор | Эквивалент через Constrain |
|-------|----------|----------------------------|
| `GetИмяПоляEQ(param)` | `==` | `Constrain("GetИмяПоля() ==", param)` |
| `GetИмяПоляNE(param)` | `!=` | `Constrain("GetИмяПоля() !=", param)` |
| `GetИмяПоляGT(param)` | `>` | `Constrain("GetИмяПоля() >", param)` |
| `GetИмяПоляLT(param)` | `<` | `Constrain("GetИмяПоля() <", param)` |
| `GetИмяПоляGE(param)` | `>=` | `Constrain("GetИмяПоля() >=", param)` |
| `GetИмяПоляLE(param)` | `<=` | `Constrain("GetИмяПоля() <=", param)` |

Все методы принимают один параметр типа Variant и возвращают текущий объект `Set` (с наложенным ограничением).

### Ссылочные поля (REF)

Для каждого ссылочного поля генерируются методы:

| Метод | Описание |
|-------|----------|
| `GetИмяRefNE(param)` | Оставляет строки, у которых ссылка не равна `param` (целое число). |
| `GetИмяRefEQ(param)` | Оставляет строки, у которых ссылка равна `param` (целое число). |
| `GetИмяRefSet()` | Возвращает новый `Set` со ссылками из этого поля (эквивалент `GetRefSet("GetИмяRefFld()")`). |

Для ссылочных полей поддерживаются только операторы `==` и `!=`, а также метод получения набора ссылок.

### Битовые поля (BIT)

Для каждого битового поля генерируются методы:

| Метод | Описание |
|-------|----------|
| `IsИмяEQ(param)` | Оставляет строки, где бит установлен (`param = TRUE`) или сброшен (`param = FALSE`). |
| `IsИмяNE(param)` | Оставляет строки, где бит сброшен (`param = TRUE`) или установлен (`param = FALSE`). |

## Внутренние константы и детали реализации

Класс `Set` использует следующие специальные значения и детали реализации:

- `NULL_RECORD` — специальное значение, возвращаемое методом `GetRecord()`, если объект записи не задан (набор создан без привязки к записи или с пустой строкой в качестве имени записи).
- `NULL_REF` — специальное значение, возвращаемое методом `GetLine()`, если итератор не установлен на валидную строку.
- Внутренний итератор работает в одном из трёх режимов: `UnknownIterator` (начальное состояние), `RecordIterator` (обход через систему фильтров записи), `BitBufferIterator` (обход через битовый буфер `BitBuffer`). Режим `ArrayIterator` зарезервирован, но не используется.
- Теоретико-множественные операции (`Or`, `And`, `Xor`, `Not`) и метод `Pick` переключают итератор в режим `BitBufferIterator`.
- Методы, возвращающие новый объект `Set` (`Constrain`, `Pick`, `GetRefSet`, `Or`, `And`, `Xor`, `Not`, `GetRecordObject`), реализованы как `IMPLEMENT_MTYPED` и возвращают типизированный объект (`CISet` или `CEMERec`).

## Примеры

Фильтрация строк записи по условию и обход результата:

```EME-L
'Создать набор строк товара с группой 15'
setGoods = Object("Set", "Goods", "GetGroup() ==", 15);
setGoods.SetFirstLine();
Loop (setGoods)
    nLine = setGoods.GetLine();
    'Чтение данных строки nLine'
End Loop
```

Использование динамических методов и теоретико-множественных операций:

```EME-L
'Два набора: активные и отмеченные товары'
setActive = Object("Set", "Goods");
setActive.IsActiveEQ(TRUE);
setMarked = Object("Set", "Goods");
setMarked.IsFlagEQ(TRUE);
'Пересечение: активные и отмеченные'
setBoth = setActive.And(setMarked);
```

> В примере выше предполагается, что в записи `Goods` есть битовые поля `IsActive` и `IsFlag`. Для поля данных `Group` краткая форма выглядела бы как `setGoods.GetGroupEQ(15)`.

Получение набора ссылок из ссылочного поля:

```EME-L
'Все строки заказа'
setOrder = Object("Set", "OrderHeader", "GetDocNo() ==", nDocNo);
setOrder.SetFirstLine();
Loop (setOrder)
    'Получить набор строк товаров из ссылочного поля'
    setGoods = setOrder.GetRefSet("GetGoodsRefFld()");
    setGoods.SetFirstLine();
    Loop (setGoods)
        nGoodsLine = setGoods.GetLine();
    End Loop
End Loop
```
