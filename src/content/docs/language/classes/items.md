# Класс Items

Класс `Items` в языке EME-L — класс-оболочка для формирования и управления набором абстрактных элементов в DBIntegrator. Предназначен для программного создания дерева элементов интегратора, привязки к ним EME-L класса-обработчика, настройки категорий, иконок, цветов и фильтрующих методов, а также для последующей вставки элементов в DBIntegrator в виде корневых узлов или иерархического дерева.

Основные возможности класса:

- Создание набора элементов с указанием EME-L класса-обработчика и необязательного родительского набора.
- Добавление элементов с заданным текстом и именем класса.
- Установка текущей иконки, категории, свойств категории, ссылки REF и фильтрующего метода для элементов.
- Поиск свойств категории по цепочке родительских наборов.
- Получение текста, категории, свойств и REF текущего элемента.
- Установка цвета текста и фона последнего добавленного элемента.
- Вставка всех элементов в DBIntegrator как корневые узлы или с учётом категорий в виде иерархического дерева.

Используется в прикладных скриптах EME-L для динамического построения содержимого интегратора, навигационных панелей и древовидных справочников.

Объект класса `Items` создаётся через `Object()`. Конструктор вызывает метод `OnInit` указанного EME-L класса-обработчика. Если передать пустую строку в качестве имени класса, создаётся набор без EME-L обработчика — элементы добавляются в интегратор напрямую, без вызова `OnInit`.

## Создание объекта

Класс `Items` имеет две перегрузки конструктора, доступные из EME-L.

```EME-L
'Набор без родителя — корневой уровень интегратора'
objItems = Object("Items", "MyHandlerClass");
```

```EME-L
'Набор с родительским объектом Items — дочерний уровень'
objItems = Object("Items", "MyHandlerClass", objParentItems);
```

Конструктор создаёт пустой набор элементов, привязывает его к указанному EME-L классу-обработчику и немедленно вызывает метод `OnInit` этого класса. Если метод `OnInit` не найден — генерируется ошибка. Если имя класса — пустая строка, набор создаётся без обработчика (метод `OnInit` не вызывается), и элементы можно добавлять в интегратор напрямую.

## Управление элементами

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AddItem(text, className)` | text: String, className: String | Empty | Добавляет элемент в набор. Новому элементу присваиваются текущие иконка и категория, если они были заданы через `SetCurrentIcon`/`SetCurrentCategory` до вызова. |
| `SetCurrentIcon(icon)` | icon: String | Empty | Устанавливает иконку для всех последующих элементов. Значение сохраняется до следующего вызова. |
| `SetCurrentCategory(category)` | category: String | Empty | Устанавливает категорию для всех последующих элементов. Категория используется при иерархической вставке через `AttachToIntegratorEx`. |
| `SetTextColor(color)` | color: Integer (RGB) | Empty | Устанавливает цвет текста последнего добавленного элемента. |
| `SetBkColor(color)` | color: Integer (RGB) | Empty | Устанавливает цвет фона последнего добавленного элемента. |

При создании элемента через `AddItem` цвета текста и фона по умолчанию устанавливаются в `MAXDWORD` — значение, означающее «цвет не задан», при котором используется стандартный цвет элемента управления.

## Свойства категории

Методы работы со свойствами категории последнего добавленного элемента. Свойства хранятся в виде строки параметров (формат `CParameters`) и используются при фильтрации и навигации в DBIntegrator.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetCategoryProperties(properties)` | properties: String | Empty | Задаёт строку свойств категории для последнего добавленного элемента. |
| `SetCategoryRef(ref)` | ref: Integer | Empty | Записывает числовую ссылку REF в свойства категории. Сохраняется под именем `__REF__`. |
| `SetCategorySkip(methodName)` | methodName: String | Empty | Задаёт фильтрующий метод для категории. В свойства записываются имя текущего EME-L класса (`__CLASS__`) и имя метода-фильтра (`__SKIP__`). |

## Поиск по цепочке родительских наборов

Методы поиска поднимаются по цепочке родительских наборов `Items`, пока не найдут элемент с совпадающей категорией.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `FindCategoryProperties(category)` | category: String | String или Empty | Строка свойств категории. Пустое значение — категория не найдена. |
| `FindCategoryRef(category)` | category: String | Integer | Значение REF из свойств категории. `NULL_REF` — категория не найдена или свойство `__REF__` отсутствует. |
| `FindCategorySkip(category)` | category: String | CSkip | Объект `CSkip`, настроенный на фильтрующий метод найденной категории. Объект кэшируется внутри набора. |

## Доступ к текущему элементу

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `GetText()` | — | String | Отображаемый текст текущего элемента. |
| `GetCategory()` | — | String | Категория текущего элемента. |
| `GetCategoryProperties()` | — | String или Empty | Строка свойств категории текущего элемента. Пустое значение — элемент отсутствует. |
| `GetCategoryRef()` | — | Integer | Значение REF из свойств категории текущего элемента. `NULL_REF` — свойство `__REF__` отсутствует. |

## Вставка в DBIntegrator

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `AttachToIntegrator(integrator)` | integrator: DBIntegrator (по ссылке) | Empty | Вставляет все элементы набора в интегратор как корневые (верхнеуровневые) объекты. |
| `AttachToIntegratorEx(integrator)` | integrator: DBIntegrator (по ссылке) | Empty | Вставляет элементы в виде иерархического дерева. Сначала добавляются элементы без категории как корневые узлы, затем элементы, чья категория совпадает с текстом уже добавленного элемента, вставляются как его дочерние узлы. Процесс повторяется до построения всех уровней. |

## Вложенный класс CSkip

Объект `CSkip` возвращается методом `FindCategorySkip` и предназначен для динамической фильтрации элементов дерева интегратора через прикладной метод EME-L.

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `Skip(arg0)` | arg0: любой тип | Boolean или произвольный | Вызывает фильтрующий метод EME-L класса, заданного при создании объекта, и передаёт в него аргумент. При отсутствии класса или метода возвращает `FALSE`. Тип и семантика возвращаемого значения определяются реализацией фильтрующего метода в EME-L классе. |

## Константы

| Константа | Значение | Описание |
|-----------|----------|----------|
| `NULL_REF` | — | Значение ссылки по умолчанию: возвращается методами `FindCategoryRef` и `GetCategoryRef`, если категория или свойство `__REF__` не найдены. |
| `MAXDWORD` | — | Цвет текста и фона по умолчанию для новых элементов: означает «цвет не задан». |
| `__REF__` | — | Имя свойства категории, в котором `SetCategoryRef` сохраняет числовую ссылку. |
| `__CLASS__` | — | Имя свойства категории, в котором `SetCategorySkip` сохраняет имя EME-L класса. |
| `__SKIP__` | — | Имя свойства категории, в котором `SetCategorySkip` сохраняет имя метода-фильтра. |

## Примеры

Создание набора элементов с категориями и вставка в интегратор в виде дерева:

```EME-L
'Создать корневой набор с обработчиком'
objItems = Object("Items", "TreeHandler");
objItems.SetCurrentIcon("folder");
objItems.SetCurrentCategory("");
objItems.AddItem("Склад 1", "WarehouseItem");
objItems.SetCurrentCategory("Склад 1");
objItems.AddItem("Зона A", "ZoneItem");
objItems.AddItem("Зона B", "ZoneItem");
'Вставить как иерархическое дерево в DBIntegrator'
objItems.AttachToIntegratorEx(integrator);
```

Поиск REF родительской категории по цепочке наборов:

```EME-L
objItems = Object("Items", "ChildHandler", objParentItems);
'Найти REF категории «Склад» в родительских наборах'
nRef = objItems.FindCategoryRef("Склад");
'Если nRef не NULL_REF — категория найдена'
If (nRef != NULL_REF)
    RefValue = nRef;
End If
```
