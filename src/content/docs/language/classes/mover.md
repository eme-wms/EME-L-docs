# Класс Mover

Класс `Mover` в языке EME-L предназначен для выполнения складских операций перемещения строк документов. Управляет жизненным циклом строк документов при выполнении складских операций: постановка строк в буфер, отгрузка из буфера, возврат строк из буфера и прямая отгрузка без использования буфера.

Класс обеспечивает многоступенчатый контроль целостности данных: предварительные проверки вне транзакции, проверки внутри транзакции и собственно выполнение операции. При обнаружении изменений в строках документов во время операции формируется детальный протокол ошибок.

Поддерживается автоматический контроль доступности ячеек с исключением строк, для которых невозможно выполнить операцию по соображениям доступности. Исключенные строки могут быть собраны в отдельный массив.

Опционально доступен вывод операционной информации в консоль с настройкой параметров окна (размеры, заголовок). Для передачи дополнительных параметров операции (например, настройки поиска ячеек) используется объект `OperationContext`, который задаётся методом `SetContext`.

## Создание объекта

Класс `Mover` имеет два конструктора — один на каждое число аргументов.

```EME-L
'Конструктор без аргументов — объект не привязан к конкретной строке документа'
objMover = Object("Mover");
```

```EME-L
'Конструктор с указанием записи строки документа DocLines'
objMover = Object("Mover", r_DocLines.GetRecord());
```

Конструктор с одним аргументом принимает номер записи строки документа (`DocLines`) и используется для операций над строками этого документа. Конструктор без аргументов создаёт объект без привязки к строке.

## Консоль операций

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetConsole(arg0)` | arg0: Boolean | Empty | Включает или отключает вывод операционной информации в консоль. `TRUE` — вывод включён, `FALSE` — отключён. |
| `SetConsole(arg0, arg1, arg2, arg3)` | arg0: Boolean, arg1: Integer (размер_x), arg2: Integer (размер_y), arg3: String (заголовок) | Empty | Задаёт параметры окна консоли: ширина и высота в пикселях, заголовок окна. |

## Операции с буфером

Методы `SrcToBuf`, `BufToDst`, `BufToSrc` перемещают строки документа через промежуточный буфер. Все методы возвращают строку с протоколом операции: пустую строку при успехе или текст ошибок для строк, которые не удалось обработать.

### SrcToBuf — постановка в буфер

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SrcToBuf(arg0)` | arg0: Array (номера записей строк DocLines, по ссылке) | String | Постанавливает указанные строки документа в буфер. |
| `SrcToBuf(arg0, arg1)` | arg0: Array, arg1: Integer (режим) | String | Постановка в буфер с указанием режима выполнения. |
| `SrcToBuf(arg0, arg1, arg2)` | arg0: Array, arg1: Integer, arg2: Array (исключённые строки, по ссылке) | String | Постановка в буфер с режимом и сбором исключённых строк. |

### BufToDst — отгрузка из буфера

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `BufToDst(arg0)` | arg0: Array (номера записей строк DocLines, по ссылке) | String | Отгружает указанные строки из буфера. |
| `BufToDst(arg0, arg1)` | arg0: Array, arg1: Integer (режим) | String | Отгрузка из буфера с указанием режима выполнения. |
| `BufToDst(arg0, arg1, arg2)` | arg0: Array, arg1: Integer, arg2: Array (исключённые строки, по ссылке) | String | Отгрузка из буфера с режимом и сбором исключённых строк. |

### BufToSrc — возврат из буфера

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `BufToSrc(arg0)` | arg0: Array (номера записей строк DocLines, по ссылке) | String | Возвращает указанные строки из буфера в исходное состояние. |
| `BufToSrc(arg0, arg1)` | arg0: Array, arg1: Integer (режим) | String | Возврат из буфера с указанием режима выполнения. |
| `BufToSrc(arg0, arg1, arg2)` | arg0: Array, arg1: Integer, arg2: Array (исключённые строки, по ссылке) | String | Возврат из буфера с режимом и сбором исключённых строк. |

## Прямая отгрузка

### SrcToDst — отгрузка без буфера

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SrcToDst(arg0)` | arg0: Array (номера записей строк DocLines, по ссылке) | String | Отгружает указанные строки документа без использования буфера. |
| `SrcToDst(arg0, arg1)` | arg0: Array, arg1: Integer (режим) | String | Прямая отгрузка с указанием режима выполнения. |
| `SrcToDst(arg0, arg1, arg2)` | arg0: Array, arg1: Integer, arg2: Array (исключённые строки, по ссылке) | String | Прямая отгрузка с режимом и сбором исключённых строк. |

## Режимы выполнения операций

Параметр `режим` в методах `SrcToBuf`, `BufToDst`, `BufToSrc`, `SrcToDst` принимает одно из следующих значений:

| Значение | Описание |
|----------|----------|
| `0` | Предварительные проверки вне транзакции и выполнение операции с повторными проверками внутри транзакции (по умолчанию). |
| `1` | Отгрузка с проверками внутри транзакции; транзакция открывается вызывающим кодом. |
| `2` | Только предварительные проверки без выполнения операции. |

## Контекст операции

| Метод | Аргументы | Возвращает | Описание |
|-------|-----------|------------|----------|
| `SetContext(arg0)` | arg0: OperationContext (по ссылке) | Empty | Задаёт контекст операции для управления дополнительными параметрами отгрузки (поиск ячеек, трассировка, запреты и др.). |

## Примеры

Постановка строк в буфер с контекстом операции:

```EME-L
objContext = Object("OperationContext", TRUE);
objContext.SetDisableCreateMoveOrder(TRUE);
objMover = Object("Mover", r_DocLines.GetRecord());
objMover.SetContext(objContext);
strResult = objMover.SrcToBuf(arrLoadedLines);
If (strResult != "")
    is_message(tr("Ошибка"), strResult, 1);
End If
```

Постановка в буфер с явным режимом и выводом в консоль:

```EME-L
context = Object("OperationContext", TRUE);
objMover = Object("Mover", r_DocLinesMove.GetRecord());
objMover.SetContext(context);
objMover.SetConsole(TRUE, 500, 500, tr("Постановка в буфер"));
strResult = objMover.SrcToBuf(arrDocLinesMove, 1);
If (strResult != "")
    is_message(tr("Ошибка постановки в буфер"), strResult, 1);
End If
```
