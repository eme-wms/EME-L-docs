## Обзор is-функций в языке EME-L

is-функции в EME-L являются внешними встроенными функциями, которые не могут быть реализованы на EME-L. Вызов is-функции имеет следующий формат:

```EME-L
{is-функция}([{Аргумент1}, [{Аргумент2} ...]])
```

is-функции языка EME-L подразделяются на функциональные группы: Bit, Browser, Context и другие.

---

## is-функции группы Bit — битовые операции

is-функции группы Bit отвечают за работу с битовыми признаками в языке EME-L. в системе EME.WMS битовые операции используются для манипуляции флагами, проверки прав доступа, формирования масок и низкоуровневой обработки данных.

Доступные функции:

| Функция | Описание |
|---------|----------|
| `is_bit(arg0, arg1)` | Проверка установленного бита. Возвращает `TRUE`/`FALSE` |
| `is_clear_bit(arg0, arg1)` | Сброс указанного бита в 0 |
| `is_set_bit(arg0, arg1)` | Установка указанного бита в 1 |
| `is_reverse_bit(arg0, arg1)` | Инверсия бита (0→1, 1→0) |
| `is_and([arg0[, ...]])` | Побитовое И. Произвольное число параметров |
| `is_or([arg0[, ...]])` | Побитовое ИЛИ. Произвольное число параметров |
| `is_xor(arg0, arg1)` | Исключающее ИЛИ |
| `is_not(arg0)` | Побитовое НЕ (инверсия всех битов) |
| `is_mask(arg0[, ...])` | Формирование битовой маски |
| `is_shift_left(arg0, arg1)` | Побитовый сдвиг влево |
| `is_shift_right(arg0, arg1)` | Побитовый сдвиг вправо |

**Подробная документация** с таблицами параметров, типами и примерами кода — в разделе [Системные функции → Битовые операции](../system-functions/bit-operations/).

```EME-L
' Проверка бита 3 '
Result = is_bit(Flags, 3)

' Установить бит 5 '
Flags = is_set_bit(Flags, 5)

' Сбросить бит 5 '
Flags = is_clear_bit(Flags, 5)

' Маска с битами 1, 3 и 5: 0b101010 = 0x2A '
Mask = is_mask(1, 3, 5)
```

## is-функции группы Browser — работа с браузерами

is-функции группы Browser отвечают за работу с браузерами в EME БД. в системе EME.WMS браузеры используются для отображения и выбора данных из записей базы данных.

Доступные функции:

| Функция | Описание |
|---------|----------|
| `is_hewed(mark, line[, level])` | Проверка высечения строки |
| `is_hew_item(mark, line[, level])` | Высечение (выбор) строки |
| `is_empty_hew(mark[, level[, clear]])` | Проверка пустоты переменной высечения |
| `is_browse(name1[, name2[, ...]])` | Запуск браузера в каскадном режиме |
| `is_browse_data(column[, line])` | Содержимое колонки браузера |
| `is_browse_data_se(column)` | Содержимое колонки как вещественное число |
| `is_browser_base_record(line)` | Базовая запись браузера |
| `is_run_browse(record)` | Запуск браузера записи |
| `is_keydown_flag()` | Флаги состояния клавиатуры |

**Подробная документация** с таблицами параметров, типами и примерами кода — в разделе [Системные функции → Работа с браузерами](../system-functions/browser/).

```EME-L
' Запуск браузера '
Line = is_browse("BrowserOrders")

' Чтение данных колонки '
Value = is_browse_data("ClientName", Line)

' Проверка высечения '
Result = is_hewed("MyHew", 5)
```

## is-функции группы Context — работа с контекстом

is-функции группы Context отвечают за работу с глобальным контекстом в EME БД. в системе EME.WMS контекст используется для передачи данных между различными частями приложения, хранения состояния и проверки текущего контекста выполнения.

Доступные функции:

| Функция | Описание |
|---------|----------|
| `is_put_context(name, value)` | Сохранение значения в контекст |
| `is_get_context_as_string(name)` | Получение контекста как строки |
| `is_get_context_as_ref(name)` | Получение контекста как числа |
| `is_del_context(name)` | Удаление ячейки контекста |
| `is_office_doc_save(rec, field, line[, del])` | Проверка сохранения документа офиса |
| `is_office_doc_already_open(rec, field, line)` | Проверка открытия документа офиса |
| `is_check_context(type[, name])` | Проверка текущего контекста |
| `is_get_context(type)` | Получение имени текущего контекста |

**Подробная документация** с таблицами параметров, типами и примерами кода — в разделе [Системные функции → Работа с контекстом](../system-functions/context/).

```EME-L
' Сохранить и прочитать значение из контекста '
is_put_context("MyContext", "Hello")
Value = is_get_context_as_string("MyContext")

' Проверить текущий контекст '
Result = is_check_context("Dialog")

' Получить имя текущего диалога '
DialogName = is_get_context("Dialog")
```
