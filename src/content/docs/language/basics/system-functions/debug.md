## Профилирование и отладка

### is_prf — профилирование

функция для профилирования кода. Аналог ядерных функций профилирования.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| args[0] | Integer | Да | Тип: 0 — reset_prf, 1 — start_prf, 2 — stop_prf, 3 — get_prf |
| args[1] | Integer | Нет | Номер таймера (0-31). Для args[0]=0 не нужен |

**Возвращает**: при args[0]=3 — время в мс. В остальных случаях — ничего.

```EME-L
' Запуск таймера 0 '
is_prf(1, 0)

' Остановка '
is_prf(2, 0)

' Получить время '
time = is_prf(3, 0)
```



### is_mem_dump — дамп памяти

записывает в катастроф-лог информацию об использовании памяти.

**Параметры**: нет.

**Возвращает**: ничего.

```EME-L
is_mem_dump()
```



### is_SYS_mem_dump — дамп пула SYS

выполняет дамп пула SYS.

**Параметры**: нет.

**Возвращает**: пустое значение.

```EME-L
is_SYS_mem_dump()
```



### is_ui_test_mode — режим тестирования UI

возвращает TRUE, если программа в режиме тестирования интерфейса. В этом режиме база последовательно запускает все пункты меню. Прикладной код может использовать для отключения браузеров и MessageBox.

**Параметры**: нет.

**Возвращает**: `Boolean` — TRUE если включён режим тестирования.

```EME-L
' В режиме тестирования UI не показывать MessageBox '
If (is_ui_test_mode())
    showMsg = FALSE
End If
```



## Планировщик и события

### is_eventer_tick — запуск планировщика

запускает процедуры планировщика.

**Параметры**: нет.

**Возвращает**: `Integer` — результат отправки WM_TIMER, 0 при ошибке.

```EME-L
is_eventer_tick()
```



### is_force_standard_export — стандартный экспорт

Инициирует принудительный стандартный экспорт данных. Вызов QueryExport.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| args[0] | Boolean | Нет | TRUE — выдавать предупреждение перед экспортом (по умолчанию TRUE) |

**Возвращает**: `Integer` — результат запроса на экспорт. При отсутствии поддержки семафоров возвращает 0.

```EME-L
is_force_standard_export(TRUE)
```



## Прочее

### is_generate_NSI_script — генерация инсталляционного скрипта

генерирует инсталляционный скрипт.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| args[0] | String | Нет | Постфикс имени скрипта |
| args[1] | Integer | Нет | 0 — использовать текущий каталог, 1 — стандартные папки |
| args[2] | String | Нет | Путь к папке данных |
| args[3] | String | Нет | Путь к папке метапроекта |
| args[4] | String | Нет | Путь к папке ядра |
| args[5] | String | Нет | Имя выходного файла |
| args[6] | String | Нет | Путь к файлу лицензии |

**Возвращает**: ничего.

```EME-L
is_generate_NSI_script()
```



### is_OLE_serverbusydelay — задержка Server Busy

устанавливает задержку появления диалога OLE Server Busy.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| args[0] | Integer | Нет | Задержка в мс (по умолчанию 5000) |

**Возвращает**: `Boolean` — TRUE при успехе, FALSE если фильтр недоступен.

```EME-L
is_OLE_serverbusydelay(10000)
```



### is_set_method_find_mode — режим поиска методов

устанавливает режим поиска методов объектов для текущего контекста. Решает проблему привязки номеров методов к переменной при смене объекта.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| args[0] | Integer | Да | 0 — стандартный режим, 1 — FindMethod перед каждым CallMethod |

**Возвращает**: ничего.

```EME-L
is_set_method_find_mode(1)
```



### is_get_data_path — путь к папке данных

возвращает путь к папке данных текущего проекта. Вызов GetProjectDataDir.

**Параметры**: нет.

**Возвращает**: `String` — путь к папке данных.

```EME-L
path = is_get_data_path()
```



### robot — ссылка на робота

возвращает ссылку на текущего выполняющегося робота (CIRobot). Глобальный объект, доступный из EME-L без явной передачи параметра.

**Параметры**: нет.

**Возвращает**: ссылку на объект робота (ссылка).

```EME-L
r = robot()
```



### is_enable_dataslice — включение срезов

включает режим рабочей станции для работы со срезами данных.

**Параметры**: нет.

**Возвращает**: `Boolean` — TRUE при успехе, FALSE если условия не выполнены.

```EME-L
' Включить режим работы со срезами данных (TRUE — включены) '
result = is_enable_dataslice()
```



### is_restart_as_server_request — запрос на переключение сервера

отправляет на резервный сервер запрос на переключение в режим сервера БД. IP адрес берёт из настройки рабочей станции.

**Параметры**: нет.

**Возвращает**: `String` — текст ошибки или пусто при успехе.

```EME-L
err = is_restart_as_server_request()
```



### is_sys_import — системный импорт

выполняет "ручной" системный импорт по файлам из указанной папки.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| args[0] | String | Да | Путь к папке с файлами импорта |

**Возвращает**: `Integer` — результат выполнения (код EEXPORTRESULT).

```EME-L
result = is_sys_import("C:\\import\\")
```
