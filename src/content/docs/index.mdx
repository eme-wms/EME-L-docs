## О EME-L

**EME-L** — язык программирования, разработанный для платформы EME.WMS (Warehouse Management System). 
Язык используется для автоматизации складских операций, интеграции с ERP-системами, 
создания отчётов и управления бизнес-логикой склада.

### Основные возможности

- **Типизированные переменные** — Integer, Real, String, DateTime и другие типы данных
- **Объектная модель** — создание классов, компонентов, наследование и полиморфизм
- **Встроенная работа с БД** — запросы, транзакции, записи и поля
- **EME-SQL** — расширенный SQL диалект с поддержкой SELECT, JOIN, UNION, TOTAL
- **HTTP интеграция** — взаимодействие с внешними сервисами и ТСД устройствами
- **Отчёты** — генерация печатных форм, редактируемые отчёты, бэнды
